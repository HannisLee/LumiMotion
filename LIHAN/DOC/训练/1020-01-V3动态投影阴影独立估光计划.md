# V3动态投影阴影独立估光计划

## 固定条件

- 日期：2026-10-20；服务器ushas；环境lumimotion-ushas；使用空闲GPU 2。
- 数据集LH-dynamic-jumpingjacks-ELDL-V3；沿用117 TRAIN、18 DEV、15 TEST，时间为(frame-1)/149。
- 固定N00原生Stage1的35000检查点；不更新几何、材质、Stage1或Stage2，不加载旧估计灯向初始化。
- 输出：output/1020-01-LH-dynamic-jumpingjacks-ELDL-V3-T05动态投影估光。程序/日志/缓存不得覆盖旧实验。

## 预先登记的方法与对照

1. 复用旧T05的平面拟合、投影栅格、均衡明暗分类损失。只由TRAIN可见几何RANSAC拟合接收平面，稳定平面点作为接收者；每帧使用完整预测几何中opacity>0.1且高于平面的点作为动态遮挡物，不冻结人物姿态。
2. 观测沿用核验的16位线性化、背景扣除、AREA降采样。最多16384个canonical体素代表点，原深度/法线/Alpha筛选，不要求PS法线运输有效。
3. 原T05亮度标签作为对照：每点TRAIN P90参考，暗<0.2、亮>0.65。
4. 主方案适配环境补光：每点TRAIN P10为加性底亮，P90-P10为动态幅度；幅度须大于max(0.03,0.1*P90)。归一化(I-P10)/(P90-P10)后仍取暗<0.2、亮>0.65。这只近似消除稳定补光，不能消除移动点灯或曝光饱和的影响。
5. 512个半球候选，随机种子1015；每帧至少8暗、32亮，至少10个支持充分的TRAIN时刻。仅支持时刻进入DP，其余时刻归一化线性插值、端点夹取。转移权重0.05，除以相邻支持时刻实际帧间隔，避免DEV长缺口被当作一帧。
6. 主方案固定执行半径6度、步长1度的局部球面网格DP，保留粗路径中心候选；仅TRAIN目标严格改善时接受。候选、阈值、细化范围不依据GT修改。原阈值对照无支持也保留统计和失败结论。

## 冻结与验收

- 拟合进程安装无GT文件读取护栏；只允许TRAIN打包数据、父模型和本输出。保存输入SHA、标签、几何缓存、代价、候选与最终灯向后写冻结收据，再由独立CPU进程读取SUN真值。
- 同时报告粗解、固定细化解、原标签对照，不按GT挑选；主方案事先指定为动态底亮归一化后的细化解。
- 方向误差按世界坐标表面指向光源计算signed夹角，不翻转、不对齐；主要汇报TEST15 mean/median/max，并列TRAIN/DEV/ALL。比较旧固定灯向TEST均值16.336216416度与DIR终点16.313949410度。
- 四类图检查：观测采样、预测接收面与动态遮挡几何、明暗标签与投影叠加、冻结后灯向真值曲线。平面投影图不是完整物理渲染；本实验不声称法线或RGB已改善。
- 工程完成与科学效果分别判定；若支持不足、方向没有改善或可视化不成立，保留所有失败结果，不重调阈值追逐GT。
