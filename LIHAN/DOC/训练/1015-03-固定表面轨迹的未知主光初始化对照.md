# 固定表面轨迹的未知主光初始化对照

## T02 预注册

主机 ushas，环境 lumimotion-ushas。先静态 DL，再动态 DL，沿用默认 Stage1@35000。目标是建立可重复的共享材质／主光拟合，比较随机方向、粗法线＋RGB球面搜索、RGB加25% Stage1重建颜色辅助的初始化；本轮不更新几何，不读取任何GT灯光及测试帧。

表面缓存：canonical包围盒64³体素，每体素选择高opacity代表，最多8192个、种子1015。逐帧用默认形变投影，像素内仅保留预测深度最接近的一点；原图alpha的3×3内部、预测alpha>0.95、相对深度误差<0.01、代表法线与像素法线点积>0.8。原图满码标记保守池化；可见性仅指相机可见，不假设已经得到光源可见性。分辨率为原图1/4。保存所有筛选比例和每条观测，不将筛选后的小误差当作完整几何准确性。

训练内部预留排序索引 `index % 9 == 4` 的15个时间，剩余120个时间拟合；表面需在拟合时间至少有3次有效观测、1次未饱和支持。保留时间仅插值光向和能量，不为其创建参数。默认Stage1已经见过135帧，因此这只是Stage2开发验证，不是全流程独立泛化集。所有候选共享相同缓存和观测支持。

模型：每个代表表面一个跨时间共享RGB有效反照率，softplus正参数；每个训练时间一个单位世界方向及正能量，固定训练节点平均E/pi=1。此时albedo代表规范化有效响应，不强制物理[0,1]界限，也不能声称恢复绝对反照率。无环境、镜面、光源阴影；稳健Charbonnier与单侧饱和残差，固定掩膜／分母。smoothness=0.001，方向学习率0.015、能量0.01、材质0.02，600次全训练观测Adam更新。随机种子1015；先单种子初筛，最终入选与核心对照仍须三种子。

RGB初始化使用固定256个球面候选，对未饱和亮度逐候选拟合正尺度并最小化平方误差；SH辅助仅改变初始化目标为75%真实RGB＋25% Stage1重建RGB，后续损失仍对真实RGB。三组初始化搜索成本单列，不声称完全同总算力。固定600次终点比较，不按保留指标挑选中间checkpoint。

工程门槛：有效观测充足、600次真实更新、预测有限、训练能量均值1、保存后恢复预测逐位一致。科学结果先报告拟合／保留时间的稳健误差、未饱和MSE及覆盖数量；若保留误差未改善或不同初始化收敛到不同灯向，不能声称自标定成功。GT方向独立离线评测后续登记；当前缓存、筛选与训练绝不读取GT。几何与足部无变化，不作科学PASS。

完整命令将在各实验目录 launch.sh 和 README 登记。缓存入口 `scripts.cache_dl_surface_tracks` 经原生bootstrap运行；拟合入口 `python -m scripts.fit_dl_surface_tracks`。输出使用独立日期序号目录，日志同目录；缓存生成四类默认模型图与采样覆盖图。拟合暂输出观测级预测和方向checkpoint，完整重渲、三法线／深度／网格评测尚待后续，必须明确记录缺项。

## 离线灯向评测补充协议

各组固定600次终点后，单独调用 `scripts/eval_dl_light_fit.py --result <result.json> --gt <原数据lights.json> --output <offline_light_eval.json>`。只读训练结果，不加载优化器或改写checkpoint。核实GT灯为同向远场光后，报告拟合／保留时间角误差均值、中位数、P90、最大值和超过30度帧数；不按GT挑选候选或重选中间迭代。GT光强不进入当前评测或任何训练。缺少正式未见时间与受控对照前，仍不作完整科学PASS。

## 同预算 GT 光向参考组

未知光六组完成后，静态／动态分别增加 oracle 子目录，用独立 `scripts.fit_dl_oracle_tracks` 入口读取方向并固定120个训练节点，仍由训练节点插值保留时间。只训练同样的共享材质和能量，600次更新，缓存、掩膜、损失、学习率与验证规则不变。它不读取GT能量／材质，模型不得回灌未知光组。用途是区分估光歧义与当前表面／Lambertian近似偏差，不因读取GT后低角误差宣称自标定成功。
