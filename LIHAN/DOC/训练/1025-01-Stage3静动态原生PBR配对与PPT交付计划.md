# Stage3 静动态原生 PBR 配对与 PPT 交付计划

日期：2026-10-25；服务器 ushas；环境 lumimotion-ushas。用户授权补训、必要调参、PSNR/SSIM 评价及 PPT 图片和 Exporter 文档导出。

逻辑 Stage3 指几何优化后的材质/照明外观阶段；原生 LumiMotion 代码称它为 Stage2，入口 scripts.train_stage2。历史 three_stage 实验有不同模型和失败边界，不直接当成本次成功结果。

静态采用同一 DL-V2 观测：原生 S1@35000 与历史 GS 最优 F-T04@16500。动态采用同一 DL-V2 观测：原生 S1@35000 与完整路线预登记主检查点@16500。动态不依据已见 TEST 改选18000。两组均从各自原几何重新初始化原生环境 PBR，而非从失败外观 checkpoint 继续。静态旧 EL 与 DL 不同照明的跨数据参考，以及 1024 已知方向光 PBR 结果，单独列出，不能混入严格同观测配对。

四臂各20000循环，原生每4循环更新且终点保存先于更新，均4999真实优化器更新；保存新增4000/12000/20000。512半球采样、400×400、黑背景、原生混合追踪深度 depth_ratio=1。保留原生损失、材质/opacity优化范围、冻结XYZ/rotation/scale/运动形变。原生 mlp_color 组虽在优化器中，原前向无梯度路径；不改变该历史行为。动态改进父无颜色头且全点形变，入口必须继承 pred_color/no_binary_separation/hyper_dim 等架构，禁止错误加载或偷偷增加参数。两条几何训练路线不同，动态原生父见过135时刻、改进父117时刻，完整方法对照不能宣称唯一法线因素的因果消融。

本轮 Stage3 动态统一117 TRAIN、静态135 TRAIN；训练 source 无 TEST 文件。固定15 TEST仅在训练完成后用于最终离线评价，不据 TEST 调参、挑检查点或宣称盲测。历史 TEST 已反复查看，属于固定方案复现。动态使用共同原生数据视图，历史该视图 Alpha 来自 Albedo Alpha，只用轮廓、不读材质RGB；来源在 manifest 记录。

先各24循环、5更新工程冒烟，输出 output/smoke_test/1025-03至06-对应名称-冒烟；只查看固定三个 TRAIN，检查加载、保存、原生 PBR 和四类图，不当精度通过。正式各独立GPU0/1/2/3；每卡最多一个本轮训练，不干扰已有进程。总控 output/1025-02-Stage3-PPT配对总控，正式03至06。禁止覆盖失败目录。

统一 PSNR/SSIM：15固定测试视角、黑底完整浮点sRGB裁到[0,1]、逐帧计算后均值，SSIM项目11×11、sigma1.5，补充前景PSNR。保存浮点数组并CPU独立复算PSNR；RGB、Alpha、Normal、原生红绿分离四类必查，另出Albedo、Roughness和统一5倍误差图。静态/动态均选固定相同视角10/80/150和完整视图，不用只看局部遮掩鞋部缺陷。视频注明是随采集相机/时刻变化，不能冒充固定相机动态。

若 TRAIN 显示明确饱和初始化、非有限数或光照问题，先另落档受控单因素修订再训练；不预先保证改进几何必然提高PSNR。最终 README 留完整训练/渲染命令、source/model/iteration、日志、指标、图/视频及四类实际目检，科学失败写 FAILED 并保留模型和全部产物。最终交付根目录 Exporter/1025-01-Stage3静动态实验展示；中文日期序号文档，来源清单和量化表。LIHAN与LIHAN.md仅同步本轮指定新增文件，保留其他会话未提交改动。

## 冒烟接入修复

首轮三臂24循环与三个TRAIN渲染完成，动态候选因原生render_ir未支持None颜色头在第一循环失败。按其零颜色调制语义修复，旧目录/源码快照/日志保留，候选新“冒烟重试1”验证；正式四组统一snapshot_v2，不以该接入修复改变原生有颜色头分支。

## 因果解释边界

正式读取完整父checkpoint，除XYZ/旋转/尺度外也带入其材质DC/SH、门控与MLP，点数不同。故文中早期“只换几何”应解释为“几何优化父模型承接相同环境PBR”，不能称严格只替换几何的单因素消融。最终展示统一使用“父模型承接对照”与“方向光完整方法”的表述。opacity继续学习，因而即使canonical几何冻结，投影深度/法线支持也未必逐像素不变；不把父法线MAE直接当Stage3新checkpoint法线MAE。
