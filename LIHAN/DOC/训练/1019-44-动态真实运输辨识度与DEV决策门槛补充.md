# 动态真实运输辨识度与DEV决策门槛补充

日期2026-10-19 UTC；本补充先于正式Stage2及DEV选模执行。不改原生Stage1、不使用候选TEST/GT结果，不增加正式四组及灯向对照的8100更新预算。

## 冒烟暴露的问题与限定修订

20步A1/B1在首次刷新有24/11可靠轨迹，XYZ/rotation/scale的PS梯度非零，但全部来自模型gate<=0.5的集合。64个动态候选有130条相机有效观测，运输联合有效数为0；有限弦相对误差最小0.27094、中位1.39337，head与Jacobian切平面余弦中位0.58868。不能称动态PS门禁通过，也不能放宽训练43的阈值。正式35000同父模型的完整117 TRAIN、2048候选将按既定门槛复核；若仍无动态支持，保留四组作为有限预算的失败/阴性对照，明确不能证明动态PS收益，不再追加搜索。

置信度原实现用近似旋转矩阵的SVD，与真实加性四元数优化不完全一致。修订为求解点真实运输的两个单位法线切向JVP，加未知rho的幅度列。背光clamp导数及幅度为零，不计有效帧；逐RGB通道独立构建设计矩阵，至少单一通道自身满足>=6观测和奇异值比>=0.05，禁止拼接不相交通道制造可辨识度。保留旧线性SVD作为诊断，不作为最终门槛。目标仍只由真实观测求解、detach，保持PS权重0.02。

修订后重复固定数学控制及A1/B1的20更新工程预算各一次；关闭PS组无需重训，其PS前缀资产已保存。透明度重置后Alpha门槛导致PS短期为空仍判该覆盖项FAILED；normal-opacity隔离只能证明梯度路径，不保证恢复，不更改正式3000/6000重置及200步保护。

配对前缀的原始位相同要求分别检查几何、deformation和物理状态。CUDA光栅含原子累加，独立同种子运行可能有浮点差异：若几何/形变不一致，或物理状态绝对差超过1e-6，则门禁失败；小于该阈值仅记录数值等价，绝不写成位相同。原失败日志与脚本快照保留。独立重载同一检查点仍要求逐位相同。

## DEV资格与选择

固定18 DEV（61..79去除70），只读原RGB与原Alpha，不读法线、几何、灯向或TEST。背景校正使用117 TRAIN已冻结的B，亮区阈值也只来自TRAIN。

以同一Stage1@35000几何在同一18 DEV的几何代理为参照；所有候选只评8100终点。逐帧等权统计，固定前景分母Alpha>=0.5；缺失预测不删去。资格要求：全部参数/渲染有限；前景预测Alpha>0.5覆盖不低于参照减0.05；Alpha IoU不低于参照减0.05；有预测处GS–Expected法线的平均1-dot不高于参照加0.05。覆盖与IoU必须同时报告，代理阈值不是GT准确率证明。

合格者按完整DEV的线性删失绝对RGB误差（原满码通道为下界）逐帧均值最小选主线；1e-6内沿A1、B1、A0、B0顺序。若全部不合格，按同一RGB与同分规则选一个诊断主线完成原定灯向lr1e-5对照，但标记FAILED_DEV_ELIGIBILITY，不能称选出合格模型。灯向组仍从同一Stage1独立8100更新，未用TEST选起点。正式结论保留全部五组，不因DEV或TEST结果增加预算。

最终模型为合格四组主线与其灯向对照中通过相同资格门槛、DEV误差较小者；1e-6内保留冻结灯向。若均不合格，选诊断终点并明确整体FAILED。冻结所有候选身份和预算后才执行隔离TEST/GT统一评测；任何GT数值不得改变上述决策。
