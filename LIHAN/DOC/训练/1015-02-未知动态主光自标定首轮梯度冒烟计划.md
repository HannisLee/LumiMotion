# 未知动态主光自标定首轮梯度冒烟计划

日期：2026-10-15。主机 ushas，环境 lumimotion-ushas。对应 Goal：`../GOAL/1015-01-跨时间表面对应驱动的动态主光自标定.md`。

## T01：先验证实际灯向梯度

本轮仅验证固定默认 Stage1 下未知灯向到原生光栅 RGB 的梯度、真实优化更新与几何冻结。静态 DL 和动态 DL 分别运行一次，使用各自 `output/1011-01-LH-static-jumpingjacks_DL_V2-原生LumiMotion两阶段/stage1_frozen` 与 `output/1011-03-LH-dynamic-jumpingjacks_DL_V2-原生LumiMotion两阶段/stage1_frozen` 的 35000 检查点。

输入为各自 data_view 的 transforms_train.json、训练 RGBA 与默认 Stage1；不读取测试图像、灯光资产、GT 法线／深度／材质／运动。训练相机按现有排序首、中、末均匀取 3 帧；种子 1015；分辨率缩小 8 倍；实际 Adam 更新 24 次、学习率 0.03。随机单位灯向、固定共享灰反照率 0.5、固定能量 pi、无环境／镜面／光源阴影，仅 Lambertian 余弦和原生可见表面光栅。该简化仅用于工程探针，不计为 A1 正式科学结果。

默认形变和颜色头均冻结；保留形变后的 XYZ、旋转、scale／opacity。法线沿用现有旋转头并朝相机定向，尚未证明其为一致的物质法线。颜色头输出不用于物理颜色。线性域平方误差；原图满码以保守池化保留，作为单侧下界处理。所有几何及形变张量更新前后按字节哈希比较。

预注册工程门槛：选第一帧灯向最大绝对梯度分量，中心有限差分步长 0.01／0.003／0.001 的相对误差均小于 5%；梯度非零；24 次真实更新后方向参数变化；三帧平均目标下降；冻结张量完全不变；输出与梯度有限。任一失败保留现场，诊断后新建目录重试。科学灯向精度、几何改进、最终测试和足部验收均未执行。

命令使用 `LIHAN/scripts/bootstrap_1011.py <仓库绝对路径> scripts.probe_dynamic_dl_selfcal --source <data_view> --model <stage1_frozen> --output <独立冒烟目录> --iteration 35000 --frames 3 --steps 24 --resolution 8 --seed 1015 --lr 0.03`。GPU 0 首次检查已有两个其他用户进程，单独顺序执行本任务，运行前再次核实。设置独立 TORCH_EXTENSIONS_DIR 和显式 Conda 编译器，绑定源码与新二进制来源，不改写旧实验门禁或共享缓存。

静态输出：`output/smoke_test/1015-01-LH-static-DL-未知主光梯度`；动态输出：`output/smoke_test/1015-02-LH-dynamic-DL-未知主光梯度`。完整启动脚本、日志、README、梯度数值、checkpoint 和 RGB／Alpha／Normal／动静分离 PNG 均在对应目录。渲染由同一入口训练后执行，无独立渲染命令；checkpoint 不可用于正式实验接续。

后续正式 A／B 对照须另外登记开发划分、共享材质、阴影／环境模型、能量规范、预算与科学门槛。本探针不替代这些必要工作。
