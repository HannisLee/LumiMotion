# GOAL：静态 DLv2 未知方向光下的高精度法线恢复

## 1. 研究目标

阅读 `LIHAN/DOC/GOAL/` 中的 `1011-02`、`1012-01`、`1013-01` 及相关训练报告，复用已验证有效的物理着色、早期法线一致性、几何优化和足部保护策略。

结合 `1015-01` 中 **T05 的阴影投影估光方法**，在 `LH-static-jumpingjacks_DL_V2` 上开展实际训练与迭代，使未知方向光下的 **GS / Depth / Mesh 法线 MAE** 尽可能接近 GT 灯向训练结果。

## 2. 核心约束

- **无 GT 主线**：仅允许使用原始训练 RGB、Alpha、相机及时间信息；禁止使用 GT 灯向或其他 GT 监督，也不得加载任何使用 GT 灯向训练过的模型权重。
- **训练流程**：从无 GT 的静态初始化出发，优先通过阴影投影估计灯向，再接入历史有效的几何训练流程。先固定估计灯向验证法线收益，再根据实验结果探索联合优化。
- **评测要求**：保持原有评测口径，参考历史 T06 的 `2.668° / 5.405° / 4.208°`，量化三类法线 MAE 差距；额外检查人物、腿足区域的深度、覆盖率和几何完整性，避免局部退化被全局指标掩盖。

## 3. 子 Agent 分工

按照以下模型配置创建并调度子 Agent，避免高成本模型承担低价值任务：

| 子 Agent | 指定模型 | 职责 |
|---|---|---|
| 规划 Agent | **GPT-6 Astra High** | 仅负责文献与历史报告分析、技术方案设计、实验规划及迭代方向决策 |
| 训练监控 Agent | **GPT-6 Luna Medium** | 负责训练启动后的日志检查、进度监控、异常发现和运行状态汇报 |
| 评测分析 Agent | **GPT-6.1 Sol High** | 负责定量评测、可视化对比、GT 差距分析、失败原因定位及改进建议 |

**调度原则：**
- Astra High 只用于需要深度推理的规划环节，不参与日常监控。
- Luna Medium 负责训练运行期间的常规监控，异常问题及时反馈主 Agent。
- Sol High 负责每轮训练结束后的评测与结果分析，为下一轮优化提供依据。
- 主 Agent 统筹代码修改、实验执行和结果落档，根据任务类型调用对应子 Agent。

## 4. 实验执行与迭代

持续执行 **分析 → 规划 → 修改 → 训练 → 评测 → 改进** 的闭环。

优先验证阴影估光的准确性及其对法线的实际收益，再逐步引入历史有效策略。每轮坚持控制变量，与独立 GT 对照比较，依据 GS / Depth / Mesh MAE、局部几何质量及可视化结果决定后续优化方向。

必须开展具有充分训练预算的正式实验，不能仅凭短程测试或未收敛结果下结论。保留表现良好的 checkpoint，避免无依据的修改破坏既有成果。

## 5. 文档落档要求

**统一在以下文件中记录，并随实验持续追加：**

`LIHAN/DOC/GOAL/1017-01-静态 DLv2 未知方向光下的高精度法线恢复迭代.md`

严格遵循项目已有 GOAL 和训练报告规范，逐轮记录：

- 实验目标、假设、配置及相对上一轮的修改。
- 代码改动、训练与评测命令、日志路径、checkpoint 路径。
- 灯向估计结果、三类法线 MAE、GT 对照差距及关键可视化。
- 人物和腿足区域的几何质量、异常现象及失败原因。
- 每轮结论、最优结果、保留方案和下一轮计划。

**所有实验及其产物必须可追溯、可复现，不覆盖或丢弃历史结果。**

最终目标不是单纯提高 PSNR，而是在完全未知灯向的条件下，实现接近 GT 灯向对照的高精度法线恢复，同时保持稳定、完整的几何重建。
