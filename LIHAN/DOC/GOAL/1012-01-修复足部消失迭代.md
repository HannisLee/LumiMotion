# Goal：修复足部消失并保持高精度法线

**Goal 文件：`LIHAN/DOC/GOAL/1012-01-修复足部消失迭代.md`**

## 1. 核心目标

在 `1011-02-PBR法线两度突破迭代.md` 已取得较优法线结果的基础上，新的目标是：

- **首要目标：修复人物腿部 / 足部消失问题。**
- **约束目标：在修复足部和腿部轮廓的同时，尽可能保持当前最优法线精度，不允许为修复足部而明显破坏整体法线质量。**
- **基准选择：必须先查看相关报告与历史实验记录，以法线效果最精准的那一组结果作为基准配置，在其基础上分析管线中导致足部消失的原因并迭代修复。**

**最终验收标准：**

1. 从可视化结果看，人物**腿部和足部应完整显示**，轮廓恢复正常，不再出现明显缺失、截断、塌缩或透明消失。
2. 修复后结果的法线 MAE 应尽量接近当前最佳结果，不能出现明显退化。
3. 以“**足部恢复成功 + 法线保持高精度**”作为最终成功标准，而不是仅追求单一数值。

## 2. 优化方向与限制

重点围绕“为什么高精度法线结果下会出现足部消失”展开分析与修复，优先排查以下方向：

- 几何表示、形变网络、可见性或增密 / 裁剪策略是否导致足部区域被错误删除、稀疏化或透明化。
- 足部区域是否因视角覆盖不足、阴影、接触地面、遮挡关系或正则项过强而被错误压制。
- 渲染管线、PBR / 阴影优化、法线约束或几何约束是否对足部这种细小结构产生副作用。
- 在保持最佳法线配置主体不变的前提下，允许对局部几何恢复、densification、pruning、mask、loss 权重、可见性判断及训练策略做针对性修复。

**训练约束：**

- 默认延续上一 Goal 的训练约束与数据范围。
- 仅使用原有训练集图片、原始相机参数及允许使用的光照信息进行训练。
- 不得引入额外 GT 几何、GT 法线、GT 深度、人工分割标签等额外监督，除非原方案已明确允许。
- 历史最佳法线结果只作为**基线对照**与分析依据，不得改变评测口径来制造“修复成功”。

**评测规则：**

- 保持原有测试集、掩膜和 MAE 计算方式不变。
- 除法线 MAE 外，必须增加**足部 / 腿部可视化检查**，作为本 Goal 的核心验收内容。
- 视觉检查至少覆盖：正面、侧面、与足部相关的关键视角，确保足部不是偶然在单一视角下恢复。

## 6. 执行原则

按照 **读取历史 → 分析报告与最佳基线 → 设计修复方案 → 并行实验 → 训练 → 评测 → 可视化检查 → 落档 → 下一轮** 的闭环持续迭代。

优先基于当前法线最优方案做**最小必要修改**，避免无关改动破坏已有精度。若多个方案并行，优先保留那些能够在**足部恢复明显**的同时**维持低法线 MAE**的配置。

**最终目标不是单纯修复一个局部显示问题，而是在保持当前高精度法线表现的前提下，使人物腿部和足部恢复完整、稳定、正常的几何与轮廓显示。**
