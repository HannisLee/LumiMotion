# Goal：Stage2 训练优化与外观质量提升

**Goal 文件：`LIHAN/DOC/GOAL/1013-01-Stage2训练与外观优化迭代.md`**

## 1. 核心目标

首先读取 `LIHAN/DOC/GOAL/1011-02-PBR法线两度突破迭代.md` 及相关报告，选取**法线 MAE 优秀、整体重建效果较好的思路 作为基线。

本轮目标：

- **保持法线精度**：GS、Depth、Mesh Normal MAE 尽量不退化。
- **提升整体 PSNR**：改善 RGB 重建质量和 PBR 外观。
- **修复局部退化**：重点改善腿部 / 足部几何与轮廓，以及局部黑边、阴影伪影等问题。
- **优化训练策略**：分析目前约 10,000 iter 是否训练不足，合理探索更长训练和分阶段优化。

## 2. 优化方向

不强制采用具体方案，由实验结果决定：

1. **训练长度消融**：先核实当前 Stage1 / Stage2 的迭代配置，比较 10k、20k、35k、55k 等训练预算下的 MAE、PSNR 和视觉质量，不要求必须跑满 55k。
2. **分阶段优化**：探索先获得高精度几何与法线，再冻结或降低几何学习率，继续优化 Albedo、Roughness、BRDF 等外观参数的可行性。
3. **伪影修复**：针对腿部退化、黑色边缘进行原因分析，检查几何、Alpha、遮挡、阴影、材质及渲染合成，避免单纯增加迭代却无法解决问题。
4. **自适应训练**：根据验证集指标、可视化效果及收敛趋势决定训练长度、参数冻结与学习率调度，保留效果最好的 Checkpoint。

**训练约束**：延续前一 Goal，仅使用静态 DL 原训练集图片、相机参数及 GT 光照方向；禁止额外 GT 几何、法线、深度、阴影或材质监督。

## 3. 执行与评测

- **GPU 并行**：4 张 GPU，每张最多并行 2 个任务，总计最多 8 个，按显存合理调度。
- **`6.1sol xhigh`**：负责方案规划、实验设计、结果分析及下一轮决策。
- **`6-luna high`**：负责训练执行、GPU 调度、日志监控和异常处理。
- **`6.1sol high`**：负责 MAE、PSNR 评测及结果核查。

**评测指标**：GS / Depth / Mesh Normal MAE、PSNR，以及腿部完整性、黑边和整体渲染效果。保持原测试集与评测口径，不能以牺牲法线精度换取小幅 PSNR 提升。
