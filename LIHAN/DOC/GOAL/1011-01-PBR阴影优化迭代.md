# Goal：静态 DL 的法线 MAE 优于静态 EL

以 LumiMotion 为基线，使用**静态 DL 数据集**持续迭代，使法线恢复效果超过《1011-07》报告中的静态 EL 场景。

## 1. 优化方向与约束

- **优化方向**：围绕方向光下的着色与阴影／可见性解耦，改进 Stage1、Stage2。让受光变化约束局部法线，让投射阴影约束遮挡几何，减少阴影引发的伪几何、错误法线和伪运动。允许调整渲染管线、损失函数、梯度传播及增密策略。
- **训练约束**：仅允许使用静态 DL 原训练集图片及对应 GT 光照方向。禁止使用 EL 图片、额外图像及 GT 法线、深度、材质、阴影或光强作为训练监督。GT 法线仅用于评测。
- **验收目标**：在完整测试集上实现 **GS MAE < 3.51°、深度法线 MAE < 7.35°、Mesh 法线 MAE < 5.46°**。严格保持原有评测口径，不得修改评测掩膜或筛选有利区域。
- **执行方式**：按“分析 → 修改 → 训练 → 评测 → 落档”自主迭代，记录成功与失败实验。

## 2. GPU 并行与模型分工

**GPU 并行：**

- 共 4 张 GPU，每张 GPU 最多同时运行 2 个独立训练任务，即**最多 8 个并行任务**。
- 根据显存和实际占用动态分配任务，避免 OOM、资源冲突及严重性能竞争。
- 每个任务独立保存配置、日志、检查点和评测结果，禁止互相覆盖。
- 可并行探索不同优化方案，但必须保证实验对比公平、结果可复现。

**Agent 模型分工：**

- **规划与分析：`6 astra xhigh`**：负责研究假设、优化方案设计、实验规划、结果分析及下一轮决策。
- **训练执行与监控：`6-luna high`**：负责启动训练、检查日志、监控 GPU、排查运行异常和维护任务进度。
- **指标评测：`6.1sol high`**：负责执行 MAE 评测、汇总各项指标及检查评测结果的完整性。

创建子 Agent 时，如执行环境支持模型指定，应直接按上述分工指定模型。训练监控不需要反复调用规划模型；只有实验完成、出现关键异常或需要决定新优化方向时，才交由 `6 astra xhigh` 分析。

以**三类法线 MAE 同时低于静态 EL**为最终成功标准。每轮优先选择具有明确物理动机、可验证假设的改动；保留最佳 Checkpoint，避免重复无效实验。
