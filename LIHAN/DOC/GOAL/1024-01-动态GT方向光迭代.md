5. 保持动态模型及时间输入。允许分阶段冻结、解冻几何和形变参数，但不能把动态任务简化为静态任务。

6. 沿用原有 117 TRAIN / 18 DEV / 15 TEST 划分，并核对历史父模型的数据使用情况。保持分辨率、背景处理、法线坐标系、掩膜及聚合方法一致。

7. 启动前明确 DEV/TEST 渲染使用的光向来源；若使用对应帧 GT 方向，标明这是已知光照评测设定，不将其用于更新模型。

8. 使用 DEV 选择方案及检查点，冻结配置后开展最终 TEST 评测。说明历史 TEST 已被查看的事实，不声称这是全新的盲测。

四、执行路线

先复核父模型、数据来源、历史指标和评测协议，建立 GT 方向光的最小可运行对照，完成冒烟测试后正式训练。

优先考虑以下方向，由规划 Agent 根据证据确定次序：
- 材质与光照适配后逐步解冻几何；
- GS 法线与预测深度法线的一致性；
- 增密、裁剪和 opacity 更新策略；
- 动态形变学习率与正则；
- 环境光、反照率和几何之间的拟合平衡；
- 必要时设置几何冻结对照，确认提升是否来自实际几何更新。

每轮记录修改因素、假设、训练预算、预期作用及实际结果，优先使用可解释的对照确定收益来源。

完成训练、评测、目检和结果整理。未达标时继续分析和迭代，不将“训练正常结束”或“某个辅助指标改善”当成 GOAL 完成。遇到需要外部信息才能解决的阻塞时，说明具体原因及已保留的证据，不虚报成功。

五、验收标准

核心数值验收：
- 同口径 GS Normal MAE 低于原生基线2°，历史参考为 7.116155°。
- 固定 GT 前景分母、缺失预测罚 180° 的 GS MAE 同时低于原生基线，历史参考为 7.614905°。
- 基线与候选必须使用同一评测协议；不得改变掩膜、删除难帧、只统计共同有效像素，或混用像素加权和帧平均口径来制造改善。
- 若收益接近数值误差，应复评并检查稳定性，不凭舍入差异宣称成功。

辅助评测：
- GS / Depth / Mesh 三类法线 MAE及覆盖率；
- RGB PSNR、SSIM；
- 可获得的 Albedo MAE，并注明输出的物理含义、颜色空间和评测协议；
- 人物与平台分别统计的误差；
- 必要的鞋足及小腿局部误差，用于解释完整性问题。

目检要求：
检查完整人物、手臂、小腿、鞋尖和平台，以及 RGB、法线、深度/Mesh、静动态分离或配置门控四类可视化。

保留同帧、同视角、同尺度的全图、局部细节和误差图。不能只用裁剪后的优势区域代替整体检查。若未训练静动态分离，明确标注该项不适用。

分别给出：
1. GS 数值目标：PASS / FAILED。
2. 整体几何与外观质量：PASS / FAILED，并说明原因。

若数值达标但脚部或外观退化，应如实记录，不宣称完整动态重建成功。

六、多 Agent 分配

授权使用以下三个子 Agent 协作，严格按指定模型与推理强度分配。主 Agent 负责协调、统一实验台账和最终交付。

1. 规划 Agent
模型：gpt-6-astra
推理强度：medium

职责：
- 阅读历史实验，核对父模型与参考路线。
- 制定训练方案、对照实验、预算及验收标准。
- 负责训练实现及配置修改，明确每轮实验假设。
- 根据独立评测结果分析原因，决定下一轮修改。
- 汇总证据，向主 Agent 提交目标是否达成的判断。

2. 评测 Agent
模型：gpt-6.1-sol
推理强度：medium

职责：
- 独立核对数据划分、GT 使用边界及评测协议。
- 重评原生基线，并评测各候选检查点。
- 计算法线 MAE、覆盖率、PSNR、SSIM 和可获得的 Albedo MAE。
- 检查人物、鞋足、平台和四类可视化，识别缺失区域造成的虚假改善。
- 输出可追溯的评测报告，分别给出数值和整体质量结论。
- 不自行修改训练配置，不根据 TEST 结果指导调参。

3. 训练监控 Agent
模型：gpt-6-luna
推理强度：medium

职责：
- 执行规划 Agent 已确定的训练命令。
- 监控 GPU、显存、进程、日志和 checkpoint。
- 记录进度、异常、NaN、OOM 及退出状态，及时通知规划 Agent。
- 完成后向评测 Agent 提交准确的实验编号、模型路径和 iteration。
- 不自行改变损失、超参数、数据划分或预算。
- 不停止其他任务的训练；重试使用独立目录，保留失败结果。

协作规则：
- 每轮按“规划 → 训练与监控 → 独立评测 → 规划复盘”推进；互不依赖的工作可以并行。
- 主 Agent 统一调度 GPU，遵守显存充足时单卡最多并行 3 个训练的限制。
- 明确文件修改归属，避免同时改写同一文件。
- 子 Agent 完成单项任务不代表 GOAL 完成。
- 最终由主 Agent 根据冻结的验收标准和评测证据判断结果。
- 若指定模型或推理强度不可用，明确报告，不静默替换。
