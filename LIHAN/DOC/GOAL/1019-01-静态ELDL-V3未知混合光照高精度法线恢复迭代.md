# 静态 ELDL-V3 未知混合光照高精度法线恢复迭代

启动日期：2026-10-19（Asia/Tokyo；主机日志使用 UTC）。服务器 ushas，Conda 环境 lumimotion-ushas。状态：ACTIVE。本文件是独立新 GOAL，不续写 DL-V2。

## 目标与输入边界

使用 `data/LH-data/static/LH-static-jumpingjacks-ELDL-V3`，恢复准确的 GS、Depth、Mesh 法线和完整的人体、腿足、鞋、平台几何。不能以 PSNR 或训练 loss 单独判定成功。

主线只读取原始 TRAIN RGB、Alpha、相机、时间及它们生成的产物；禁止读取 GT 光照、法线、深度、位置、材质或 TEST RGB 进行初始化、观测筛选或训练。所有模型从头训练，不加载历史 GT 模型。GT 只在隔离的 `eval_only` 离线评测使用。内部留出来自 TRAIN，模型已见图像的检查必须称为训练内诊断。

## 实施顺序

1. 核查帧数、相机、划分、坐标、静态性、颜色空间和曝光；只凭 TRAIN 图像验证暗区分布与光照变化，不假定 EL 已解决可观测性。
2. 首个候选产生前冻结 V3 评测协议和分区；历史 V2 数值不作 V3 成功阈值。
3. 建立 V3 原生基线和显式 EL+DL 无 GT 基线。环境项采用受限共享表示，前向为环境贡献加可见度调制的方向光贡献，DL 可见度不得乘到 EL 上。
4. TRAIN 估光经过内部留出检查后冻结，完成正式几何训练；固定光结果与诊断支持后才研究受约束联合优化。
5. 分析、规划、修改、工程验证、充分预算训练、完整评测、改进。每轮明确控制变量，失败现场全部保留。

## 预算与评测原则

初始正式预算参考 16000 步，保存 8000、12000、16000 和透明度重置附近检查点。最终预算、延长条件与成对配置在训练计划预登记；冒烟最多验证工程，不作为质量结论。T08 重置与损失日程是候选，不默认最优。

联合评测至少包含 GS/Depth/Mesh 法线 MAE（像素及等帧汇总）、Expected/Median 深度、人体/腿足/鞋/平台分区、覆盖率、固定分母距离阈值比例和缺失惩罚。完整 RGB、Alpha、Normal、Separation 四类可视化及正侧背/腿足目检不可省略。缺可靠 GT 的指标记为不可计算，不伪造。
