## 1. 核心目标

请围绕“方向一：跨时间表面对应驱动的主光自标定”，完成实现、受控实验、评测和文档归档，并根据实验结果持续迭代。

**在不读取 GT 光照方向、强度、材质、几何或运动作为训练输入的条件下，从默认 Stage1 的粗几何、粗形变和外观出发，利用同一 canonical 表面在不同时刻的真实图像观测，恢复世界坐标系中的动态主方向光，并使这些光度约束改善动态场景的真实几何与完整性。**

本轮需回答三个问题：

1. 默认 Stage1 能否为未知主光提供有用初值？SH／动态颜色信息是否比“粗法线＋训练 RGB”提供额外收益？

3. 未知光条件下的改进，能否转化为 Depth／Mesh 等实际表面指标的改善，而不只是更好的着色法线或训练 RGB？

本轮重点实现新 Stage2。Stage1 保持默认管线作为共同起点；Stage3 预留光照、几何、材质接口。完整 env map、RadioGS 式间接光缓存、阴影边界几何梯度和方向二的信息矩阵更新不是首轮必做内容，不能同时扩展而失去可归因的对照。

## 3. 数据、模型与优化边界

### 3.1 允许输入与 GT 隔离

- 主线训练只使用原训练图像、原始 alpha（如数据提供）、相机、时间戳和由这些输入训练的默认 Stage1。明确声明采用远场单主光、时间共享材质等先验；灯色是否固定必须依据已声明的采集设定，不能从逐帧 GT 元数据读取。
- GT 灯向、能量、法线、深度、网格、语义和运动仅供独立离线评测；不得用于初始化、筛选训练表面、损失加权、选择候选灯向或调整训练超参数。
- 允许建立明确标注的 GT 光向参考组，使用独立配置／加载器；它与未知光主线同起点、同预算，不能将其优化后的权重回灌主线。
- 从训练数据预先划分开发用的保留时间／区域，固定后再比较方法；最终测试集不用于逐轮挑选方案。原 15 测试帧已被历史实验反复观察，沿用时须说明其局限。
- 保留时间的光照由训练得到的时间模型或预注册插值规则预测，不能拟合该时间的测试 RGB 或插值 GT 灯光。逐帧参数基线也必须说明保留时间的推断规则。

### 3.2 主光与材质

- 一个时刻的主光由全场景共享：单位方向 `l(t)`、正能量 `E(t)`。先实现低维、可检查的时间表示，如球面方向控制点加时间正则；只有证据支持才增加网络复杂度。
- 明确世界坐标、光线入射／指向光源的符号及归一化，处理零向量；不能用每个 Gaussian 的独立灯向吸收几何错误。
- 材质绑定 canonical 表面并跨时间共享。显式固定能量—albedo 的尺度规范，例如固定训练时间的平均能量，并解释相应单位；不能依靠 GT 能量定标。
- Stage1 SH 表示出射外观，不等于入射光照。禁止直接对全场景 SH 求和或取最亮方向作为物理灯向。SH／动态颜色头只能作为待验证的初始化或辅助先验，真实训练 RGB 是主要拟合目标。
- 不允许任意逐点逐时刻颜色、albedo、环境项或曝光自由度替代主光解释。必要的环境底项采用受限参数并做对照，避免把非零环境错误归因给灯向。

### 3.3 表面对应与法线

- 从稳定的 canonical 表面块开始，沿默认形变投影到各帧，聚合可见、受支持的真实图像观测；记录可见次数、法线分布、遮挡、饱和和对应残差。
- Gaussian 身份持续不等于物质对应必然正确。处理遮挡、混合像素和投影越界，不把同一像素内多个 Gaussian 当成独立观测。
- 可靠性只由训练证据得到，并报告被排除比例；不得通过减少困难区域的有效覆盖制造误差下降。静态背景和动态主体分别统计，平面背景不能单独证明三维灯向可辨识。
- 使用变形后的世界法线。局部刚性近似可用旋转运输；一般形变需检查逆转置 Jacobian 或变形切平面关系，不能未经验证就把独立旋转头当成一致的法线运输。
- 首版用漫反射主导区域稳定估光，显式处理 sRGB／线性域和饱和截断。共享 albedo 的最小二乘消元仅用于满足模型假设的有效观测；分母近零、镜面或未建模环境不能强行套闭式公式。

## 4. 执行顺序与最小对照

按以下顺序推进，每次只改变一个关键机制。以最小真实前向、反向和参数更新开始，不先搭建庞大的调度系统。

### 阶段 A：固定几何，验证能否估光

固定 XYZ、尺度、旋转、opacity、点集和形变，先在静态 DL 控制场景验证灯向约定、未知光接口和优化稳定性；随后在动态 DL 上固定默认形变进行估光。静态通过不等于动态 Goal 完成。

同一默认 Stage1、训练观测和预算比较：

| 组别 | 初始化／信息来源 | 用途 |
| --- | --- | --- |
| A0 | GT 光向固定；其他量按共同规则估计 | 隔离的参考组，仅衡量同设定差距 |
| A1 | 与 GT 无关的随机／均匀候选方向，训练 RGB 拟合 | 简单未知光基线 |
| A2 | 粗法线＋真实训练 RGB 初始化 | 检验粗几何提供的帮助 |
| A3 | A2 加 Stage1 SH／动态颜色辅助 | 检验外观先验的增量价值 |

报告初始化及优化后的结果、候选搜索成本、失败率和跨区域预测。候选由训练残差选择，不能按 GT 角误差选最优。A3 没有收益时允许舍弃 SH 辅助，不能将其作为必须证明正确的前提。

先检查真实灯向梯度和至少一次非零优化更新，包括有限差分或小扰动检查；可见性暂用停止梯度近似时，明确记录该近似，不将其描述为完整可微阴影。

### 阶段 B：验证跨时间表面对应的增量收益

在动态 DL、固定默认几何／形变条件下，使用阶段 A 选出的未知光初始化，比较：

| 组别 | 机制 | 要验证的问题 |
| --- | --- | --- |
| B0 | 逐帧主光拟合，共同材质表示 | 独立估光的能力与不稳定性 |
| B1 | B0 加时间平滑 | 平滑本身能解释多少收益 |
| B2 | B1 加显式跨时间表面观测聚合与可靠性筛选 | 对应机制是否提供额外有效约束 |
| B3 | B2 加静态／动态区域之间的预测一致性 | 是否避免只解释局部区域 |

统一材质容量、渲染器和采样预算。若基线已通过 canonical 材质隐式共享信息，必须说明 B2 新增的是观测组织、可靠性或跨帧目标，而不能把已有对应能力包装成新增模块。B3 仅在场景确实存在可用静态区域时启用。

固定训练来源的表面／时间保留集，检查拟合区域之外的 RGB 预测和主光一致性。只改善训练残差、灯向评测和保留预测均无改善时，先定位对应与模型偏差，不直接解冻全部参数。

### 阶段 C：将光度约束转化为动态几何改善

采用联合目标、分块更新：先灯光／共享材质，再真实几何，最后受限形变。先冻结 opacity、增密、裁剪和 reset，减少删除困难表面造成的假改善。

至少保留以下受控比较：

1. 默认 Stage1 起点，以及同预算、不使用新增对应机制的未知光几何优化基线。
2. 最佳未知光自标定方案，开放 XYZ／尺度／旋转等真实几何，保持默认形变固定。
3. 在上一组基础上开放受限形变，检查非刚性对应与光照是否相互补偿。
4. 同起点、同预算的 GT 光向几何参考组，隔离未知光误差造成的差距。

关键对照区分普通联合更新与分块更新；按实际优化次数、采样观测数和耗时报告预算，不能只对齐循环迭代号。通过参数变化、梯度和共享 MLP 主干审计确认“冻结”实际成立。

同时约束表面法线与真实深度／切平面的一致性。只优化独立着色法线而不改善深度／网格，不能算完成几何目标。打开拓扑或 opacity 更新必须有独立原因和对照，不应把历史足部消失策略直接恢复。

做姿态与光照解耦检查：固定几何状态转灯、固定灯播放动作，并检查改变灯光输入是否意外改变 XYZ。无未见组合 GT 时只报告结构与视觉检查，不能宣称已量化证明重光照准确性。

## 5. 评测、验收与调整条件

训练前在计划中登记主指标、非退化容差、缺失处理、选择 checkpoint 的规则和预算。容差依据同协议基线重复测量与具体任务需求确定，不能看到候选结果后放宽，也不照搬历史静态的“两度”阈值。

| 维度 | 必报内容 |
| --- | --- |
| 主光 | 方向角误差均值／中位数／P90，失败时间，轨迹；能量按声明的尺度规范评估，区分训练与保留时间 |
| 几何 | 同一 checkpoint 的 GS／Depth／Mesh Normal MAE，expected／median 深度误差、有效覆盖和固定缺失惩罚 |
| 完整性 | 人体／鞋部等独立区域，足部高度、轮廓与表面覆盖，多视角目检；台面 Alpha 不代替鞋体完整性 |
| 动态 | 动态主体和静态区域分别报告，对应残差、运动稳定性与保留时间效果 |
| 外观 | 同口径 RGB 指标、未饱和观测误差、albedo 中光照残留、受控换光检查 |
| 成本 | 循环数、各参数组真实更新数、观测／光线数、初始化成本、总耗时和峰值显存 |

**完整 Goal 的 PASS 必须同时满足：**

- 未知光主线没有读取禁用 GT，能在动态数据上从默认 Stage1 实际运行并保存可恢复 checkpoint。
- 相比预注册的简单未知光基线，对应机制在灯向恢复与保留观测预测上提供可复核收益；最终候选与关键对照至少用 3 个相同配对种子报告均值、离散程度与失败率。
- 同一模型在动态主体的预注册 Depth／Mesh 几何主指标上改善，其他关键几何指标在登记容差内，覆盖率与足部完整性不恶化；缺损未修复时必须明确写出，不能称完整重建已解决。
- 收益不能仅由额外输入、更多更新、删除难点、放开时变颜色或选择不同 checkpoint 的单项最优解释。
- 完成 RGB／Alpha／Normal／动静分离四类目检，以及深度、网格和关键足部补充检查；命令、结果和限制均可追溯。

**调整与停止条件：**

- 灯向不可辨识时，先分析法线覆盖、对应误差、饱和及环境／镜面偏差；如实记录不确定性，允许缩小可支持的结论。
- 对应机制没有稳定收益，保留负结果并简化方案；连续两轮针对同一假设的受控实验无改善后，先总结证据并改变假设，不无限延长同一训练。
- GS Normal 变好但 Depth／Mesh 退化、足部缺失或运动异常时，判定几何目标 FAILED，回到具体参数路径排查。
- 环境或输入缺失阻止运行时，记录可复现的阻塞点。工程检查通过、阶段 A／B 通过、预算耗尽或文档归档都不等于完整 Goal 完成。

## 8. 方法来源与研究定位

- [PS-NeRF](https://arxiv.org/abs/2207.11406)：多视角、多未知光条件下联合恢复的参考；不能假设本项目具备同姿态多光堆栈。
- [Self-calibrating Photometric Stereo by Neural Inverse Rendering](https://arxiv.org/abs/2207.07815)：光照、材质与表面自标定及镜面线索的参考。
- [Photometric Stereo for Dynamic Surface Orientations](https://www.microsoft.com/en-us/research/publication/photometric-stereo-for-dynamic-surface-orientations/)：动态表面法线与观测对齐的参考。
- [Dynamic 3D Gaussians](https://arxiv.org/abs/2308.09713)：持续表面身份、局部运动与对应建模的参考。

本轮待验证的贡献是：在每时刻单张观测、物体非刚性运动与主光同时变化的条件下，将可靠的跨时间表面证据转化为主光自标定和真实几何收益。时间 MLP、交替优化、共享材质和最小二乘消元本身不作为新颖性声明；近邻工作及查新边界沿用路线讨论，不能宣称已经证明首次或完成全部创新验证。
