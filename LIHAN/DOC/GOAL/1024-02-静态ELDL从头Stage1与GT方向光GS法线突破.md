### 一、目标与指标

### 四、静态场景和允许输入

本任务是静态几何：人物固定在原动画第100帧，相机和主方向光变化。训练共享canonical Gaussian，关闭时变几何与时变颜色的拟合自由度，不能借动态形变吸收光照误差。

原数据150视角、800×800、16位PNG，原划分135 TRAIN与15 TEST。保留原15张TEST（10、20、……、150）。从原135 TRAIN中预先固定DEV并隔离，优先核验现有117 TRAIN /18 DEV配置是否适用于这套静态数据；同一划分同时用于新Stage1和后续候选。不能先让Stage1训练全部135帧，再把其中18帧称为完全未见DEV。历史EL若用了135 TRAIN，明确记录数据量差异；必要时补充同划分EL对照，同时保留用户指定历史参考。

训练只用合法训练RGB、原Alpha、相机以及对应帧GT主方向光的单位向量。原Alpha若需从albedo文件提取，只提取Alpha通道，生成净化输入，不读取或使用其RGB材质值。保留16位信息并核对背景、线性/sRGB变换和缩放方式。

`lights.json` 的 `light_dir_world` 定义为表面指向太阳、用于n·l。先核对帧号、坐标轴、方向正负和单位化，再导出仅含合法帧号与方向的净化文件。方向固定不训练；GT光强、颜色、点光位置、GT环境、GT法线、深度、albedo、mesh、语义标签和物体姿态不得进入训练监督、初始化或正则约束。独立评测使用GT不等于允许训练使用GT。

ELDL-V3实际包含旋转SUN、两盏固定点光和恒定环境光。因此保留完整原始RGB，并从TRAIN RGB学习环境及额外照明的表达；可研究共享normal-SH或其他有约束残差，明确其近似边界和可辨识性。不能直接照搬纯DL的ambient=0，也不能用GT分离出纯方向光图像来替换任务。不得让无限制逐帧残差吸收全部光照而绕开几何优化。

### 五、训练路线

阶段A：从新随机Gaussian初始化运行静态原生Stage1，记录种子、实际optimizer更新次数、保存iteration、全部参数和冻结源码。以历史原生35000日程为核对起点，由规划Agent在训练前固定实际预算及保存点，检查实现是否存在末步少一次更新。完成重载与独立基线评测后封存父模型。

阶段B：从本轮父模型继承几何，转换到已知GT主方向的物理着色。先做有明确预算的材质/照明适配，再解冻XYZ、旋转、尺度等几何参数开展优化。核验继承逐项一致、RGB和normal确实能驱动几何，不能只训练外观后宣称法线改善。采用本轮父模型的状态制定续训日程，不套用随机初始化的global step，更不能把35000之后本已停用的增密误当作正常启用。

优先复用并核验以下机制：

- censored鲁棒RGB：大正残差权重0.25，大负残差权重0.5，阈值0.08；饱和像素使用单边约束。是否适配混合光及原图预处理须有TRAIN/DEV证据。
- Alpha BCE权重0.1、预测expected-depth normal一致性权重0.1、distortion权重1000作为历史初始候选；normal不是GT法线监督。
- 仅切断normal→opacity梯度，保留normal→XYZ/rotation/scaling以及其他loss→opacity路径。历史证据针对自然reset后恢复窗口，应针对新父状态做配对验证，不认定任何时刻detach都更优。
- 使用预测几何计算可见度，核验缓存更新、normal翻面和物理前向；记录BVH可见度是否停止梯度。
- 原增密路线、受控reset、短程续训、适合父状态的XYZ学习率；明确Adam是否重建、增密统计是否清零、global iteration与新增真实更新数的关系。

阶段C：围绕DEV证据做少量可解释的配对实验，例如normal梯度路线、混合光容量、几何解冻时序和增密恢复。每轮先写方案、假设、预算、保存点及选择规则，再执行冒烟和正式训练。失败后归因并持续迭代，不能只提交首轮失败结果，也不能盲目延长同一无收益路线。

### 2. 本轮迁移必须解决的三个差别

第一，DL历史最优是从随机几何开始、较早进入物理着色的一条Stage1训练谱系；用户本轮要求先完成原生Stage1，再用GT方向继续优化。复用的是loss、梯度和拓扑机制，不是把旧DL权重搬到ELDL，也不是声称同样的iteration编号对应同样的几何状态。

第二，ELDL有环境光与两盏点光。纯DL的ambient=0不适用。第一版采用共享低阶normal-SH作为稳定照明近似，加GT主方向的Lambertian直射分量和预测可见度；记录每个分量的能量、残差空间分布及几何梯度。环境与点光近场效应未必能被低阶SH表达，只有TRAIN/DEV残差显示该瓶颈时，再单独增加空间照明表达能力。不得同时扩大照明容量、改loss、改增密而失去归因。

第三，新父模型已经过原生35k训练。几何精度、opacity和点密度都不同于旧14000检查点。不能把累计35000直接传给旧DL入口后令所有增密失效，也不能重放旧reset周期冲掉成熟表面；为续训显式定义相对step、学习率和拓扑窗口。

历史ELDL三阶段实现还保留了父MLP逐帧输出；本轮要求共享静态几何，需在新Stage1训练前就冻结时变几何自由度。若使用原生入口的静态配置，记录与历史B00的区别；禁止在续训时直接删除已训练的非零MLP而声称完整继承。发现非零逐帧几何时先修正父模型训练配置，不能用截取某一帧冒充无损转换。

R阶段不是必跑项：固定拓扑已足够且reset无合理诊断依据时直接进入F阶段或最终冻结。F阶段先做跨拓扑事件的110步冒烟；100步增密、screen threshold 0.0002、min opacity 0.01作为历史初值，核对成熟父点云的实际尺度和过滤行为后冻结。必要时增加同父、同预算的无增密对照，判断收益来自拓扑还是额外优化步数。

A0采用可学习混合照明时应固定一个幅度规范以缓解albedo/光强尺度歧义，具体规范在训练前登记；不直接混用历史固定2π、lambda_mix和另一套自由光强参数。首轮不安排几何冻结的完整PBR外观Stage3，因为该阶段不直接推动本次GS法线目标；需要更准确的物理前向时，由规划Agent提出与几何目标有关的受控改动。

### 4. 首轮参数、审计与可变因素

初始合成loss取历史 `L_photo + 0.1 L_alpha + 0.1 L_normal + 1000 L_distortion`。其中L_normal为渲染GS法线与预测expected-depth法线的一致性；沿用历史Alpha腐蚀5×5、预测Alpha>0.5及单位化口径。鲁棒RGB阈值/权重为0.08、0.25、0.5，逐通道饱和下界规则保持。新的混合光模型与旧DL前向的差异单列，不能把新实现包装成逐值复现。

首轮成熟几何LR建议以已有静态ELDL接续方案为初值：XYZ 1e-6、rotation 5e-5、scale 1e-5、opacity 1e-3，几何优化阶段衰减至初值0.1倍；反照率适配阶段1e-3、联合阶段2e-4；共享照明适配1e-3、联合阶段1e-5作为候选。它们是本轮初始规划，不是DL最优的原LR。若梯度和参数位移显示几何几乎不动，再做同父同预算的几何LR倍率配对，不把LR不足误判为方法无效。

A0结束后G0/G1同时重建相同Adam状态，记录零动量和相同参数哈希；后续各段是否重建优化器、统计清零均登记。相机不放回采样，续训seed1012，所有配对保持相机序列一致。执行顺序统一为forward/backward→optimizer→拓扑/reset→保存；终步不做无后续训练承接的拓扑改动。

必须直接审计：full/detach前向相同；normal→opacity由有限非零变成零；normal→XYZ/rotation/scaling保持；RGB/Alpha/distortion仍能更新opacity；两个normal副本的screen梯度先向量相加，再累计一次范数和denom。只检查配置字段不足以证明上述机制。

### 5. 迭代优先级与评测负担

先解决物理转换和混合光残差，再检查法线梯度路线，再研究reset/增密及短程细化，最后才增加照明容量或新损失。按单因素配对推进；旧DL未显示稳定收益的non_normal_floor不列为首轮默认方案。

每个预定保存点在DEV上做GS、固定分母误差、coverage及RGB快速评测；进入下一阶段的少量候选再补Depth/Mesh和鞋足局部图。最终冻结的同一检查点完成完整TEST、四类图和视频。不能每隔很少步做一次完整TEST/Mesh重建来挑最低值。

DEV优先选择覆盖及人体结构无退化、GS更低的候选；近似持平时比较固定分母GS和鞋足诊断。数值容差、覆盖下降容限及几何完整性门槛由独立评测Agent在首次候选结果出现前明确冻结，不能事后为了某个模型放宽。

若首轮失败，必须区分：原生父几何不足、混合光表达不足、物理转换造成的残差、几何LR过小/过大、normal驱动opacity丢点、增密裁剪损伤、平台掩盖人物退化。每次下一轮只针对已有证据最多改变一至两个有明确关系的因素，并记录共同父模型和新增真实步数。可按需要补一个独立seed复验，区分稳定收益与单种子偶然低点。
