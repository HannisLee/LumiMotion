# Goal：PBR 阴影与法线优化——突破 2° MAE

**Goal 文件：`LIHAN/DOC/GOAL/1011-02-PBR法线两度突破迭代.md`**

## 1. 核心目标

在上一轮静态 DL 优化已超过静态 EL 基线的基础上，继续突破法线精度极限。

- **核心目标：GS Normal MAE < 2.00°**
- **辅助目标：** 持续降低 Depth Normal MAE 和 Mesh Normal MAE，至少保持上一轮最佳水平，力争三项均低于 2°。
- 以当前最佳 Checkpoint 和训练配置为新基线，不从头重复已完成的无效实验。

## 2. 优化方向与限制

重点研究方向光下限制法线精度的残余误差，包括：

- 阴影可见性与法线梯度的进一步解耦。
- PBR 渲染方程、BRDF、直接光与间接光的优化。
- 多光照方向下的法线可观测性与跨帧一致性。
- Gaussian 几何、法线参数化、正则化及增密策略。
- 通过误差空间分布和消融实验定位精度瓶颈，允许探索新的优化方案。

**训练约束：** 仅使用静态 DL 原训练集图片、原始相机参数及对应 GT 光照方向。禁止使用 GT 法线、深度、材质、阴影或其他额外监督进行训练。GT 仅用于离线评测。

**评测规则：** 保持原有完整测试集、掩膜及 MAE 计算方式不变，不得通过更改评测口径、数据泄漏或筛选有利样本提升指标。

## 3. 并行执行与 Agent 分工

- **GPU：** 4 张卡，每卡最多并行 2 个任务，总计最多 8 个任务，按实际显存动态调度，所有任务独立保存日志与 Checkpoint。
- **`6.1 sol xhigh`：** 负责创新方向规划、误差归因、实验设计及每轮结果分析。
- **`6-luna high`：** 负责训练执行、GPU 任务调度、训练监控与异常处理。
- **`6.1 sol high`：** 负责 MAE 评测、指标汇总和评测一致性检查。

环境支持指定子 Agent 模型时严格采用上述分工，避免使用高成本规划模型执行常规监控任务。
