# GOAL：B-guided 环境贴图初始化的渲染方程 Stage 2

落盘位置：LIHAN/DOC/GOAL/1113-01-B引导环境贴图初始化的渲染方程Stage2.md


本轮位置：Static ELDL 方向光初始化线（冻结 Stage 1、150 帧、Blender GT 冻结后一次评测）。2026-11-11 组会老师定调：抛弃几乎无约束的标量 B_G、Stage 2 换成渲染方程（关键是物理约束与可辨识性，不是参数数量）；本轮是该定调的第一轮实现，但初始化路径不用 Stage 1 的 SH——理由：Stage 1 的 SH 同时拟合了静态光与动态光，即使其 RGB 重建质量好，也不保证恢复出的 SH 是准确的静态光照，不能直接转成静态 Environment Map。本轮改用已验证灰度模型分解出的 b 做 B-guided Environment Map Initialization：已在显式分离动态光的模型里学到的静态亮度先验，去约束 PBR 静态分支的环境贴图初始化，再联合微调。

现行最优基线与先验来源：E4（GOAL 1031-02，分支见最优方案 1103-01，冻结产物 output/1031-12，只读）——Mean 4.248° / P50 3.787° / P90 8.030° / ≤5° 90/150；方位 MAE 0.707、仰角 MAE 4.013、仰角偏差 −3.890°。本轮的 (ρ^Y, l_t, b) 先验全部取自 E4 冻结产物。1108-02 无正则版（Mean 4.2266°）是否取代 E4 为下游默认仍未裁定，本轮不预设切换，E4 仍为对照基线。

已核查事实（2026-11-06 BG 探查，须以代码复核为准）：Stage 2 现行模型的 b（即 b_g）是每个 Gaussian 一个非负标量、亮度量、跨全部 150 帧共享恒定，不随法线变化，不是梯度优化得到的，而是闭式 NNLS/KKT 解出。由此直接决定本轮 L_static 的形式：b 只能约束每个 Gaussian 的跨时间平均静态亮度，不许要求逐帧 PBR 输出等于 b——物体运动会改变法线与可见性，静态光的逐帧反射结果本就随时间变，逐帧等式是错误约束。

导师要求（2026-11-11 组会原文要点）：① 标量 B_G 几乎无约束、能自由补偿 radiance 变化，分解无物理意义，必须换成渲染方程；② 第一阶段用 Lambertian，roughness 可先去掉或固定为常数，最终 Stage 3 再优化；③ 两个公式共用同一个 albedo 参数，不许另起一套；④ 同曝光下不新增可学习光强标量（环境光自身尺度可吸收），仅当环境图归一化时才许一个平衡参数且须写明归一化方式；⑤ 环境光用照片形式的环境贴图表示，老师已认可；⑥ 两成分命名固定为 static environment illumination 与 controlled illumination，方法表述为 Light Direction Estimation via Inverse Rendering，弃用 matching brightness；⑦ Stage 2 核心是 illumination、geometry、reflectance 联合优化，现阶段重点在 albedo 分解。


本轮只改初始化与静态分支的建模方式，目标模型（规划阶段定稿）：

Î_t = Lambertian(ρ, n_t, l_t, V_t) + PBR(ρ, L_env; α0)

只有 Lambertian 分支含动态光（controlled illumination），PBR 分支只负责静态环境照明（static environment illumination），roughness 固定为 α0 不参与优化。规划阶段须写明 α0 的取值与依据，并对照组会 §3.2「roughness 可固定为常数」与 §3.6「先去掉 roughness」两处口径，记录本轮选固定常数的理由，不得含糊带过。

1. 先验继承：(l_t, ρ) 由 E4 的灰度分解结果初始化（l_t 直接继承，ρ 的 RGB 化方式规划定稿）；动态光分支结构与 E4 一致，不重新发明。
2. EnvMap 初始化分三步：A 固定 ρ、l_t，环境贴图初始化为均匀灰度，继承已有光照尺度；B 只优化低分辨率环境贴图，监督 = L_static（见下）＋真实 RGB 重建损失并行，不许只用 b 单独拟合环境贴图；C 逐步联合优化 ρ 与 L_env，最后微调 l_t。
3. 静态亮度监督：L_static = || Y(PBR(ρ, L_env; α0)) − b ||₁，其中 Y 为 RGB 转灰度；按已核查事实，约束作用在每个 Gaussian 的跨时间平均静态亮度上，聚合方式（先逐帧渲染再时间平均）规划定稿并写明。
4. Indirect Light 隔离：LumiMotion 管线另有基于 Stage 1 颜色的间接照明通道（见 GOAL 1107-02 对 --wo_indirect 的核查），动态光可能经 Stage 1 颜色漏进 PBR 的间接分支。静态光初始化阶段（步骤 A、B）先关闭或冻结该通道，EnvMap 拟合完成后再决定是否在静态光条件下引入，决定与理由记入 GOAL 文档。


- 参数自由度红线：环境贴图只许低分辨率全局一张（分辨率规划明示），不许逐高斯自由环境项，不许重蹈 1108-01 无约束 SH 的覆辙；ρ 全场共享同一参数（RGB 三通道），不许两分支各一套 albedo。
- 可辨识性防护：L_static 的时间平均形式即本轮核心防护；另须设无 GT 检查项，至少含环境项能量占比（回应 1108-01 环境项吸收约 70% 线性能量的教训，规划须预先写明占比的合理区间或等价约束）与 L_static 残差分布；环境图归一化与否二选一在规划中定死，若归一化则按导师口径引入平衡参数并论证。
- 正则口径沿用 1108-02 裁定：不恢复 L_coef 与光轨迹平滑；环绕结构项（λ_rev 反向惩罚、环绕方向、初始总绕行检查）保留。
- 本轮明确不处理：roughness 优化（Stage 3）、光源绕相机合成数据、真实拍摄数据、relighting（另行承诺，不混入本轮）；规划若认为有结构冲突，单列说明并请示式记录，不得擅自改动。


冻结后一次 GT 评测：Mean / P50 / P90 / ≤5° 帧数，与 E4 逐项对照，方位/仰角误差分解。以 Mean 为主指标：严格优于 E4（4.248°）记 PASS，否则如实 FAILED。本轮特有诊断量：环境项能量占比、L_static 残差（均值/分布）、逐通道残差 RMS 比（回应 1108-01 的 R 通道问题）。
