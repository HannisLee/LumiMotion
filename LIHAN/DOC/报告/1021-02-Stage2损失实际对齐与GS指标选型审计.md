# Stage2损失实际对齐与GS指标选型审计

日期2026-10-21（Asia/Tokyo）；ushas/lumimotion-ushas。按用户质疑，只读复核实际训练，不改权重、模型、评价或重训。

## 结论

本次动态DL V2与之前ELDL H0的训练核心源码、loss实现、完整config和关键执行日程一致，未发现loss漏开或配方运行错分支。但H0是按三法线综合MAE选择的，用户当前关注的是全前景GS渲染法线MAE。此前将综合法线改善作为GS目标的依据，选型不准确。

更正后的证据是：ELDL H0本身的GS也没有胜过原生Stage1，所以不能根据它的综合MAE改善推断迁移后GS应当改善。当前结果只说明这次单种子配置没有实现GS收益，不构成该类loss必然无效的证明。

## 1. 实际loss及图片配方的差别

本轮实际执行：

`L = L_historical_RGB + 0.1 L_Alpha_BCE + 0.1 L_normal + 1000 L_distortion`

| 项 | 用户图片的I0配方 | 迁移使用的H0配方 |
|---|---|---|
| RGB | 0.8 L1 + 0.2(1−SSIM) | 历史单侧稳健sRGB光度函数 |
| Alpha | 0.1 L1 | 0.1 BCE |
| normal | 0.1自一致性 | 0.1自一致性 |
| distortion | 1000 | 1000 |

H0的config虽含lambda_dssim=0.2，historical分支不调用SSIM，实际dssim恒为0。该字段不代表SSIM被开启。DL V2尚未运行I0图片配方，本轮不能称其结果。

两次H0各88条实际训练记录均复算总loss。DL V2的`rgb+0.1alpha+0.1normal+1000dist`与记录loss最大差7.3012e-9；ELDL H0最大差4.7755e-9，符合float归约误差，证明日志和实际加权式一致。

## 3. 选型指标的纠正

以下均为全前景GS渲染法线的有效预测像素加权MAE，单位°，每行只和自身数据集Stage1比较。

| 数据集/模型 | GS MAE |
|---|---:|
| ELDL原生Stage1 | 7.116155 |
| ELDL I0图片loss | 7.306651 |
| ELDL H0历史loss | 7.694974 |
| ELDL I1联合校准 | 7.147468 |
| DL V2原生Stage1 | 14.545605 |
| DL V2迁移H0 | 14.673674 |

ELDL三组GS均未超过其自身Stage1；H0只是综合法线最优，不是GS最优。DL V2的GS增加0.128069°，综合值下降主要来自Depth/Mesh。这两种结论可以同时成立。

## 4. 估光与训练目标的限制

DL V2实际使用的P10底亮细化方向TEST均值17.223240°、P95为74.525395°；冻结原阈值粗解均值6.848114°。底亮规则在纯DL上存在严重尾部失效，不能沿用ELDL精度结论。

normal项约束渲染GS法线与模型预测深度导出的法线一致，不是GT法线监督。该loss降低不保证GT GS角误差降低；两组都受自身几何和光照解释能力影响。当前只读审计不能单独量化错误灯向、环境残差或几何参数化对GS结果的贡献。

后续实验应将GS MAE明确为主指标，按图片I0配方或固定loss下的灯向对照分别预登记；不能继续按综合最优挑H0后宣称满足GS目标。本次只完成审计。
