# 参考损失三组Stage2整体结果与动态主体边界

## 结论

三组均已完成8100个新增更新及统一评价。参考图片与历史损失的这轮改动确实降低了全局综合法线MAE：最好H0从上一轮14.701°降至12.118°，也优于原生Stage1的13.865°。但收益集中在平台和Depth/Mesh法线；人体与鞋部没有同时超过Stage1，RGB也仍明显较差。当前不能用任一组全面替换Stage1。

执行验收PASS；全局综合法线改善PASS；动态主体几何与外观联合验收FAILED。失败checkpoint、渲染、统计和日志全部保留。

## 评价范围和比较口径

- 数据集LH-dynamic-jumpingjacks-ELDL-V3；同117 TRAIN、18 DEV、15 TEST。三组同N00 Stage1@35000父模型，唯一预定终点8100，无TEST选checkpoint。
- 综合法线为GS渲染法线、Expected Depth法线、Mesh法线三方法等权，先逐帧等权汇总；固定GT分母，缺失预测罚180°。分区同口径。不能将其与条件有效像素MAE混用。
- 原生N00和上一轮投影Stage2均取已有同协议评价；核对逐帧统计算术与候选间固定GT分母，核对三组终点模型文件与冻结SHA一致。
- 本轮单种子1019，不能将0.016°的组间差距解释成稳定显著优势。所有终点评分一起报告，未按TEST结果重训或挑中间checkpoint。

## 实际四类目检与光照分量

实际查看每组5张10/80/150帧接触表，加70帧人体及110帧鞋部局部，共21张图片；未宣称人工逐帧看完150帧视频。图片清单及SHA见总控result_review_v1/manual_review.json。

1. RGB含Alpha：三组保留动作和大体轮廓；面部、衣服、手臂与鞋细节仍模糊，局部Alpha缺失。70帧手臂碎片与110帧鞋旁漂浮碎片可见。I1量化外观最好，视觉差异较小。
2. 法线：GS较平滑，Expected Depth人体、腿足仍有条纹；平台法线改善不足以替代主体质量。不能把GS平滑当作真值准确。
3. Depth/Mesh：Mesh相对平滑，但手臂断裂/碎片、鞋部误差和平台起伏仍存在。15 TEST各有真实独立TSDF，其余135视频帧标注未重建。
4. 静动态门控：大体人红地绿，脚边地面存在泄漏，门控不是GT语义。
5. Stage2额外EL/DL：EL视觉仍接近完整RGB，DL图较暗；本轮目检不构成EL/DL能量比例定量结论。

本轮方向冻结，不存在新训练将灯向继续优化到更低角误差的结论；沿用投影方案。此前该投影方案TEST方向误差均值3.878°、中位数2.906°、最大16.664°；本轮没有把这项已知最大误差变小。
