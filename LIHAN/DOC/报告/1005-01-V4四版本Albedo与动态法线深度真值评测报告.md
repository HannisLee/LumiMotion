# V4 四版本 SSIM、Albedo 与动态法线、深度真值评测报告

日期：2026-10-05（Asia/Tokyo）；服务器 `venus`；Conda `lumimotion`。评测编号 **1005-01**，评测对象为 **1003-01/02/03/04 的最终 55000 权重**。每组使用完整15个留出测试帧，共60组相机/时刻；另用每组105个训练帧进行统一的 albedo 尺度诊断。未重新训练，未覆盖原始模型、baseline 或 Blender 文件。

## 主要结果

- 静态两组全前景法线约 **7.73°**、expected Z 深度约 **3.07 cm**；动态两组分别为 **11.33° / 9.38 cm** 和 **10.52° / 8.80 cm**。动态布料自身误差明显更高：**20.98° / 20.30 cm** 和 **19.60° / 18.37 cm**，全场景平均会被相对准确的椅子和平台稀释。
- 同为静态时，Lambertian 数据组 raw albedo bMAE 比原始材质组低 **13.4%**；同为动态时低 **28.7%**。四组仍有阴影形状、斑驳和色偏残留，不能把流程通过解释为正确分离了材质。
- 四组没有已有的 `calibration` 或 `albedo_scale` 文件，训练命令也没有光强标定步骤；都使用原版学习环境光。AREA 灯 `energy/intensity=1800` 不是可直接用于当前模型的单位方向光照度。此次统一报告 **raw 绝对误差 + 仅训练帧拟合全局 scalar 后的诊断误差**，不会将灯功率1800直接乘除到 albedo，也不会用测试帧调系数。
- 两个动态集共用已提供的动态 Blender 场景，各自的 alpha/EXR 独立核验通过。已重新导出 **15个逐帧动态三角面 PLY**，每帧几何不同，深度 GT 实际从新 PLY 求交生成；旧动态 baseline 未参与评分。

## 2. Albedo 光强和尺度统一

### 训练与已有标定核对

读取每组 `cfg_args`、实际Stage2命令、PLY/deform/envmap权重目录，以及相应 `lights.json` 和 Blender 场景。四组采用相同原版IR算法及相同灯元数据；Blender中光源为AREA，功率1800，颜色白色。光源随帧移动，原版Stage2学习一张环境光；文件夹名 `chapel_day` 只用于输入布局，不代表采集光是固定HDR。

没有发现上述四组模型的光强标定文件或已保存albedo缩放文件，也没有 `photometric_lambertian` 独立方向光 checkpoint。原版学习环境光与材质之间可能存在尺度自由度，因此学习到的亮度尺度未必等于Blender的绝对物理功率。数据标签Lambertian描述生成图像时使用的材质管线；提供的blend保存了原始Principled节点，不能只凭保存节点把Lambertian数据认定为已做过绝对光强标定。

本次每组先取 `get_albedo` 的sRGB材质并转线性，使用各帧实际形变和相机，以零背景直接光栅化，然后除以累计alpha取得可见表面材质。这个过程不查询环境光、BRDF、SH颜色调制、阴影或镜面项。对未预测到的GT内部像素仍计算材质误差。

### 所有组采用同一校准方法

仅在105个训练帧的GT内部前景上，以全模型一个非负scalar拟合：

```text
s = sum_train(pred_linear * GT_linear) / sum_train(pred_linear ** 2)
calibrated_test = s * pred_test_linear
```

同一组所有相机、材质和时刻使用同一个s；15个测试帧不参与拟合。各组系数数值不同是其学习材质尺度不同，统一的是拟合数据划分、掩码和公式。raw仍为主指标，校准用到了额外GT albedo监督，属于亮度尺度诊断，不能称为模型自行完成了光强标定。校准后不裁剪至[0,1]，不进行逐帧或逐材质最佳拟合。

| CV4D | 1.308752 | 0.178358 | 0.133791 | 0.133193 | 0.122752 |

### 真值生成与逐帧对齐

生成GT时读取新PLY，并验证其顶点、三角面、角点法线和物体ID与同帧evaluated mesh完全一致。使用Open3D CPU射线求交，从640×360评测相机的像素中心发射**不单位化**射线，取首个三角交点，因此 `t_hit` 为正camera Z。另存射线距离用于审计，不混用两种深度。

未使用模型产生GT、未使用旧baseline求交、未做ICP、尺度/平移拟合或图像min/max对齐。Blender为METRIC且scale_length=1，本报告1世界单位=1米，表格深度转为cm。GT是中心射线三角表面深度，不宣称与EEVEE抗锯齿Z pass逐像素相同。

新网格与GT alpha的最低IoU：静态 **0.999491**，动态两组各 **0.999244**。内部区域网格插值法线与各自EXR的角度均值范围：静态约 **0.657–1.624°**，动态约 **0.278–1.472°**。这验证了当前帧表面、坐标、相机与已导出的GT一致；残差来自中心射线与EXR渲染/重采样方法差异。

## 4. 动态预测与法线、深度协议

每个测试帧严格对应：

```text
source_frame n → time=(n-1)/119
当前模型canonical PLY + deform PTH(time, binary feature)
→ 当前帧Gaussian位置/旋转/尺度 → 当前帧相机栅格化
GT Blender frame n → 新导出mesh_n.ply → 同相机/像素中心GT Z及法线
```

原始模型PLY的 `nx/ny/nz` 零占位不参与预测法线。预测法线取真实变形后Gaussian盘面法线的alpha合成结果，转换世界坐标并单位化；主法线角度为 `acos(clamp(dot(pred,GT),-1,1))`，单位°，不取abs(dot)来掩盖反向法线。无方向轴误差、分量MAE、深度导出法线也保留为辅助项。

主深度固定为 `expected_Z=sum(alpha*T*Z)/sum(alpha*T)`；median_Z是辅助项。静态两组median深度MAE分别约2.96cm，动态原始/动态Lambertian分别约9.75/8.97cm。本报告不为每组挑选更小的depth类型。

GT全前景为alpha≥0.5且命中网格；仅布料区域由首次命中物体ID `Falling_Cloth` 确定，不能凭模型颜色推断布料。内部区域另以GT alpha≥0.99内缩2像素报告。预测alpha≥0.5且法线/深度有效的交集计算条件MAE，并保留GT定义的覆盖率。

动态预测使用每帧真实time；未沿用静态NVS的固定timestep0001，也不需要BVH首帧复用、BRDF或间接光。首/中/末12组相机上，专用几何和albedo渲染与原版渲染器核验通过，最大几何差约1.28e-7；另将动态time故意固定为0核验，六个动态样本的alpha/深度均发生变化，确认动态time实际参与前向计算。这个故意错时刻的诊断不参与最终评分。
