# Stage2损失组合与动态PS失效机制审计

## 审计结论

本轮Stage2实际执行的是自定义A+PS物理训练入口，不是原生LumiMotion训练器简单续训。源码、保存配置、优化器状态、四次PS缓存及终点TRAIN求导相符；没有发现PS漏接、权重未生效或几何组完全不更新。

**主要机制限制已定位：动态形变运输假设大量失效，动态PS几乎没有直接监督；环境分量占据大部分预测，生成PS时又扣除该环境估计；阴影可见度停止梯度。** 这些事实能够解释为什么方向更准确仍只有微小几何收益。各因素的独立因果贡献尚未通过新训练消融分开；本次不启动新训练、不修改loss或权重。

## 实际loss组合

实际训练快照：`output/1019-58-LH-dynamic-jumpingjacks-ELDL-V3-两阶段PS总控/snapshots/formal_stage2_v1/LIHAN/scripts/dynamic_v3_train.py`，与当前LIHAN相应源码SHA相同。第199行：

\[
L=L_{photo}+0.02L_{normal}+1000L_{dist}+0.001L_{local}+0.02L_{PS}+L_{light}.
\]

| 项 | 真实定义 | 说明 |
|---|---|---|
| 光度photo | 前景Charbonnier +0.1背景Charbonnier +0.1亮区附加Charbonnier +0.1 Alpha BCE | 线性RGB，不是L1+SSIM；亮区为sigmoid软加权，使用全前景分母 |
| normal，权重0.02 | GT Alpha内缩区域内，单位GS法线与Expected Depth法线的1-dot | 两个预测量自一致，未用GT法线 |
| dist，权重1000 | 光栅器rend_dist的全图均值 | 是射线深度畸变正则，未用GT深度 |
| local，权重0.001 | canonical邻边相对长度/位置偏移，后半程附加相对Stage1的形变XYZ偏移 | 保持局部结构与父模型的弱正则，不是完整时间光流或轨迹监督 |
| PS，权重0.02 | canonical GS轴与detach伪法线、当前Depth法线与运输后detach伪法线的1-dot平均 | 由真实多时刻观测独立求目标，按confidence、有效观测加权；动态/静态共用一个分母 |
| light | 0.1 mean‖delta‖² +0.01 mean‖delta[t+1]-delta[t]‖² | delta是单位方向相对投影初值的改变量；平滑改变量，不直接抹平初始离群方向 |

Charbonnier的epsilon=0.02，定义sqrt(error²+0.02²)-0.02。饱和通道先将预测减观测残差截为min(error,0)：预测达到饱和值后不再惩罚过亮；Alpha仍有独立BCE。

原生Stage1入口`scripts/train_stage1.py:149`使用L1与DSSIM混合，外观由原生SH/动态颜色表达。本轮物理入口用override_color将着色替换为rho/π乘环境及Lambert直射，rho灰色、SH零系数起步，原生颜色字段及颜色头冻结。因而Stage1与Stage2比较同时涉及外观模型和loss变化；新旧DIR Stage2之间则保持这些设置一致，只换初始灯向。

部分记录字段（如normal_weight、distortion_weight、lambda_dl、alpha_weight、deform_lr_fraction）在实际执行处以相同数值的字面量实现，不是所有config字段都被动态读取。本次实际数值与计划一致，后续若调整这些字段，须同时核对执行语句。

## 生效日程与停止梯度

| 步数 | 直射颜色系数 | 主要可更新组 |
|---|---:|---|
| 1～540 | 0 | rho、SH；D/灯向不贡献直射光度梯度，几何冻结 |
| 541～1350 | 0.5 | rho、D；SH冻结，几何与灯向冻结 |
| 1351～4050 | 0.5 | 加canonical XYZ/rotation/scale/opacity及灯向lr=1e-5，PS开始作用 |
| 4051～8100 | 0.5 | 再开放小学习率形变，终点deformation lr=8e-8 |

1350/4050/5400/6750刷新PS，3000/6000重置opacity，随后各200步阻断normal/PS到opacity的梯度，保留photo梯度及opacity恢复lr=0.05。没有新点增密或split。SH在1350与8100保存值逐位相同，541起冻结由绑定源码及日志支持。

直射表达为`rho/pi * D * V * max(n dot L,0)`，A路径完整颜色为`EL + 0.5*DL`。0.5是前向渲染系数，不是额外loss。全场景当前G_t每次都重建BVH，但visibility的build/trace在no_grad下执行；因此光度loss不能穿过阴影可见度去移动遮挡物修正投影轮廓。仍保留法线点积、光栅位置/尺度/opacity等其他梯度，不能说几何完全没有梯度。

## 证据一：动态PS的运输检查几乎全部失败

各次采样均有1024条模型动态候选，并非没有采动态点。末次6750：

| 阶段 | 动态分组结果 |
|---|---:|
| 相机有效观测，点×时刻 | 26368 |
| 正Jacobian行列式后 | 15411 |
| 条件数<20后 | 12140 |
| 伸缩界后 | 11690 |
| XYZ切平面法线与独立旋转头一致至20°内后 | 2661 |
| 有限surfel弦相对误差<0.2后 | **104** |

104/26368仅0.3944%。以轨迹计，755条动态候选原有至少6次相机有效观测，运输检查后仅6条仍有至少6次，PS秩/残差/可靠性检查后只剩3条。四次刷新可靠动态轨迹依次0、3、2、3；末次静态可靠577条。

动态有效相机观测的法线一致性cos中位0.5235（约58.4度），有限弦相对误差中位1.744，远超门槛0.2。这说明当前XYZ形变场的局部延拓和原生独立rotation头不提供一致、可靠的物质表面运输。Jacobian在点云外的延拓也不等同真实皮肤/衣物形变，不能把这些拒绝直接解释为真实人体拓扑翻转。

这些检查本身用于拒绝不可信伪法线；本轮loss没有直接强制XYZ Jacobian与rotation头及有限尺度surfel一致的项。因此，简单增加PS权重或放宽阈值无法补足可信动态目标。

## 证据二：环境占比高，扣除后大量动态残差为负

在终点TRAIN1、81、86、149四帧，用线性渲染辐亮度求和得到：

| TRAIN帧 | 模型动态区域EL占比 | 实际0.5 DL占比 | 有效动态PS轨迹/帧 |
|---|---:|---:|---:|
| 1 | 94.51% | 5.49% | 0 |
| 81 | 97.48% | 2.52% | 0 |
| 86 | 93.92% | 6.08% | 1 |
| 149 | 94.86% | 5.14% | 1 |

这是模型渲染分解，不是GT能量分解；强补光场景本身也可能有较大EL，不能仅由占比断定应强迫增大DL。

但A路径PS明确用`I_observed - stopgrad(rendered_EL)`作为直射残差。末次动态相机有效观测通道中59.34%残差为负，通过运输的104条观测中60.26%通道残差为负，求PS时均不能进入有效光度拟合。即使只看可靠3条轨迹对应的55个时刻观测，也有51.52%通道残差为负。

同一动态相机有效观测的通道饱和率仅2.38%，静态为40.97%；当前动态链路的大量损失首先发生在运输和EL残差层，不能笼统归咎于全场景饱和。此通道统计与此前原800图像“任一RGB通道满码像素比例”定义不同，不可直接相减。

环境在前540步直射关闭时单独拟合，随后冻结SH，PS又依赖扣除它，形成相互依赖的估计问题。当前共享SH环境是E(n)，不显式表达位置依赖；数据含两个POINT补光源，动态人体运动时的补光变化未必能由同一E(n)正确解释。这是模型表达限制，独立因果量需受控实验进一步确认。

## 证据三：梯度存在，但动态PS的有效贡献很小

固定1/81/149帧，并按TRAIN动态目标有效性增加86帧；没有读取DEV、TEST或GT法线/灯向，也没有optimizer.step。按真实权重对每项分别求导：

| TRAIN帧 | photo对XYZ梯度范数 | 全部0.02 PS对XYZ | 动态分组0.02 PS对XYZ |
|---|---:|---:|---:|
| 1 | 0.62377 | 0.01385 | 0 |
| 81 | 0.53281 | 0.06829 | 0 |
| 86 | 1.32989 | 0.21334 | 0.000419 |
| 149 | 0.70163 | 0.03139 | 0.001765 |

86/149帧动态权重仅占该帧PS总权重0.169%/0.181%。动态PS对XYZ梯度范数为photo的约0.0315%/0.2516%。完整PS及其他光度项确实能作用到形变共享参数，不能把“动态目标缺席”误写成“所有动态参数梯度都为零”。这些只是少数终点帧的欧氏梯度，不代表Adam实际更新量，也不是完整训练轨迹的因果消融。

末步原训练日志的加权loss：photo0.035109、normal0.002165、PS0.000465、dist0.000130、local约0.00000204、light约0.00000837，总约0.037879。dist虽然系数1000，实际标量约1.3e-4；仅凭系数大小不能认定它压制了全部训练。normal只保证两种预测自一致，无法独立纠正共同偏离真值的方向。

## 对后续修改的优先级建议

1. 优先修复或重新建立可信动态表面对应/法线运输，使XYZ形变、surfel rotation和有限尺度表面一致；先用TRAIN验证动态有效轨迹和空间覆盖，不用GT放宽门槛挑结果。
2. 独立审查EL/DL/材质分解和PS残差，减少“只拟合EL后冻结、再从总亮度扣除EL”的偏置；考虑符合点光位置依赖的表达。目标应是观测解释和可辨识性，不是人为强制固定DL占比。
3. 在这些条件成立后再调PS/几何/结构项；若恢复SSIM等结构约束，须与线性域、饱和规则和Alpha边界处理一起验证。当前不能只调大0.02就声称可恢复动态人体。
