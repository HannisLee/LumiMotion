## 一、结论摘要

1. EL基准 GS 3.50676425° / Depth 7.35467544° / Mesh 5.45750273° 真实来自 `output/1011-02-LH-static-jumpingjacks_EL_V2-原生LumiMotion两阶段`、`model_mlp` @35000（原生Stage1，135训练帧，resolution=2），指标文件 `evaluation_35000/normal_depth/metrics.json` 的 `summary.foreground.normal_metrics.{gs_render,depth_normal,mesh}.mae_pixel_mean_deg`，值 3.5067642547619093 / 7.3546754396285285 / 5.457502725041595。我从其保存的15帧预测数组独立复算GS，得 3.5067642547619093（逐位一致，coverage 0.9991693294273357，缺失180° 3.6533719919697805）。
2. EL-V2与ELDL-V3 **几何与采样严格一致**（相机、静态姿态、尺度、GT法线逐帧数值一致；前景掩膜仅有0.05%像素的边缘差异），但 **照明、RGB位深/训练输入、time编码均不同**。因此EL对ELDL是“同几何同视角、不同照明与训练输入”的跨数据集比较，不能称严格受控的照明消融。
3. 历史协议SHA `7cf1e7f6…1646be` 对应 `output/archive/1011-08-…DL_V2-Goal评测协议/protocol.json`，绑定DL_V2路径与3.51/7.35/5.46阈值，**不能逐字用于本任务**；但其度量数学（`utils/geometry_eval_utils.py`、`scripts/eval_geometry_gt.py`、`utils/predicted_mesh.py` 的SHA）与EL metrics.json及本任务V3评测入口完全相同，故“数学适用、文件不适用”。本任务以V3固定协议（1019-02）+ 本文冻结扩展为准。
4. 在V3 GT上对EL重评分：GS条件MAE 3.5096196°（相对历史值+0.00286°，来自V3与EL-V2前景掩膜相差182像素），coverage 0.99890，固定分母缺失180° GS **3.7037251°**。冻结可比EL参考同时保留历史值，门槛取更严者。
5. B00原生Stage1@35000（用了全部135 TRAIN，含将来DEV帧，且带MLP形变头）在同协议下GS 4.7008°，与1019-02既有评测逐位一致（全部分区/方法最大绝对差0）。
6. **关键事实**：平台占评测像素约82.5%、人体约17.5%、鞋足约1.2%。EL的GS 3.51°由平台1.39°与人体13.50°合成。仅看总体GS会被平台掩盖人体退化，故DEV规则加入人体/鞋足门槛。

## 四、冻结的评测协议（任何候选出现前）

以下规则固化于 `PROTOCOL_1024_FROZEN.json`；数学、掩膜与分母沿用1019-02协议（SHA `c3da32dc…`）。

- **GS法线坐标系**：世界坐标Blender着色Normal EXR（Normal.X/Y/Z，float32）对光栅化归一化混合surfel法线，400×400。
- **朝向**：有向角 acos(clip(dot,−1,1))，不取abs；acos(abs(dot))仅作无向辅助。
- **前景/掩膜**：albedo Alpha（16位面积缩放）≥0.5 ∩ GT ray hit ∩ GT有效Normal。预测可见=预测alpha≥0.5。内区为Alpha≥0.99腐蚀2像素（仅辅助）。
- **缺失处理**：预测alpha<0.5或法线无效视为缺失；条件MAE不含缺失；固定分母MAE以全部GT前景像素为分母，缺失计180°。
- **主指标**：像素加权MAE。帧等权（含缺失180°帧等权）仅供审计，不与主指标混用。零有效帧保留在缺失惩罚内并列出缺帧。
- **Depth Normal**：expected Z反投影中心差分，支持=预测可见∩GT前景3×3腐蚀。**Mesh Normal**：仅用模型实际训练相机（FIT117或TRAIN135）的预测expected深度TSDF（voxel 0.02，trunc 0.08，depth_trunc 20，alpha 0.5），首次射线交点法线；DEV不重建Mesh（Mesh列未评测，非通过）。
- **RGB**：黑背景合成16位RGB，AREA至400×400，PSNR帧均值与Alpha IoU；SSIM/LPIPS当前入口 **未实现**，如需另行补充。
- **分区**（评测时才使用GT语义/object标签）：human（6个人体网格）、leg、foot、shoe、footwear(foot∪shoe)、platform、human_other、object_00…07；互斥完整覆盖，每分区报告GT像素份额、三法线coverage与缺失180°、Alpha覆盖、深度保留率。
- **GT仅评测使用**：不进入训练监督、初始化、正则或模型选择之外的任何路径；DEV帧不在FIT117训练内，DEV/TEST渲染所需光方向用FIT117方向nlerp，不读DEV/TEST的GT方向。
- **EL参考**：历史值（3.50676425/7.35467544/5.45750273，coverage 0.99916933，固定分母3.65337199）与V3 GT重评（GS 3.50961960，coverage 0.99890019，固定分母3.70372505）并列；通过门槛取更严者，历史GS 3.50676425不得放宽。

## 六、冻结的DEV选择规则

**主选择指标P**：DEV前景GS固定GT分母缺失180°像素加权MAE。持平容差0.03°（历史同路线相邻保存点差0.0045°视为无意义，机制对照差0.1–0.27°为真实）。条件MAE与coverage必须同表给出，帧等权仅审计。

**资格门槛**（相对本血统父模型/同阶段上一级；Stage1自身只记录）：

| 门槛 | 要求 |
|---|---|
| 前景GS coverage | ≥ max(0.9985, 父−0.0005) |
| 人体GS固定分母MAE | ≤ 父 + 0.10°（平台改善不得换取人体退化） |
| 人体GS coverage | ≥ 父 −0.002 |
| 鞋足(footwear) GS coverage | ≥ 0.99 且 ≥ 父 −0.005 |
| 鞋足 GS固定分母MAE | ≤ 父 + 1.0° |
| 鞋足/人体 Alpha覆盖 | 鞋足≥0.99且≥父−0.005；人体≥父−0.002 |
| Depth Normal条件MAE | ≤ 父 + 0.5°（崩溃检查，不用于选优） |
| RGB | DEV黑背景PSNR帧均值不比父低2 dB以上，Alpha IoU不比父低0.001以上（DEV光方向用FIT117 nlerp，不读DEV GT方向） |

**选择流程**：只有满足全部门槛的预定保存点有资格；单一checkpoint，不拼接；P最低者胜；与次优差<0.03°视为持平，持平时依次比较人体固定分母GS、footwear固定分母GS、更早保存点/更少新增更新。声称优于对照（≥0.03°）要求18个DEV帧中至少12帧的帧级固定分母GS同向改善，并报告帧自助法90%区间供参考。必须报告 P=平台份额×平台P+人体份额×人体P（+其他）的分解，并单列人体和平台改善量。TEST只对DEV选出的唯一checkpoint跑一次，不得因TEST回头改选；旧TEST已被查看，非全新盲测。

**最终TEST完整验收**：基本目标=GS条件MAE严格低于EL（历史3.50676425，且低于V3重评3.5096196）与本轮Stage1，固定分母GS严格低于EL V3口径3.7037251与Stage1，coverage ≥ max(0.9985, Stage1−0.0005)；进阶目标=条件MAE ≤2.50676425°（同时单列是否≤2.5096196°）。GS/Depth/Mesh必须同一checkpoint。出现鞋/足可见消失、腿孔洞等退化即完整验收FAILED，即使GS达标。

**四类目检检查项**：
- RGB：饱和/过曝及高光、阴影与材质块、碎片或漂浮Gaussian、背景污染、与GT同视角有无缺失。
- Alpha：人体轮廓完整、腿足鞋无孔洞或消失、平台与人体粘连（不得以Alpha覆盖证明鞋体恢复）、边缘漂浮点。
- Normal：朝向未翻面（与GT同号）、人体边缘与鞋足法线、平台平整无噪声条纹、同帧GT对照。
- Separation：静态下为常量或继承门控，只记录语义，不声称学到分离；检查有无不应出现的语义混入。
- 代表帧：DEV 61/75/79；TEST 10/80/150及前150/侧130/背10；鞋足crop由固定GT分区计算。必须实际打开图片，未目检不得写PASS。

## 七、风险与待办

1. 新Stage1（117帧、从头、静态配置）极可能高于EL与B00：B00用135帧、MLP形变，GS已4.70°。若新Stage1亦如此，“低于EL”需要几何阶段本身贡献约1–2°，与GOAL一致；不得通过换分母/掩膜降低难度。

4. 平台占82%像素：同一EL参考下，若平台已达≈1.4°，总体2.5°的进阶目标几乎只能靠人体（EL人体13.5°）改善；必须据此分解并报告。
