# 未知主光表面轨迹初始化对照与模型偏差

日期：2026-10-15；主机 ushas；环境 lumimotion-ushas。对应方向一 Goal 的 T02。

**本轮完成静态／动态两场景各三种未知光初始化及一个GT光向参考，共8组、4800次实际Adam更新。未知光最终平均方向误差仍约40—44°，没有获得可靠自标定证据。工程运行与checkpoint恢复PASS，科学目标FAILED，完整Goal保持ACTIVE。**

## 协议与结果

共同默认Stage1@35000；每场景8192个体素代表点；从原135训练时间固定预留15个用于Stage2开发验证，其余120个优化共享材质、世界主光及正能量。Stage1已见过这135帧，因此不能称全流程独立测试。600次固定终点，无中间checkpoint选择。所有GT方向评测在训练之后独立进行；oracle为隔离参考，未回灌未知光。

## 证据说明什么

1. 粗法线＋RGB及SH辅助的初值均比随机初值好。SH辅助进一步改善了初值，但最终收益基本消失；动态保留时间SH辅助由重建初值39.349°变为43.747°。这支持将SH视为辅助初始化，不支持“SH已解决主光恢复”。
2. 错误未知光解的光度目标比固定GT方向更低：静态参考0.111235、未知RGB组0.059789；动态参考0.151668、未知RGB组0.078895。当前目标不偏好真实灯向，继续仅降低这个目标不等于恢复更真实光照。
3. 上一条说明当前表面与着色近似存在需要诊断的偏差／歧义，不能单凭它断定唯一原因。初版没有光源阴影、环境和镜面；代表点也不保证是同一物质表面。下一步必须分别检验可见性与对应误差，暂不将这些估计灯向用于几何解冻。
4. 训练节点平均相对能量在1e-6内为1，8组保存恢复最大预测差均为0。独立模型契约验证通过单位方向／插值端点／能量规范／饱和下界梯度检查。它们只证明实现基本契约，不证明模型物理正确。

## 观测支持与目检

静态共有269313条有效观测，60.003%至少一个通道饱和；动态261419条，60.252%饱和。初始化只用未饱和支持，正式拟合保留单侧饱和约束。全局未饱和法线二阶矩最大特征值占比约0.773／0.807，观测明显集中于一个法线方向；全局谱不等于逐帧或每个表面的可辨识性。

每个代表点有效时间数的中位数为静态3、动态5；其中至少5次支持的点分别3974与4149。静态点相对首次可见位置的位移P90仅约2e-6世界单位，但P99约0.214；无向法线变化P99约17.39°。因此静态大多数轨迹近乎固定，少量轨迹有明显伪运动，不能把整组失败简单归因于“全部对应都错”。动态位移和法线变化同时包含真实运动，不能直接解释为错误。

已实际查看两套cache/contact.png：四类默认渲染仍显示平台法线起伏、Alpha与足部完整性不能等同、阴影影响动静分离；采样覆盖偏向平台。实际拟合预测另见各组sample_prediction.png，它们只显示采样点，不是完整重渲。几何、足部、测试15帧三法线和网格指标均未执行，本轮不能宣称几何改善。

另外已实际查看两场景RGB初始化与oracle的sample_prediction.png：未知光组在台面投影阴影处仍有明显残差；oracle残差还分布于较大范围台面。该观察支持进一步区分遮挡与其他模型偏差，但没有证明仅加入阴影就足以解决问题。random／sh_aux的采样点图已生成，未逐张人工检查，不把它们写成全部目检通过。
