# 静态 DL 两度目标：G2-T01 至 T06 与脚部机制归档报告

日期：2026-10-12（Asia/Tokyo）。主机 ushas，环境 lumimotion-ushas。本报告结束本轮实验与诊断；原始训练、评测、失败冒烟、日志和检查点均保留。新 Goal 的 GS Normal MAE <2.00° 尚未达成。

## 固定范围与验收

训练仅使用原静态 DL 的135张训练 RGB、自身 Alpha、原相机及对应 GT 光方向。GT 法线、深度、材质、阴影、能量和语义对象仅用于离线诊断或固定评测。正式数值来自原15张测试图（10、20、……、150），使用原掩膜和有效像素加权 MAE；协议 SHA256 为 7cf1e7f6e1ce7f223319899febdfb1d443440add68cddee191fe5bf47e1646be。三项数值须来自同一检查点，且要检查鞋尖、脚掌是否完整。

新 Goal 的同模型门槛为 GS <2.00°、Depth ≤5.8876060528°、Mesh ≤4.7507435938°，并且足部无明显短缩或塌低。低于旧静态 EL 的 3.51°／7.35°／5.46°不等于本 Goal 通过。历史 T13 数值达成旧目标，但后续审计确认脚部三维支撑缺失。

## 足部消失机制与本轮验证

早期独立审计在 T14@9000→10000 观察到鞋部高度带 Gaussian 中心 2240→0；9000步保存发生在重置前。模拟重置并遍历135张训练图后，法线一致性项对足部 opacity 的梯度常推动其降低，绝对量为其他三项之和的17.49倍。透明度重置上限和低透明度裁剪阈值均为0.01；脚后的台面仍可填满合成 Alpha，无法保护内部鞋面。这解释T14的突然损失，但T13@5000已经严重缺脚，不能把其最早失效精确归到9000重置。证据见 LIHAN/DOC/报告/1012-02-近期训练脚部消失审计报告.md。

T05／T06从相同T03@14000起步，训练2000次并跨过15000自然重置；之前均保留 normal→opacity 梯度，T06仅在15001起阻断。UID重放显示重置后低透明度过滤分别删除14832／2112点，首次15100分别为14648／251点；增密出生与split父点替换另列。预重置预测高度0.05<z<0.35的2422／2430个UID根中，终点完整灭失的谱系分别为1042／253。高度队列不是GT语义鞋，全场景删除数也不是鞋部删除数；两独立组重置前已有31点差异，不能声称逐位确定性因果。

T06相对T05的全局GS、Depth、Mesh分别低约0.26876°、0.09379°、0.23375°，支持梯度路由影响真实拓扑与结果，但收益主要落在平台和衣物。同一GT对象4鞋区6185像素上，T05三法线约20.1225°／27.5397°／28.6812°，T06约21.2039°／27.7434°／30.0599°；T06鞋expected同射线2厘米内比例从60.82%升到65.00%，三项鞋法线却略差。10／80／150目检仍见鞋尖短缩，鞋区Alpha覆盖100%不能证明鞋体存在。两实验输出的 evaluation_16000/FINAL_REVIEW_COMPLETED.json 与 topology_diagnostic/summary.json 保存完整证据。

## 固定T06的零更新候选诊断

T06@16000只读遍历原135训练帧、4,494,614个原法线掩膜像素，检查expected与median深度差能否提示法线项和RGB的梯度冲突。进程exit0，来源、checkpoint、参数、输入和CPU/CUDA随机状态未变；未创建优化器，没有参数更新或新MAE。完整命令、日志、数组和结果：output/1012-12-LH-static-jumpingjacks_DL_V2-G2-预测深度混合法线梯度零更新诊断；训练记录：LIHAN/DOC/训练/1012-10-LH-static-jumpingjacks_DL_V2-G2-预测深度混合法线梯度零更新诊断.md。

τ由训练相机范围预设为0.00858005米。深度差>τ的像素占14.28%，承担96.54%的法线自一致性残差。这说明残差集中，不能证明这些梯度有害。该档XYZ负内积视角为38/135，低差档为67/135；原始四元数为56/135对44/135，没有一致增强的冲突。候选权重使逐视角法线梯度范数降至原来的XYZ 0.246、四元数0.193，潜在效果难与大幅减弱法线约束分开。按预注册门槛，**本轮否决直接开展置信度调权训练**，不据此调τ或权重下限追分。诊断执行PASS，科学假设未获足够支持。
