# 材质冷启动对照的机制与最终效果预先判读

2026-10-19；ushas / lumimotion-ushas。本报告只读报告61、68及训练19、20，在未读取M08/M09训练结果、机制数值或任何GT/TEST评测的情况下冻结解释边界。主控已告知两组正式启动及149/149初始控制核验通过；本报告不将该告知扩写成自行完成的新验收。没有修改代码、参数、预算或运行计划，没有启动训练、诊断或扫描。

## 本轮检验的两层问题

第一层是启动机制：SH颜色清除后，统一灰DC造成的初始光度不兼容，是否通过允许几何同步更新而影响早期预测演化；固定几何材质预适配能否改变这一过程。第二层是最终策略：在相同24000物理步后，这一干预是否提高法线与完整几何质量。第一层的部分证据不能替代第二层，第二层有收益也不自动证明第一层的全部因果链。

固定对应关系为M08对M06、M09对M07。每对共享同一父四几何及点序、其他属性、旧固定光、正式目标、相机处理、相对日程、新Adam及共同随机初态，初始独立变量仅为预适配DC。比较必须先在每对内部完成，再完整报告两对是否一致。M08对M07或M09对M06不是材质单变量对照；两父差异不能用来事后选择初始化。

保留训练19全部共同门槛：预适配两父共同通过才进入正式，固定末点而非最低中间loss，既有≤1%门槛只用于预适配末期预算检查。本文不把该1%移作几何收敛、photo收益或最终精度阈值，不新增百分比成功线、综合分数、显著性标准或“最好父即可通过”的例外。

## 五个节点的待观察量及解释

四模型均使用完整135已见TRAIN、V2的no_bg=True目标及固定原Alpha支持。每节点报告等帧photo、Alpha IoU、固定源前景有效深度覆盖、点数、V模式；各相邻区间同时报告共同有效覆盖、expected-Z变化、signed GS法线变化，以及原固定分母的缺失180°和相对深度缺失1惩罚。不能只展示共同有效像素上的较小MAE而省略支持丢失。

| 固定节点 | 主要观察及可支持结论 | 不可据此主张 |
|---|---|---|
| 0 | 在相同几何下，候选photo与对应灰材质控制之差衡量实际初始光度兼容；几何/覆盖应沿用同父初值一致性证据。 | photo下降是预适配拟合过的目标，不是新验证，不证明真实albedo或更准几何。 |
| 1000 | 两对同为无V，比较0→1000的几何预测变化及覆盖，观察初始DC干预是否改变早期轨迹。这是五点中最直接的早期窗口。 | 较小漂移不等于更准确；该阶段已允许原拓扑操作，不能宣称只隔离了某一种几何梯度通道。 |
| 3000 | 按原opacity reset后的瞬时保存解释，完整显示photo、覆盖和缺失惩罚；同节点成对差异可描述处理对reset响应的影响。 | 不能把跨到3k的覆盖突降直接归为材质失败、永久几何崩塌，或把候选较高覆盖直接当最终几何改善。 |
| 5000 | 按恢复过程后且V首次启用的冻结状态解释。成对比较表明处理效应在共同V日程下是否仍可观察。 | 3k→5k photo下降同时含reset恢复、继续优化与V启用，不能单独归因于材质；这里不是“已经接受5000步全BVH训练”。 |
| 24000 | 固定预算末点，完整比较TRAIN兼容、覆盖及相邻5k→24k预测变化；结合原定晚期五点稳定性诊断描述终末行为。 | 5k→24k累计变化不是晚期收敛速率，也不能与0→1k不同长度区间直接比较；TRAIN稳定性不是GT准确性。 |

报告68已经显示原M06/M07在3000的固定源覆盖约为0.00201/0.34562，到5000约恢复至0.99769/0.99740。该历史事实足以要求reset解释边界，不能据此删3k节点或新增有利的恢复节点。两个控制0→1k的共像素Z/GS变化不同，也只能说明父起点不同下轨迹不同，不说明短父一定受冷启动伤害更重。

需要区别“共同事件”与“处理效应”：reset、V启用及其他原日程在同一父的处理/控制中相同，成对差异仍可能是初始DC干预经opacity、拓扑或材质演化产生的间接结果；不能把这些差异全部排除为无关噪声。但单看一个模型跨3k或5k的变化，无法把共同日程效应与材质效应分开。五点也不能估计精确恢复时长或拆分每条中介路径。本轮不为解决这种解释限制临时增加优化、反向或节点扫描。

当前机制脚本直接输出相邻区间变化，不能把其0→1k、1k→3k等值误写成“每个节点相对step0的累计漂移”；也不能把相邻绝对变化相加当作0→24k的净变化。不同模型的共同有效像素集合可能不同，因此共像素均值须连同固定分母惩罚和覆盖解释，不能当成严格同像素质量排序。

## “早期改善”的用语限定

若两父均具有更低初始photo，且到1k出现同方向的photo/几何轨迹变化、覆盖未靠丢失困难像素换取，可以支持“预适配提高初始兼容，并改变早期优化路径”。其中较少漂移至多表示对既有SH几何保持更多，不证明这些被避免的变化本来错误。只有photo降低而几何路径没有相应差异，只支持外观适配，不支持几何冷启动机制是主要问题。

若较小共像素漂移伴随更差覆盖或更大缺失惩罚，不能称为早期几何改善。若两父方向不同，应如实报告起点依赖；不能只汇总平均收益、只展示有利父，或按事后GT挑选长/短预热。

本轮一个固定随机种子及原控制复用可以提供受控处理证据，但没有估计跨种子方差。不能把任意微小正负差异写成统计显著，也不能据此添加后验容差；报告实际幅度、分区和可视化证据即可。

## 最终外评及停止/继续条件

当前两处理继续原固定24k及已登记后流水线，不因中途photo、3k低覆盖或某父暂时更好而提前停止、延长或换参数。实际工程异常按已有运行/验收规则处理；若来源、更新、保存或评测不完整，应先写工程未完成，不能用缺失结果作科学否证或只放行一父。

最终只依据训练20已冻结的24k协议：法线、expected/median深度、原固定分母及缺失惩罚、分区与覆盖、TRAIN-only TSDF mesh、完整四类图像/视频和正侧背腿足实际目检。两对同口径报告。photo、PSNR、较小漂移或单一均值不能替代“法线与完整几何”目标；也不把18旧开发或135已见TRAIN称为未见数据。本文不读取外评或为外评新增门槛。

| 完整结果模式 | 允许的结论 | 本轮处置 |
|---|---|---|
| 初始photo下降，但两父早期几何演化和最终外评均无一致收益 | 完成了材质拟合，未支持冷启动为当前主要几何问题。 | 按训练19停止该策略；不扫预适配时长/lr，不选中间点，不单独保留有利父。 |
| 两父初始兼容和早期轨迹均出现一致有利证据，但最终完整几何无一致改善 | 可支持“初始适配有效/早期轨迹受影响”，不能证明早期更准确；作为本轮24k最终几何策略未获支持。 | **机制的部分成立不挽救最终策略失败。**停止本分支，不凭早期信号追加预算或改Vstart/reset。 |
| 两父最终完整几何均有一致收益，且早期证据方向相符 | 支持这一固定预适配初始化方案，并与冷启动解释相容；不证明光照/BRDF正确或全部误差来自冷启动。 | 可提出有限独立复核/复现实验，由主控在用户已授权的GOAL范围内制定下一轮控制变量和预算；本文不触发额外训练或扫描。 |
| 两父最终完整几何均有一致收益，但五点未给出早期机制证据 | 支持固定初始化策略的结果收益，冷启动具体路径仍未建立。 | 可以把策略复核与机制未定分开报告；不得倒写早期机制已验证。 |
| 仅一父受益、另一父无益/受损，或法线与完整性之间存在实质冲突 | 至多是起点依赖或指标权衡，不能宣称双父一致改善或普遍策略成功。 | 按既定共同解释停止扩展，不根据外评选父/调参数；保留全部反例。 |

“最终无一致改善”不是要求所有数字必须严格同号，也不是新造综合门槛；必须根据原协议的完整几何、覆盖、分区和目检证据陈述收益、损伤及不确定性。证据混杂时结论为不支持强成功主张，不能事后给某个指标更高权重换取通过。若尚缺完整外评，只能保持结论待定，不能先用TRAIN替代它作最终失败或成功判定。

即使初始和终末TRAIN photo更低而最终几何不改善，也不足以把原因唯一指向恒定EL、固定D、方向、V或BRDF。它只表明这次材质初始化干预未实现最终目标；本报告不据此自动重开历史失败灯候选、引入联合光几何或扩大模型自由度。

## 计算预算和证据边界

每父候选都有额外4050次材质预适配及原定回放，再运行与对应控制相同24000次物理更新。原控制没有这段预适配，故本轮是“相同正式物理预算、不同初始化”的干预，不是等总算力优劣实验。P00短/长父来自同一16k轨迹，不得把较长预热成本藏入免费初始化，也不得按“4050+物理步”的总更新数去错位对齐机制节点。

两父点数不同，预适配与正式一步的实际代价也不同；同更新数不等于同墙钟时间、显存或FLOPs。所有机制节点仍按相对物理步对齐。没有额外计算量匹配控制，本轮不能区分“分阶段预适配”与所有其他同算力使用方式谁更优，也不能宣称计算效率提升。
