# N0 GT-normal oracle 实验与下一轮建议

日期：2026-08-18  
服务器/环境：`garuda / lumimotion-garuda`

## 技术摘要

N0 oracle 在 CV3 和 CV3L 都通过。从各自 iteration 10500 的同一 checkpoint 分叉，固定 position、rotation、scale、opacity、deformation、albedo 和 GT light，关闭 RGB loss 与 normal-init prior，只用 Blender world-space GT normal 监督 independent normal。100 步后，CV3 平均角误差从 `25.5981°` 降至 `21.1359°`，CV3L 从 `24.8087°` 降至 `20.1739°`。

这证明 independent normal 参数、deformation-relative normal、alpha-normalized raster map、GT EXR 坐标口径和离线 evaluator 是可导且可恢复的。原来 RGB-only normal 退化的根因应转向光照建模、单方向 Lambertian 的可辨识性和 RGB 梯度方向。

## 实验设计

- 起点：CV3/CV3L iteration 10500。
- 终点：iteration 10600。
- normal LR：`1e-3`。
- GT-normal cosine loss 权重：`1.0`。
- photometric RGB loss 权重：`0.0`。
- normal-init prior：`0.0`。
- 有效 mask：GT normal 非零且 rendered alpha `>=0.5`。
- 评估：120 帧 world-space normal 离线评估。

## 定量结果

| 数据集 | iteration | mean | median | P95 |
|---|---:|---:|---:|---:|
| CV3 | 10500 | 25.5981° | 15.8961° | 74.9210° |
| CV3 | 10600 | **21.1359°** | **10.6208°** | **69.7788°** |
| CV3L | 10500 | 24.8087° | 18.4963° | 65.8672° |
| CV3L | 10600 | **20.1739°** | **13.2747°** | **61.4648°** |

checkpoint 对比显示，两个数据集的 position、rotation、scale、opacity 和 albedo 最大绝对变化均为 0；只有 independent normal 变化。梯度审计中也只有 normal 的 `LR × gradient` 非零。

## 下一轮建议

### 1. N1：RGB 梯度与 GT-normal 方向对齐审计（最高优先级）

在与 N0 完全相同的冻结条件下，同时求取 RGB loss 和 GT-normal oracle loss 对 independent normal 的梯度，统计：

- `cos(g_rgb, g_gt)`；
- `g_rgb · (n_gt - n)` 的符号；
- 布料、椅背、椅脚、平台和灯板的分区结果。

若大量像素/帧的梯度夹角为负，就直接证明当前 RGB 模型在把 normal 推离 GT。

### 2. N2：global lightdir 与 per-GS 近场光对照

用已知 Blender 光源位置只做 oracle，为每个 Gaussian 计算 surface-to-light direction，不强求将它作为最终部署模型。比较：

- fixed global direction；
- per-GS direction；
- 2–4 个 area-light 采样方向。

若 per-GS 显著改善 RGB-only normal，就确认光源离物体过近和空间方向差是主因。

### 3. N3：弱 GT-normal 权重扫描

若项目允许训练期使用 GT normal，扫描 `lambda={0.01, 0.05, 0.1, 1.0}`，同时保留 RGB loss。这不是用于证明 photometric stereo 可辨识，而是确定多少 normal prior 足以防止 RGB 把法线拉偏。

### 4. N4：多光方向/时序聚合

单帧单方向只约束 `n·l`。应在共享几何/法线的条件下，对多个光方向的帧聚合 loss，不再让每个时刻单独为错误 normal 找一个亮度解。

### 5. N5：alpha 边缘与遮挡分区审计

以 `alpha>0.9`、`0.5<alpha<=0.9` 和轮廓膨胀带分别统计 normal 误差/梯度。这可以分离实体内部的可辨识问题与 2DGS alpha 混合导致的边缘假误差。

## 建议执行顺序

`N1 梯度对齐 → N2 per-GS 光照 oracle → N4 多光聚合 → N5 alpha 分区`。只有在方法允许 GT normal 监督时才执行 N3。
