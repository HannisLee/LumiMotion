# only_clothV3：从光强 1 到 5.5 的图像恢复报告

日期：2026-08-18  
数据集：`data/LH-data/transfer-dynamic/only_clothV3`  
服务器与环境：`garuda / lumimotion-garuda`

## 技术摘要

本次结论很直接：早期 Lambertian 实验把 `gt_point` 光源强度设为 **1.0**，真实的 Lambertian 渲染几乎全黑；问题不在“模型没有渲染到物体”，而在进入像素前的光照辐射量过低。随后以 120 帧 Blender GT 图像确定 directional 管线应使用的全局辐照度为 `5.5043499`，训练中取 **5.5**。采用固定 GT directional light、光强 5.5 并重新训练后，图像从近黑恢复为可辨识的灯板、椅子、台面和布料颜色。

这里的“恢复”指的是光照曝光尺度和 RGB 可见性恢复，**不**等同于 Stage 1 全部通过：5.5 实验的 normal 与 alpha 仍未通过严格验收。光强修复解决了“没有足够辐射量进入 Lambertian 像素”的问题，不会自动修复 Gaussian geometry 或 normal。

## 2. 光强为 1 时，真实发生了什么

0811 实验的训练设置是：

```text
light mode = gt_point
light intensity = 1.0
光源位置 = 每帧 Blender area light 中心的点光近似
```

该分支把 Blender area light 当作点光源。每个 Gaussian 接收到的量不仅会被 Lambertian 的 `/π` 缩小，还会再经过到光源距离的 `1/r²` 衰减。对 only_clothV3 的场景尺度而言，`1.0` 的源强度不足以支持正常显示亮度。

结果不是 alpha 消失或相机看错物体：在本次显式渲染中，椅子、圆台、灯板的位置和轮廓仍在；只是 RGB 辐射量非常低，经过显示转换后呈现为近黑图像。此时训练可以通过提高 albedo、修改 geometry 或 opacity 尝试吸收误差，但这些补偿不会把错误的辐射尺度变成合理的物理光照。

此前 0811 目录中存在亮的 RGB insight 图，但现已确认那次命令没有显式指定 `photometric_lambertian`，实际走的是默认 `original_sh`。因此那些亮图不能用来判断“光强 1 的 Lambertian 效果”。本报告中的左图是补渲后的唯一有效图像证据。

## 3. 发现的问题：不是颜色没有学到，而是辐射模型不匹配

从近黑的真实输出可以确认，早期参数把两个不同的光照语义混在了一起：

1. 数据中的灯是 Blender 的移动 area light；
2. 训练中使用的是“area light 中心作为点光源”的 `gt_point` 近似；
3. 该近似继续施加距离平方衰减，但源强度只设为 1；
4. Lambertian 本身还包含能量归一化；
5. 最终进入像素的有效辐射量过低，导致全局欠曝。

因此后续修复不再尝试靠提高 albedo 或让 Gaussian 旋转去“补亮”，而是先把实验目标明确为：固定每帧 GT 灯的**方向**，为方向光确定一个能让 GT 图像处于正确曝光尺度的固定辐照度，再训练场景外观。

~~~mermaid
flowchart LR
    A["0811：GT area light 中心\n近似为 point light，I=1"] --> B["/π 与 1/r² 后\n进入像素的辐射量不足"]
    B --> C["真实 Lambertian 图\n接近全黑"]
    C --> D["以 120 帧 GT RGB、albedo、normal、灯位\n确定 directional 的全局曝光尺度"]
    D --> E["标定值 5.5043499\n训练取 5.5"]
    E --> F["固定 GT directional light\n重新训练"]
    F --> G["RGB 可见性与曝光恢复\n但 normal/alpha 仍需独立验收"]
~~~

## 4. 光强 5.5 是如何确定和接入的

为避免再根据观感手调，后续在 only_clothV3 的 **120 帧** Blender GT 数据上，以 GT RGB、GT albedo、GT normal 和每帧 `lights.json` 灯位做统一曝光标定。得到的推荐全局 directional irradiance 是：

    5.504349875812332

训练参数取 `5.5`。这是方向光的辐照度缩放，不是 Blender 灯的原始功率，也不能直接填入 `gt_point`。

标定后接入训练的关键参数如下：

```bash
--render_mode photometric_lambertian \
--photometric_light_mode gt_directional \
--photometric_gt_lights_path data/LH-data/danamic/only_clothV3/lights.json \
--photometric_gt_light_intensity 5.5 \
--photometric_gt_light_color 1.0,1.0,1.0
```

完整 120 帧标定产物仍保留在：

- [最终标定 JSON](/mnt/workspace/users/han.li/lumimotion/output/0816-only_clothV3-coordinate-pipeline-audit/calibration_camera_facing/calibration.json)
- [最终标定 GT 对照图](/mnt/workspace/users/han.li/lumimotion/output/0816-only_clothV3-coordinate-pipeline-audit/calibration_camera_facing/eval_contact_sheet.png)

本报告不展开标定公式与坐标审计；相关细节见 [0816 坐标与标定复审](/home/han.li/reproduce/LumiMotion-perlight/output/0816-only_clothV3-coordinate-pipeline-audit/README.md)。

## 5. 标定为 5.5 后，图像质量恢复了什么

5.5 实验为 `output/0816-only_clothV3-lambertian-gt-directional-i5p5-free-geometry`。它将 GT light direction 固定后允许 Gaussian、deformation 与 photometric albedo 共同训练，最终的 RGB 训练/测试质量恢复到正常可优化区间：

| 检查点 | PSNR | SSIM | LPIPS | 解释 |
|---:|---:|---:|---|
| iteration 1 | 14.68061 | 0.80605 | 0.22764 | 已能产生可见 Lambertian 图，但外观尚未拟合 |
| iteration 10,000 | 36.31685 | 0.98598 | 0.03315 | 主体、颜色和光照外观已明显恢复 |
| iteration 30,000 | **40.74279** | **0.99384** | **0.02177** | 此实验的最佳 RGB PSNR |
| iteration 35,000 | 39.91180 | 0.99353 | 0.02040 | 最终保存 checkpoint |

从视觉和数值两方面，修复后的收益是：

- **曝光恢复**：不再是近黑图，主体各组成部分可见；
- **颜色恢复**：红色灯板、木质椅腿、深色坐垫与浅色台面可区分；
- **训练信号恢复**：RGB loss 不再长期处于“整体欠曝”的退化状态，PSNR 可稳定上升到约 40 dB；
- **光照责任更清晰**：每帧光方向由 GT 固定，不再要求 albedo 或 rotation 去承担全局亮度不足的主要补偿。

但不能把该结果写成“全部图像质量恢复”或“normal 已恢复”：该实验在 iteration 35000 的 world-space normal 平均误差仍为 `34.9066°`，且 alpha 存在欠覆盖和浮动条带，最终实验状态是 `FAILED`。这恰好说明光强 5.5 解决的是正确且必要的一项问题，但不是整个 Stage 1 的充分条件。

## 7. 对后续实验的结论

1. only_clothV3 的 fixed GT directional Lambertian 实验统一使用 `--photometric_gt_light_intensity 5.5`。
2. 不再使用 `gt_point + intensity=1.0` 作为 RGB/normal 质量基线；它属于辐射量不足的失败配置。
3. 不再采用历史 `2.9`；它只是早期标定过程的无效中间值，不应出现在后续实验命令或结论中。
4. 光强确定后，后续实验要把关注点转回 alpha、geometry 和 normal：它们是目前导致 Stage 1 未通过的主要剩余问题。

## 最终结论

`I=1.0` 的 point-light Lambertian 配置在真实渲染中近乎全黑；通过 120 帧标定后，fixed GT directional 的推荐值为 `I=5.5`。该修复让图像恢复正常可见曝光，并支持 RGB 质量提升到约 `40.74 dB` 的最佳 PSNR；但它不等同于 normal 与 geometry 通过验收。以后应把 `5.5 directional` 当作 only_clothV3 的可用光照基线，把后续工作集中在 normal、alpha 与几何约束上。
