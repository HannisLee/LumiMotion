# 前 500 步梯度与法线崩坏审计报告

日期：2026-08-16

> 2026-08-17 更正：旧版把“固定全部几何、仅训练 albedo”当作下一轮法线恢复对照。由于当前 `rend_normal`/Lambertian shading normal 均由 GS rotation（含 deformation rotation）产生，固定这些参数会使 normal 按定义不变。该对照只能验证冻结开关，不能验证法线恢复，也不能凭其 RGB 表现定位 lighting/material 矛盾。

## 结论

本次审计复现并细化了此前的法线崩坏现象。光照已固定为 120 帧 GT-derived world-space directional per-light，irradiance 固定为 5.5，light LR 全程为 0。因此本次崩坏不能归因于可学习灯光漂移。

法线并非在 iteration 500 突然恶化，而是在前 25 步已经明显偏离：平均角误差从 `23.24°@1` 增至 `34.54°@25`，随后达到 `38.46°@100`、`46.05°@200` 和 `51.66°@400`。iteration 500 略回落为 `50.25°`，但仍比初始值恶化约 `27.02°`。

同一阶段 rotation 平均漂移从 `1.18°@10` 增至 `19.62°@500`，P95 达 `55.92°`。前 500 步 deformation 尚未正式启用，densification 尚未开始，normal/distortion 权重均为 0。

## 逐损失梯度证据

51 个采样点的加权 gradient RMS 中位数如下：

| 参数组 | total | RGB-L1 | RGB-DSSIM | Alpha | Normal | Distortion |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| rotation | 5.618e-5 | **4.207e-5** | 2.227e-5 | 7.793e-6 | 0 | 0 |
| position | 1.228e-4 | 5.003e-5 | **7.467e-5** | 3.802e-5 | 0 | 0 |
| scale | 1.218e-5 | 6.153e-6 | **6.731e-6** | 3.115e-6 | 0 | 0 |
| opacity | 2.907e-6 | **1.281e-6** | 8.017e-7 | 1.171e-6 | 0 | 0 |
| albedo | 1.439e-5 | **1.427e-5** | 2.725e-6 | 0 | 0 | 0 |

rotation 在 51 个采样点中的 50 个由 RGB-L1 提供最大单项梯度，position 则 51 个点全部由 DSSIM 主导。alpha 不影响 albedo，但持续更新 rotation、position、scale 与 opacity。normal 和 distortion 对所有关键参数的梯度严格为 0。

梯度范数本身不能证明某一损失的梯度与 GT-normal 改善或恶化方向同向，因为 GT normal 不在训练图中；在固定光、固定随机种子、无 deformation、无 densification 的受控条件下，只能确认 RGB-L1、DSSIM、alpha 正在推动 rotation/geometry，并与法线误差增长同时发生。它支持“当前 schedule 没有显式保护法线的反向信号”，但不构成 RGB/alpha 梯度导致法线恶化的方向性因果证明。方向性判断仍需计算各损失梯度与 GT-normal diagnostic gradient 的 cosine similarity。

## 实际参数漂移

iteration 1→500：

- rotation：均值 `19.6209°`，P95 `55.9204°`；
- position L2：均值 `0.05185`，P95 `0.13868`；
- log-scale 平均绝对漂移：`0.34091`；
- opacity logit 平均绝对漂移：`2.27469`；
- photometric albedo logit 平均绝对漂移：`0.12144`。

这说明不仅 rotation 在补偿图像误差，position、scale 和 opacity 也在同步重塑 Gaussian 覆盖。

## 对法线修复的直接含义

下一轮不应继续沿用“iteration 1 即放开全部 geometry、iteration 8000 才启用 normal regularization”的设置。优先执行：

1. 固定 GT per-light 5.5；
2. 固定 xyz、scale、opacity 和栅格/deformation 几何，但新增并放开不参与 Gaussian covariance 的显式 shading normal，同时训练 linear photometric albedo；
3. 合成数据 oracle 组从 iteration 1 加入 world-space GT normal loss，先证明显式 normal 的表示、投影、坐标与梯度链路能够恢复；
4. oracle 组通过后，使用相同初始化与参数自由度移除 GT normal loss，仅依赖固定 GT per-light RGB，检验 Lambertian 可辨识性；
5. 增设现有表示的 rotation-only 耦合对照：固定 position/scale/opacity，放开 rotation 与 albedo，并加入 GT-normal loss；该组会同时改变 covariance，仅用于比较；
6. 在 iteration 1、10、25、50、100、200、500 记录每项损失相对于 GT-normal diagnostic gradient 的 cosine similarity、world-normal 误差及参数漂移。

仅当“显式 normal + GT-normal oracle”仍无法降低误差时，才应优先怀疑 normal 坐标、栅格化/混合、可见性匹配或实现链路；若 oracle 成功而纯 RGB 组失败，才将重点转向 directional lighting、albedo-normal 歧义与损失设计。
