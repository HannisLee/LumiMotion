# 投影灯向Stage2重训终点结果与几何收益复核

## 结论

**训练及评价工程执行PASS；最终几何收益验收FAILED。**

同一N00 Stage1@35000、同一A+PS配置和8100新增更新，仅替换初始灯向后，TEST综合法线MAE从旧DIR的14.759131度降至14.701172度，只改善0.057959度（0.3927%）；仍比原生Stage1的13.864914度差6.0315%。更准确的方向光没有在本次固定训练配置下带来明显的整体几何改善。

本次不新增训练、不改变模型/预算/阈值、不选其他检查点。此前失败模型、渲染与统计全部保留。

末次仅3/580条可靠轨迹来自模型动态门控分组。动态区域的有效PS监督仍很少，这是可见的机制限制；不能据本轮单组结果唯一断言它解释了全部失败，也不能把模型门控当作GT分割。

实际打开5张四类/分量代表接触图（10、80、150帧）和4张局部原图（人体10/70、鞋110/130），共9张：

1. RGB/Alpha：人物边缘及手臂仍有透明碎片、模糊；头颈/躯干局部有缺失，鞋的外形与纹理细节不清晰。
2. 法线：GS人体轮廓破碎，Expected Depth法线有密集条纹，地面法线有波纹；Mesh更平滑，但不能由平滑等同GT更准。
3. Depth/Mesh：保留总体动作轮廓，局部头颈/肢体与足部误差明显；仅15TEST有真实TSDF，其余135帧未重建，不能宣称连续Mesh视频恢复。
4. 静动态/EL-DL：人物主要为动态门控、地面主要静态，局部有泄漏；示例中EL外观已接近完整RGB，DL较暗。该判断来自显示面板，未定量分解贡献，也不构成环境光因果消融。

评价进程记录五类视频均自动解码150帧；本次未实时播放视频、未逐帧检查全部150帧。以上只覆盖明确列出的9张代表图，不冒称全帧/全局部目检。
