# SH 主干与 Per-light Direction 融合方案报告

日期：2026-08-24  
服务器 / 环境：`garuda` / `lumimotion-garuda`  
状态：方案设计，尚未修改代码、尚未启动训练

## 1. 结论先行

可以把 SH 和 per-light direction 结合起来，而且这比继续直接用点光源替换 SH 更符合当前实验事实。

本报告最推荐的主线不是“SH 与 Lambertian 二选一”，而是：

> **保留当前 `original_sh` 作为完整的高质量外观主干，再增加一个零初始化、低阶、受幅度限制的 light-direction adapter。光照只学习每帧单位方向，不学习点位置，也不使用 `1/r²`。**

推荐的第一版公式是：

```text
原始颜色：C_base(g,t,v) = 当前 degree-3 view-SH + 当前 d_color(time)

方向：r_t = learned light-to-surface unit ray
      l_t = -r_t = surface-to-light unit direction

方向增益：m_g(l_t) = exp(δ · tanh(a_g · Y_2(l_t)))

融合颜色：C(g,t,v,l_t) = C_base(g,t,v) × m_g(l_t)
```

其中：

- `Y_2(l_t)` 是光照方向上的 degree-2 SH，共 9 维；它与当前按观察方向求值的 view-SH 是两套语义不同的基函数；
- `a_g` 第一版只输出每个 Gaussian 一个标量增益，不直接输出 RGB，避免重新变成任意颜色记忆器；
- `δ` 建议先限制在约 `log(1.25)`，即方向分支最多产生约 ±20%～25% 的乘性修正；
- `a_g=0` 时 `m_g=1`，理论上退化为现有 SH；工程上还应保留显式 bypass，确保关闭 adapter 时逐位走原始路径；
- 第一阶段固定 geometry、deformation、opacity、原始 SH 和已有 `d_color`，只训练方向轨迹与 adapter，避免再让 RGB 残差破坏当前已经很好的几何法线。

这条方案的优点是同时满足三件事：

1. 原有 SH baseline 可以完整保留和回退；
2. 模型显式接收 per-light direction，可以做方向干预和 relighting；
3. 不再要求不完整的 Lambertian 公式独自解释全部 RGB，因此 direction 不必把 AREA 灯、阴影和间接光误差压到 normal / geometry 上。

但必须强调一个实验边界：**CV3s 当前每帧只有一个相机状态和一个灯光状态，且二者都与 time 一一绑定。仅凭这条轨迹，任何“view-SH + light direction”模型都不能被严格证明学会了可迁移光照。** 它可以用于工程试验和定性控光，但要证明 relighting，最终仍需相机 × 灯光解耦的数据或至少固定相机、多方向光的 GT 渲染。

## 2. 为什么现在适合改成“SH 主干 + direction adapter”

### 2.1 当前结果说明 direction 有信息，但 Lambertian 替换法损失过大

| 实验 | 外观 / 光照方式 | PSNR | GT normal mean | 说明 |
|---|---|---:|---:|---|
| `0824-03` | degree-3 SH + `d_color(time)` | **52.5620** | **12.542°** | 当前最强重建与 GS normal baseline |
| `0823-01` | 全局 GT directional + Lambertian | 47.6509 | 19.226° | direction 固定，但成像模型缺项 |
| `0824-04` | 逐 GS GT 位置方向、无距离衰减 + Lambertian | 46.9644 | **18.358°** | direction 更准确后 normal 改善，RGB 仍下降 |

`0824-04` 相对 `0823-01` 的 normal mean / median / p95 分别改善约 `0.87° / 2.46° / 3.86°`，说明空间方向信息确实有价值；但最佳 PSNR 下降约 `0.69 dB`，说明“方向更准确”不能补齐 AREA 灯、visibility、间接光、材质高光和曝光等成像缺项。

因此合理的下一步是保留 SH 对复杂外观的吸收能力，只让 direction 负责一个小而明确的可控残差。

### 2.2 学方向比学点位置条件更好，但它仍是近似

点光源学习同时混合了：

- 三维光源位置；
- 每个 Gaussian 随位置变化的方向；
- 距离与光强之间的尺度歧义；
- `1/r²` 带来的大动态范围；
- 几何位置误差对方向与亮度的共同影响。

单位方向只有两个有效自由度，且没有距离—光强耦合，优化条件明显简单。因此第一版只学习一个每帧共享的 directional light 是合理的。

不过 CV3s 的灯并不是真正远场。已有量化显示，逐 GS 局部方向相对场景中心方向的夹角中位数为 `6.546°`，P95 为 `14.723°`。所以全局方向应被称为一个稳定的低维近似，而不能被称为完整 GT 光照。

### 2.3 当前代码已有可直接复用的方向模型

`scene/photometric_perlight_pbr.py` 已有 `StructuredDirectionalLightModel`：

- 二阶 Fourier 轨迹表示主光线运动；
- 每帧二维 tangent residual；
- residual 最大角度默认限制为 `10°`；
- 已有一阶、二阶时间平滑损失；
- 输出始终归一化为单位方向。

它比 `DirectionalLightModel` 中 120 条完全自由的 per-frame direction table 更适合作为 SH 融合分支的默认方向表示。建议复用或抽取这个模块，不再新写第三套方向参数化。

方向约定必须沿用现有 checkpoint 语义：

```text
保存的 r_t：light_to_surface
实际着色的 l_t：surface_to_light = -r_t
```

## 3. 五个可行方案

### 3.1 方案 S0：SH 结果上的方向比值重光照

这是最小改动、最快看到 controllable relighting 的方案，不要求重新训练 SH。

对当前帧参考方向 `l_ref` 和用户指定的新方向 `l_new`，用当前 SH 渲染作为原图，计算：

```text
s(n,l) = a + smooth_relu(n·l)

C_new = C_SH × clamp(
    (s(n,l_new) / s(n,l_ref))^γ,
    ratio_min,
    ratio_max
)
```

建议初值：

- 环境底 `a=0.2～0.4`，避免背光区域分母接近零；
- `γ=0.3～0.6`，只转移部分方向光效应；
- ratio 限制在 `[0.5, 2.0]`；
- 使用 SH baseline 的 GS raster normal，不创建 independent normal；
- `l_new=l_ref` 时严格返回原始 SH 图。

优点：

- 不动训练、geometry、SH checkpoint；
- 可以立刻验证“方向旋转时高光 / 明暗是否按几何移动”；
- 失败只影响新 relight 输出，不影响 baseline。

缺点：

- 它是受控的 quotient-image 近似，不会生成真实软阴影、可见性和间接光变化；
- 当前 normal 即使较好，也会在薄片、背面和轮廓处产生比值伪影；
- 它使用 direction，但不解决“从 RGB 学对 direction”的问题。

定位：**P0 可视化原型**。先用固定 GT direction 做参考，再接 learned direction。

### 3.2 方案 S1：原始 SH + 低阶 Light-SH 标量 adapter（主推荐）

该方案不把 Lambertian 作为主颜色，而是给每个 Gaussian 增加一组低阶“光照方向 SH”参数。

```text
C_base = 原有 view-SH(v) 与 d_color(time) 的输出

z_g(l) = a_g · Y_2(l)             # a_g 为 9 个标量
m_g(l) = exp(δ · tanh(z_g(l)))     # 正值、有界乘性增益
C_final = C_base × m_g(l)
```

第一版建议只调制 DC / 基础颜色，不调制 degree 1～3 的 view-dependent 部分。这样可以继续让原始高阶 SH 负责视角相关外观，而 direction 主要负责低频明暗变化。

参数量也较可控：CV3s 约 15135 个 Gaussian 时，degree-2 标量 Light-SH 约增加 `15135 × 9 = 136215` 个参数；相比现有每 GS 48 个 RGB view-SH 系数，增量约为现有 SH 外观参数的 19%。如果第一轮仍担心容量，可从 degree-1 的 4 个系数开始。

建议约束：

- adapter 参数全零初始化；
- `δ≈log(1.25)`，先限制增益范围；
- adapter L2 / 能量正则，避免常量项吞掉 SH DC；
- 邻近 Gaussian 的增益加轻量空间平滑，但轮廓和材质边界应使用 stop-gradient 邻接或鲁棒权重；
- light trajectory 使用一阶、二阶平滑；
- 第一版输出标量，不输出逐通道 RGB，避免把 light branch 变成第二套 `d_color`；
- adapter 启用后先冻结原始 `d_color`，否则 time 和 light direction 一一对应时，两条分支会争抢同一变化。

实现有两个层级：

1. **最小兼容版**：像当前 `d_color` 一样，只在 SH DC 的 RGB 值上乘增益，再转换回 DC 系数，高阶 SH 仍由原 rasterizer 求值；
2. **线性颜色版**：先求完整 view-SH 颜色，进入明确的线性空间后乘方向增益，再 pre-splat。该版本物理语义更清晰，但会改变当前 CUDA 内部 SH 求值路径，必须先做 `convert_SHs_python` 数值等价性审计，不能直接宣称与 baseline 等价。

优点：

- 对现有代码与 checkpoint 的侵入较小；
- 不依赖 normal，避免再次把错误 RGB 梯度推给 geometry；
- 显式依赖 direction，可以在推理时换方向；
- 零初始化、有限增益、独立 checkpoint 都方便回退。

缺点：

- 若没有交叉光照数据，Light-SH 仍可能只是另一种 time 编码；
- 标量低阶分支主要表达漫反射式低频变化，不能充分表示移动高光和遮挡边界；
- 从已经达到 52.56 dB 的最终 SH checkpoint 再训练时，图像残差很小，direction 分支可能没有足够信号。它更适合在 geometry 成形、densification 结束后但 SH 尚未完全饱和时接入，或在真正的多光数据上从 SH 初始化后微调。

定位：**主方案，建议优先实现和实验。**

### 3.3 方案 S2：SH 主干 + 几何感知的有界方向残差

如果 S1 能保持 baseline，但控光变化与表面朝向不一致，可以让 adapter 显式看到几何量：

```text
q = [smooth_relu(n·l), n·v, n·h, v·l]
z = MLP(q, Y_2(l), material_feature)
m = exp(δ · tanh(z))
C_final = C_SH × m
```

其中 `n` 直接使用 SH baseline 的 GS raster normal，先不引入 independent normal；`h=normalize(v+l)`。MLP 可以是全局共享的小网络，per-Gaussian 只保留一个很小的 latent 或 material feature。

优点：

- direction 变化与 surface normal 有明确耦合，relighting 更像真实明暗移动；
- 可以逐步加入 roughness 或当前 PBR 分支已有的 GGX 特征；
- 乘性残差有界，SH 仍负责未建模外观。

缺点：

- 会重新引入对 normal 正确性的依赖；
- 若允许 RGB 梯度更新 rotation / geometry，可能重现 Lambertian 中的法线代偿；
- 当前 AREA 灯和阴影缺项仍会通过 adapter 被近似，而不是被真实解释。

安全策略：第一轮对 `n、xyz、rotation、deformation` 全部 detach，只训练 adapter 与 direction；确认有效后，再单独做允许极小 normal residual 的消融，不能直接联合放开几何。

定位：**S1 之后的 P1 增强，不建议作为首个实现。**

### 3.4 方案 S3：低秩 View-SH × Light-SH 双球面模型

如果目标是让观察方向和光照方向共同决定外观，尤其需要表达高光，可使用两个球面变量：

```text
C(g,v,l) = C_view_SH(g,v)
           + Σ_r A_g,r(v) · B_g,r(l)
```

其中 `A(v)` 用低阶 view-SH，`B(l)` 用低阶 light-SH，并以 rank `R=1～2` 做低秩分解。交互项全部零初始化，因此初始仍是原始 view-SH。

它比简单相加的 `SH_view(v) + SH_light(l)` 更合理，因为镜面高光取决于 view 与 light 的相对关系，不能被两个独立加法项完整表达。

优点：

- 表达力最强，理论上可以同时表示 diffuse 与 view-light interaction；
- 适合真正的多视角 × 多光照数据；
- 保留 SH 这一成熟表示，不必转成完整 PBR。

缺点：

- 参数量和过拟合风险明显增加；
- 在 CV3s 当前单轨迹上，view 与 light 高度相关，分解几乎不可辨识；
- 如果没有 held-out camera-light 组合，它很可能取得更高同轨迹 PSNR，却没有真实 relighting 能力。

定位：**有交叉光照数据后再做的 P2 方案。当前不应优先。**

### 3.5 方案 S4：SH 主输出 + direction 辅助头

如果近期目标只是“方向能否学出来”，而不是立即修改最终 RGB，可以保留 SH 输出完全不变，并行增加一个低分辨率辅助头：

```text
主头：C_main = 原始 SH，承担正式 RGB 重建与指标
辅头：C_aux = low-frequency albedo × direction shading
总损失：L = L_SH + λ_aux L_aux + light smoothness
```

辅助头可以：

- 只在低通后的前景亮度上训练；
- 遮挡、饱和、高光、低 alpha 和 `n·l≤0` 区域降权；
- 初期 detach normal / geometry，只让梯度进入 direction；
- 如果允许使用 `lights.json`，增加很小的方向角监督，先验证方向表示与优化器；纯 RGB 学习则单独报告。

优点是 baseline 风险最低，且可以清楚记录 direction angle error、平滑度和辅助重建质量。缺点是 direction 暂时不控制主输出，所以它更像诊断 / 预训练，不是最终 relighting 模型。

定位：**方向学习诊断方案，可与 S1 并行但不是最终主线。**

## 4. 方案比较与推荐顺序

| 方案 | 保留原 SH | 需要 normal | 可控 relighting | 当前 CV3s 可验证程度 | 风险 | 建议 |
|---|---|---:|---:|---:|---:|---|
| S0 方向比值 | 完整保留 | 是 | 中 | 定性可验证 | 低 | 先做快速原型 |
| S1 Light-SH 标量 adapter | 完整保留，可显式 bypass | 否 | 中 | 可验证重建与方向敏感性；泛化证据不足 | **低—中** | **主推荐** |
| S2 几何感知 adapter | 完整保留 | 是 | 中—高 | 可做定性；需防 normal 代偿 | 中 | S1 成功后做 |
| S3 低秩双球面 SH | 完整保留 | 否 | 高 | 当前数据无法严格辨识 | 高 | 有交叉数据后做 |
| S4 direction 辅助头 | 主输出逐位不变 | 可选 | 低 | 方向诊断较清楚 | 低 | 用于验证方向学习 |

综合推荐顺序：

```text
S0 先验证控光观感
  ↓
S1 固定 GT direction，验证 SH + adapter 架构
  ↓
S1 learned structured direction，验证是否真的使用 direction
  ↓
S2 加入 normal / half-vector 几何特征
  ↓
拿到 camera × light 交叉数据后再评估 S3
```

## 5. 推荐的方向表示

### 5.1 默认：全局 structured directional light

复用 `StructuredDirectionalLightModel`：

```text
二阶 Fourier 轨迹 + 每帧最大 10° tangent residual + 单位化
```

建议训练顺序：

1. 先用 `gt_directional` 固定方向，验证 adapter 本身是否有收益；
2. 再从 GT 方向的 Fourier 拟合或当前相机后方椭圆初始化 learned direction；
3. 比较 fixed-GT、learned、方向打乱三组，而不是只看 learned 一组；
4. 若只用 RGB 学方向，必须报告与 GT direction 的角误差，但不能把 GT 用于反传；若允许弱监督，则明确标注为 supervised / semi-supervised。

### 5.2 可选增强：方向 + 一阶空间曲率，不直接学习点位置

如果全局方向在大物体上不足，可以用一个非常低维的方向场近似近场光：

```text
l_t(x) = normalize(
    l_t - κ_t · (I - l_t l_t^T) · (x - center)
)
```

其中 `κ_t≥0` 表示方向场曲率，近似点光距离的倒数；`κ_t=0` 就退化为全局方向。该模型只增加一个平滑标量，不学习完整三维光源位置，也暂不施加距离衰减。

它可以吸收已有量化中 P95 约 `14.7°` 的局部方向变化，是“纯全局方向”和“完整点光位置”之间值得测试的中间方案。但应在 S1 全局方向版通过后再加，保持单变量消融。

## 6. 训练策略：怎样既用上 direction，又不毁掉 SH baseline

### 6.1 baseline 不变原则

- 新建独立 `render_mode`，例如 `original_sh_perlight_adapter`；`original_sh` 的默认行为不改。
- adapter 关闭时直接走当前 `gaussian_renderer/__init__.py` 的原 SH 分支，不经过新的浮点运算。
- 原 SH PLY、deformation checkpoint 不改变格式；light model 与 adapter 保存到独立 checkpoint。
- 旧命令、旧 checkpoint 和当前 0824 系列实验必须可原样回放。

### 6.2 不建议直接从 iteration 1 联合训练所有变量

推荐分阶段：

1. **SH 成形阶段**：沿用当前 `sh_baseline`，让 geometry、opacity、deformation 和 view-SH 正常建立；
2. **拓扑固定阶段**：在 densification 结束后再创建 per-Gaussian adapter，避免处理 split / clone / prune 时的参数同步；
3. **adapter 校准阶段**：冻结 xyz、rotation、scale、opacity、deformation、原始 SH 和 `d_color`，只训练固定 GT direction 下的 adapter；
4. **方向学习阶段**：adapter 已能响应方向后，再把 structured direction 以小 LR 解冻；
5. **可选联合微调**：只允许原 SH 极小 LR，geometry 继续冻结。只有独立消融证明安全后，才考虑放开 deformation 或 normal。

一个现实问题是：最终 SH checkpoint 已把同轨迹图像拟合到 52.56 dB，残差很小，adapter 可能无信号。因此建议同时保留两条实验：

- 从最终 SH checkpoint 接 S0，做不训练的方向比值 relighting；
- S1 从 densification 已结束但 SH 尚未完全饱和的中期 checkpoint 接入，或者直接在多光交叉数据上从最终 SH 初始化。

不要为了让 adapter “有作用”而故意破坏最终 SH checkpoint。

### 6.3 防止 direction 被忽略或退化为 time 编码

至少需要以下诊断：

- **方向打乱对照**：训练 / 评测时固定其他输入，只打乱 direction；若输出和指标几乎不变，说明模型没有真正使用方向；
- **方向冻结对照**：fixed GT direction 与 learned direction 比较，分离 adapter 容量和方向优化难度；
- **adapter 能量**：记录 `log-gain` RMS、P95、饱和比例；全零说明分支被忽略，长期打满边界说明它在代偿其他误差；
- **方向干预曲线**：固定 camera、time、geometry，只让方向绕物体旋转，检查亮区质心、法线相关性和帧间连续性；
- **冻结 `d_color`**：方向阶段至少冻结已有 time-conditioned 颜色 MLP，否则无法判断变化来自 time 还是 light；
- **counterfactual 一致性**：同一个 light direction 重复输入应得到一致结果，方向小幅变化不应出现跳变。

## 7. 实验矩阵与验收标准

### 7.1 第一轮：不训练 / 冒烟

| 编号 | 配置 | 目的 |
|---|---|---|
| E0 | `0824-03` SH checkpoint + adapter off | 验证原始输出逐位等价 |
| E1 | 同 checkpoint + S0，`l_new=l_ref` | 验证 identity relight |
| E2 | 同 checkpoint + S0，方向旋转 ±15° / ±30° / ±60° | 检查 controllability、闪烁和轮廓伪影 |
| E3 | direction 符号取反 | 专门排除 `light_to_surface` / `surface_to_light` 符号错误 |

冒烟输出必须放在 `output/smoke_test`，不覆盖 `0824-03` baseline。

### 7.2 第二轮：S1 adapter 架构消融

| 编号 | direction | Light-SH | 训练变量 | 回答的问题 |
|---|---|---|---|---|
| A0 | 无 | off | 无 | 原 SH baseline |
| A1 | fixed GT global | degree 1 scalar | adapter only | 最小方向容量是否有效 |
| A2 | fixed GT global | degree 2 scalar | adapter only | degree 2 是否值得 |
| A3 | learned structured | 采用 A1/A2 最优 | adapter + direction | 学方向的额外代价 |
| A4 | shuffled direction | 同 A3 | 同 A3 | 模型是否真的使用物理方向 |
| A5 | learned global + curvature | 同最优 | adapter + direction + `κ` | 是否需要近场方向场 |

第一轮不建议同时扫 RGB Light-SH、MLP 宽度、normal residual 和 geometry LR；那会失去可归因性。

### 7.3 关键验收门槛

重建保持：

- adapter off 相对原 SH 的最大像素差应为 0，或在明确经过等价实现时小于预先定义的数值容差；
- adapter on 的同轨迹 PSNR 相对 `52.5620 dB` 下降不超过 `0.2 dB`，否则不能称为“保留 SH 优势”；
- GS normal mean 相对 `12.542°` 劣化不超过 `0.5°`；
- alpha 覆盖率和时序差不出现显著退化。

方向有效性：

- learned direction 的 GT 角误差、轨迹一阶 / 二阶平滑度单独报告；
- A3 必须明显优于 A4 的方向干预或 held-out-light 指标，否则 direction 只是标签 / time 编码；
- adapter 的增益分布不能长期全零，也不能大面积饱和在上下界。

relighting：

- CV3s 现有 stride-8 test 只能算同轨迹插值，不能作为最终 relighting PASS；
- 最终必须在固定 camera / geometry 下比较未见 light direction，最好有 GT RGB；
- 至少报告 novel-light PSNR / SSIM / LPIPS、亮区移动方向、阴影 / 轮廓稳定性和时序连续性；
- 实验 README 仍应按仓库规定记录完整命令、source / model / iteration、输出、日志、指标、代表图片 / 视频、四类目检和最终 `PASS` / `FAILED`。

## 9. 主要风险与应对

### 9.1 view-SH 和 light-SH 概念混淆

当前 SH 的输入是 camera-to-Gaussian view direction，不是光照方向。不能直接把 `l` 填进现有 SH 后称为“加入光照”，否则会丢掉原来的视角外观。必须保留两套清晰命名：`view_sh` 与 `light_sh`。

### 9.2 数据不可辨识

当前 camera、time、light 同步变化，`d_color(time)` 又能直接调 DC。没有交叉数据时，direction branch 可能只是另一条 time branch。固定 `d_color`、方向打乱对照只能暴露一部分问题，不能代替多光数据。

### 9.3 双重记忆导致 PSNR 更高但 relighting 更差

若 Light-SH 输出 RGB、degree 太高或无幅度限制，它很容易复制现有 SH 的记忆能力。第一版坚持“标量、低阶、有界、零初始化”，并以 novel-light 而非同轨迹 PSNR 决定是否升级容量。

### 9.4 颜色空间语义

当前原始 SH 路径与 photometric linear 路径的颜色处理不同。为了 baseline 可追踪，第一版应在当前 SH 语义内做最小 DC adapter；如果转为线性空间乘法，必须作为新实验并验证 precomputed SH 与 CUDA SH 的数值差异，不能静默替换。

### 9.5 adapter 与 geometry 共同作弊

若一开始同时更新 direction、adapter、normal、rotation、xyz、opacity 和 deformation，将再次出现不可归因的联合代偿。第一版冻结 geometry / deformation / normal 是硬要求，不只是训练技巧。

### 9.6 零初始化导致梯度也为零

不要同时把 adapter 内部特征和最终输出 gate 都初始化为零。建议直接令 `a_g=0`，使用 `m=exp(δ·tanh(a_g·Y(l)))`；此时输出为 identity，但 `a_g` 仍有非零梯度。若另设全局 gate，应避免 gate 与 `a_g` 双零造成分支无法启动。

## 10. 最终建议

建议把本方向定义为：

> **SH-preserving directional relighting，而不是用 direction 替代 SH 的 photometric reconstruction。**

最可行的执行路线是：

1. 保留 `0824-03` 作为不可覆盖的 SH baseline；
2. 先做 S0，快速确认 SH normal 驱动的方向旋转是否视觉可用；
3. 实现独立 `original_sh_perlight_adapter`，使用 structured unit direction + degree-2 scalar Light-SH gain，adapter 零初始化且有界；
4. 在 densification 后创建 adapter，第一阶段冻结原 SH、`d_color`、geometry 与 deformation；
5. 先 fixed GT direction，再 learned structured direction，必须带 shuffled-direction 对照；
6. S1 能在 PSNR 下降不超过 0.2 dB、normal 劣化不超过 0.5°的前提下产生稳定方向响应后，再加入 S2 的 `n·l / n·h` 特征；
7. 在没有 camera × light 交叉 GT 前，不启动高容量 S3，也不把当前轨迹上的效果写成 relighting 泛化成功。

这个方案真正利用了当前 SH 的优势：让它继续承担复杂、非物理且数据中确实存在的外观项；同时把 direction 变成一个受控、可解释、可干预的小分支。这样即使方向分支失败，SH baseline 仍然完整；如果方向分支成功，则可以逐步增加几何约束和 view-light interaction，而不必再次从低容量 Lambertian 起步。
