# 材质边界分支结束与白色DL能量条件剖面建议

2026-10-19；ushas / lumimotion-ushas。只读总控 `material_bounds_v1` 的summary、逐帧统计和梯度张量，并参照报告40/53/55及已审阅的校准源码。本报告没有读取M06/M07或其他模型的外部GT/TEST结果，没有修改生产代码、运行GPU或启动训练。M06/M07继续原预算，不根据本诊断改变初始化或光照。

## 决定：结束有限材质边界分支

旧I00、rho、E、L、几何和visibility冻结条件下，材质边界诊断已完成702次前向、117次反向，状态为 `PASS_FROZEN_GRADIENT_DIAGNOSTIC_EXECUTION`。中心原FIT为0.002575200575435709；当前贴边坐标向物理[0,1]外移所能取得的收益上界B为0.000013653257525332825，即原误差的0.5301822955%。该数值低于预先提出的1%问题门槛，且不是紧贴阈值的情况。

唯一0.001线性probe使中心FIT降到0.0025751474442788297，相对改善约0.002063%。半bias也有很小改善，双bias则由0.0029591626222006595微升到0.0029591914006652166。g·delta与像素方向导数差为2.945564288951273e-12，支持该小步确实沿已计算的一阶方向工作；没有出现需要用新步长解释的梯度失败。

因此，结束“只放开当前贴边rho就能解释至少1%旧FIT误差”的有限分支，不扫描新材质上下限、不追加步长、不重拟合后追求更漂亮的结果。外向梯度占全部梯度平方的53.788%并不推翻结论：这个比例既不含参数可移动距离，也不以原光度误差为分母。

结论不能扩大为“真实材质已正确”“全部材质自由度都无用”或“BRDF完全符合Lambertian”。B不涵盖同时移动内部rho、改EL/L、改变几何或正式sRGB目标；这些仍是不同假设，但当前不能因这个限定性结论而立即扩模型。

## 唯一建议：冻结其余状态的白色DL强度条件剖面

仍使用原I00@16000、旧init3累计90epoch rho/E、旧L、117 FIT、旧no_bg=False、resolution=2、原Alpha>0.5分母和线性censored MSE，不读取18开发图像。不使用refined失败方向，也不加载P00或M06/M07几何。

对每帧的白色DL仅引入一个非负审计系数a，定义D=aπ。所有RGB通道、Gaussian及像素共享该帧a，E固定，不增加逐点或逐通道光照自由度：

`C_i(a) = rho * [E/pi + a*q_i]`。

准确渲染的图像可写为 `P_i(a)=U_i+a*W_i`，其中W是该帧固定DL分量，U是固定EL分量。每帧固定分母下的censored MSE是a≥0上的一维凸、分段二次函数。求它的全局最小值，只是计算这个极宽的“每帧一个非负白色DL强度”条件解释器最多能解释多少残差；不将系数导出为新灯资产。

同时在同一组图像基底上求一个全117帧共享的a作为嵌套对照。二者属于同一标量DL响应假设，不新增第二种着色模型。全局共享目标仍是117帧等权，不按像素池化。记录中心原a=1、共享a、每帧a三种完整FIT目标及每帧曲线最小值，不选择更有利的图像子集。

这包含CPU上的低维条件最小化，不能称为“零优化”；但不执行训练optimizer、raster反向、rho/E/L更新或几何训练。每帧a使用该帧已见FIT RGB求得，因此结果是条件最优解释能力，不是预测验证。

## 可执行封顶预算与数值检查

最多720次原生全图raster前向、0次raster反向、0次训练更新：

1. 三bias各117帧，分别渲染原total和固定DL-only，共702次。使用同一精确BVH和生产override线性颜色；令U=原total−DL-only，不额外渲染EL。原中心逐帧回放继续要求与旧记录差<1e-7，q与已验缓存差<2e-6。保留原浮点U，不按残差或颜色做裁剪。
2. 只在中心bias求共享a和每帧a。采用float64分段二次凸求解：未饱和项总为二次式；饱和项仅在a<(target−U)/W时激活。W=0的项对a为常数，正W的有效断点排序后可用二次系数前缀/后缀和定位最小区间；无需学习率、随机初值、网格扫描或raster迭代。每个标量最多一次断点排序和线性扫描，最多118个标量问题。共享问题使用正确的每帧分母权重。
3. 若目标在一段非负区间内同样最小，记录整个最小区间和未辨识状态；固定选区间内离a=1最近的值作后续数值核验，不能把任意极端系数当估计结果。没有DL响应的帧沿用a=1并标记无辨识信息。不靠追加搜索处理退化。
4. 将中心求出的同一系数冻结到半/双bias，直接用各自U/W计算目标，不在旁档重求系数。旁档变化只描述迁移敏感性，不冒充原18开发25%验收。
5. 预先固定FIT 1/81/149，各三bias，对共享系数及该帧系数分别真实渲染核对重组合图像，共18次；与U+aW的最大差要求≤2e-5，沿用既有加性检验精度。系数、图像或目标非有限、求解区间不满足凸导数条件、真实前向不一致均记工程FAILED并停止，不通过限制系数或改阈值挽救。

分段凸问题应报告最小点左右导数/边界KKT条件及数值残差。上述a≥0范围不预设数据驱动的最大能量；若最优区间极宽或系数极端，必须如实报告不可辨识/条件解释退化，不能自动认为需要这样一盏物理光。不得为获得方便结果后验裁剪范围。

所有full-FIT指标仍固定原分母；按未饱和/饱和、内区/边缘、原五时间块列解释性贡献。只画原系数序列及最小区间，不拟合平滑曲线，不搜索时间结点或正则权重，不基于18开发挑一种轨迹。

## 事先固定的解释与停止规则

令R为逐帧条件最优解释器相对a=1的中心完整FIT改善比例。由于这是整个非负逐帧白DL系数族的最优值：若R在数值误差外仍<1%，则否证“仅改变逐帧白DL能量能解释至少1%旧FIT误差”，结束该分支，不增加RGB能量、EL或方向自由度来挽救。

若R≥1%，再完整报告相对共享a的额外收益及旁bias迁移；这只说明这个一维图像响应与残差相关。错误L、预测法线、V、视角材质或静态几何都可能被a部分吸收；较好的FIT不证明真实光能随时间变化。若额外时间收益很小，不应据此引入时间轨迹；若旁bias明显恶化或系数退化，也不准直接进入灯资产导出。无论哪一种结果，本诊断结束后都不自动重训练。

全局D=π还存在尺度等价：在范围允许时，D'=sD、E'=sE、rho'=rho/s使图像不变。因此单独释放一个全局D并不能恢复绝对光能，也不是独立的物理识别实验。这里固定rho/E做共享a对照，只测旧终点的条件光度校准余量，不能破坏这个解释边界。

目前没有固定rho下的法线相关EL残差证据，也没有同一几何/照明条件下的多视角BRDF识别证据，所以不优先扩大EL或新增specular项。报告40已否定“方向细化高频噪声因此应立即加强正则”的依据，失败方向候选继续停止。本报告不把这些模型定义上的限制当已证明的错误来源。
