## 方向光可以可靠提供什么

已知训练光方向可以约束入射方向，无须估计光源位置或按距离衰减；但“背面”有两种不同物理情况。设方向ℓ从表面指向光，V为光可见度，n为朝向实际可见面的法线，则直接漫反射为：

```text
C_direct = albedo * learned_intensity / pi * V * max(n dot l, 0)
```

1. **局部背光／附着阴影**：n·ℓ≤0。该面的直接漫反射本来为0，与远处遮挡物是否移开无关；∂C_direct/∂V=0。仅把这种点的RGB误差乘大，不会凭空产生可用于遮挡XYZ的梯度。真实RGB非零还可能来自间接光、镜面或预测法线错误，不能自动标成投射阴影。
2. **正面受遮挡／投射阴影**：n·ℓ>0，但沿ℓ方向的V小。这里改变遮挡几何可能改变照度，才适合把一部分残差信息分配给遮挡XYZ。
3. **正面受光**：n·ℓ>0且V接近1。其观测主要约束接收法线、反照率和光强；若预测过亮，也可能是材质或亮度模型错误，不能只凭暗残差就提高遮挡几何权重。

GT方向本身不提供点属于哪一类的信息，分类仍依赖预测几何／法线。当前模型n可学习，而且原生渲染会根据相机视线翻转Gaussian法线；直接以n·ℓ的符号生成“真阴影标签”有循环推断风险。方向表保持原值，不修改方向来适应图像或降低误差。

## 信息来源与跨135帧诊断

只使用原135训练RGB、自身Alpha、已给相机／方向及已训练模型预测的XYZ／q／Alpha／深度／可见度。训练RGB学习的全局光强可以作为模型参数使用，不读取GT光强。GT normal／depth／material／shadow及测试图像不参与分组、权重或局部拟合。

静态模型的固定Gaussian ID提供跨帧对应，但点中心投影不保证始终投到同一实际表面。应先用预测相机可见性检查它在各帧是否真的被观察；不能把全部135方向无条件算作每个点的有效信息。可执行的只读近似是：投影该点到原训练图像，用原Alpha、模型预测Alpha和该点camera-Z与预测深度的差构造相机置信度；深度差容差与投影方向上的Gaussian尺度相联系。使用原预测深度而非GT；镜面、边缘混合、脚周伪表面会使该近似有偏，需保存覆盖与误对应诊断。若以后实现原生逐Gaussian合成贡献统计，可替换该近似，但不能在同一最小训练消融中同时更换对应算法。

对每个初始点i、帧t保存：相机可见置信度c_it、源预测朝向翻转符号s_it、入射余弦μ_it、源预测V_it、原RGB逐通道满码标记、观察残差及使用/拒绝原因。所有源图、相机、方向和模型SHA绑定资产。跨帧传到canonical朝向的方向为u_it=s_itℓ_t；μ_it=n_i·u_it。禁止忽略相机翻面后直接把相反可见面的RGB当作同一单面Lambert观测。

局部方向诊断可用：

```text
H_i = sum_t a_it * u_it u_it^T
a_it = camera_confidence * light_visibility_confidence
       * positive_incidence_confidence * uncensored_channel_fraction
```

H只用有效的未满码近似等式观测；满足亮度下界的满码通道不应被当成精确辐亮度。下界违反时仍有光度导数，但首版H诊断将它们单独统计，不偷换成恒定等式信息。记录特征值、λ_min／trace、条件数、有效样本数`(sum a)^2/sum(a^2)`及有贡献相机数；全局方向Gram条件数约2.03不能替代这些局部统计。

该Gram仍只是局部方向覆盖近似，并非扣除未知材质、强度和非Lambert效应后的完整Fisher信息。低秩可提示信息不足，高秩不能证明法线正确。按同一来源模型固定分组后可跨135帧检查残差稳健性；不使用独立帧任意曝光来吸收阴影，也不把大残差一概叫作异常反射。

## 一个可验证的首个权重候选

第一步只做上述无更新诊断；**首个训练候选不把H也同时加入权重**，以便分辨方向／可见度分配的作用。先在初始化检查点冻结每点每训练帧的μ、V和相机置信度，整个短实验不更新分类资产，避免q通过改变门控标签降低自身被约束程度。

一个数值明确的候选为：

```text
x = clamp((mu_source - 0.05) / 0.20, 0, 1)
S = x*x*(3 - 2*x)                    # 正入射软门控
B = 4*V_source*(1 - V_source)        # 偏重可见度过渡区
g = S * B
A = source_camera_confidence > 0.5  # 仅用于权重归一化集合
w = (1 + g) / (1 + mean_A(g))       # 在A内；A外w=1
```

上述0.05／0.25入射过渡和相机0.5阈值是待审计的预设候选，不是由GT优化出来的最佳值。若集合A为空，w=1并记录该帧没有可用方向分配证据。w固定且停止梯度；其范围在0.5到2之间，A内均值为1，避免把整体遮挡梯度简单放大后误称为空间分配收益。均值相同不等于梯度向量范数相同，实际范数仍须记录。

B强调部分遮挡，是因为边界附近通常存在可见度变化；它不是GT阴影边界。完全可见或完全不可见的点不因权重变成可微。源模型可能把真实阴影误预测成V=1，届时此候选可能错过最需要修复的位置，这是明确的召回限制，不能用更有利的评测ROI掩盖。先报告非空门控的点比例、相机合成贡献覆盖和有效XYZ导数覆盖，再决定是否值得训练。

若首个方向／可见度分配通过，再独立考虑`g *= h_i`，例如`h_i=clip(3*lambda_min(H_i)/trace(H_i),0,1)`并记录有效帧数；这是第二个因素，不能在首轮一并加入。低H也不能成为删除表面点、训练图像或评分区域的理由。

## 梯度路线与避免“转背面逃监督”

保留已验证的接收／遮挡分支和一份RGB损失，不能将同一残差额外加第二次：

```text
C = C_receiver + w * (C_shadow - stop_gradient(C_shadow))
```

接收分支用V.detach，更新真实q、albedo和训练RGB光强。遮挡分支的接收位置、入射方向、余弦、albedo、light、遮挡q／scale／opacity均停止梯度，只经原trace的V更新遮挡XYZ；相机XYZ／q／alpha合成旁路仍停止梯度，几何正则按共同已验证配置更新真实表面。w也从固定源资产读取，不反传。

这样uniform与weighted应具有完全相同的RGB／Alpha／深度前向，以及相同q／material／light的光度导数；唯一差别是遮挡XYZ的梯度分布。增密和opacity／scale保持共同冻结，不允许该权重通过增密统计复制或删除所谓阴影点。

必须保留原全图接收光度约束及所有未满码通道，不能因为预测背光就把亮观测屏蔽。初始“RGB亮但预测μ≤0”、预测V=0但RGB明显非黑等矛盾点需单独报告数量、原像素贡献、残差及训练后变化。固定门控能阻断通过门控导数直接逃避，但无法保证当前渲染余弦不会转入ReLU负区；该区本来存在直接光导数死区。若亮而背光矛盾增多或GS／真实深度退化，不应以更小shadow loss接受候选。首轮不同时用软正部替换Lambert clamp，也不增加另一套反向法线损失，防止改变物理前向后无法解释结果。

## 原生可见度与朝向的硬限制

- 原trace包装器alpha≥.97直接置1，对应V=0的局部导数被截断；更大的w无法恢复这条梯度。原native单Gaussian截断、透射率终止和BVH离散命中也限制平滑可微区。
- 现有沿入射方向0.03的bias可能跳过近接触遮挡物，脚周尤其需要只读距离／V诊断。首个权重消融保持同bias，不暗改trace或额外读GT阴影。
- 相机翻面的两侧表面可能被同Gaussian表示；u_it应带源翻面符号。相机近切线处的小误差会翻符号，必须记录近切线比例，不能把两个半球的观测强行合并为稳定单面材质证据。
- 间接光、镜面和大量显示满码仍未被完整建模。背光亮像素既可能是模型遗漏，也可能是错误几何，不能仅凭它强制翻转法线或推移遮挡物。
- 本方案首先针对静态DL。动态推广需正确跨帧几何对应及方向运输；已有动态MLP Jacobian可能非物理，不直接套用静态点ID或逆转置后宣称可推广。

## 最小独立消融与验收

待T08／T09完成后，再选一个共同且已完整评测的起点，冻结来源分类资产及全部科学参数。两组同新入口、同输入SHA、同seed、同预算，均启用同一遮挡XYZ分流；控制为w=1，候选为上述固定方向／可见度权重。建议首个短实验500步，保存100／250／500；具体起点及几何统计量由当前实验结果确定后预先落档，不把未经测试的H加权并入。

启动前必须在实际训练相机验证：uniform／weighted前向精确一致；q／material／light光度梯度按原FP32容差一致；禁止路径0／None；加权XYZ梯度等于逐点带w的同一V链式导数；源分类和原方向文件未改。解析遮挡物平滑边界的有限差分只用于确认局部导数，饱和内部作为梯度为0的负控保留。还应在固定几何上改变一个未满码亮观测，证明背光分类不会直接将原接收loss删除。

共同评价仍为完整15帧原GS／Depth／Mesh MAE、coverage及四类真实渲染。保留固定代表训练帧的RGB误差、下界违反、亮而背光矛盾率、H分布、XYZ梯度覆盖与方向、光强／材质上尾；不能把跨步不同相机的日志当作同图收敛曲线。只有同预算三项及实际表面一起改善，才支持继续；细小单项收益需谨慎解释，不能沿用T05“GS微降但Depth／Mesh升高”的失败模式宣称成功。

本设计没有启动新训练、修改GT方向或当前T08／T09核心。若只读诊断显示有效可见度梯度几乎全被饱和／bias／错误对应消除，应否决此权重实验，先解决观测或表示瓶颈，而不是继续叠高阴影系数。
