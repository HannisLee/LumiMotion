## 三、若同预算重拟合仍失败：一次局部交点诊断

本轮只问一个问题：**半档到中心跳过了哪些实际surfel面片，以及这些面片是否真在原射线前方并产生足以解释ΔV的衰减？** 保留新中心、全几何、方向、所有原valid，不再搜索bias、修改opacity、删receiver或加入置信权重。

### 3.1 冻结诊断射线

取固定fit代表0001/0081/0149。在各代表的原valid中，按绝对ΔV降序、并以缓存点ID打破并列，取前8条半档敏感射线；另外取相邻且稳定的原有效射线作对照，记录选取规则。诊断选样仅用于追踪事件，不从最终评估分母中删除其他点。

当前数组可直接复现的半档极端示例（按ΔV降序/ID稳定排序）为：

| fit帧 | 缓存点ID前8个 |
| --- | --- |
| 0001 | 299, 837, 901, 965, 1030, 1212, 1274, 1406 |
| 0081 | 84, 100, 584, 837, 1406, 1790, 1916, 2365 |
| 0149 | 100, 299, 777, 901, 965, 1030, 1274, 1406 |

若重拟合改变了方向，必须使用新冻结方向重新按同规则选样，不能把旧方向事件解释为新拟合事件。仍保留旧24条作为前后可比参考。

### 3.2 每条射线需要的最小事件表

以接收中心x及灯向l定义同一条射线，记录每个候选相交Gaussian的原始ID、中心位置、opacity、两个实际尺度、法线、局部receiver/caster诊断分组、相交点和距离。核心区间为从`b_new/2`到`b_new`；同时保留该区间前后的交点作对照。

对面片j的解析平面交点，先用双精度独立算

`t_j = dot(n_j, μ_j-x) / dot(n_j,l)`，

并由实际旋转/尺度计算相交点的局部坐标u、v及`alpha_j=min(0.99, opacity_j×exp[-(u²+v²)/2])`。另设一列严格复刻原生在各实际起点o下的`d_native=-dot(n_j,o-μ_j)×dot(n_j,l)/max(1e-6,dot(n_j,l)^2)`；两种结果不能混用。记录掠射分母和clamp是否触发，检查正距离及有限面片支持。不得只按Gaussian中心距射线近就声称它被命中；倾斜且较大的面片可能由远处中心跨过射线。

代码的BVH以薄icosahedron三角形承载surfel，局部z厚度为1e-6、壳半径系数为`sqrt(2log(opacity/alpha_min))`；原生forward用背面剔除和`FLT_EPSILON`最小距离，通过triangle命中取得Gaussian ID后再计算平面alpha。因此解析椭圆支持只是独立对照，不自动与原生三角形支持完全等价。最可靠的是在隔离副本的独立诊断路径中记录triangle/gs_idx命中序列，再与解析事件对齐，禁止修改共享native库；如先用CPU小样本重建三角形求交，也应明确其未复刻OptiX的所有数值细节。

事件表至少核对：同一Gaussian是否重复贡献、解析面片交点是否落在起点后方、triangle命中与解析平面交点是否跨过bias边界、跳过区间内的alpha累积是否解释V差值、透射率0.03提前停止和末端alpha归一化对差值的贡献。原生实现并未在计算平面d后再次显式判断其正负，这是一项应检查的实现条件，**尚无证据证明它在这些射线上造成错误**。

### 3.3 结果决定唯一后续变量

- 若命中事件与物理前向不一致，例如重复贡献或射线后方平面产生实质衰减：先建立可复现的小射线例子，只修正对应交点有效性；缓存与生产必须共用修正，再完整验证。这属于实现修复，不以新bias掩盖。
- 若事件正确，且半档到中心确实穿过另一层高opacity或累积高衰减的真实预测面片：这是预测几何的层叠/表面对应问题。记录层距、法线、支撑范围及TRAIN相机可见性；下一轮应明确改变接收表面表示或代理几何重建中的一个变量，而不能删除这些ID后称全BVH通过。
- 若被跳过面片与可见的真实接触投影一致：扩大bias正在绕过合理遮挡，应否决该尺度候选；不能以稳定V或拟合下降作为正确性证明。
- 若少量射线无法解释整体尾部，按冻结规则扩展覆盖至全部79个接收点的fit事件统计；不启动正式几何训练期待它自动修正。

上述诊断本身不承诺可从无GT几何唯一识别“错误平台层”和“真实鞋底”。正因为两者在近平面几何规则下可能混淆，先保存命中ID与有限面片证据，才有理由选择后续修正。当前不建议立即把起点改成局部最高面、法向大偏移或自适应跳过所有邻居；这些方案同样可能抹掉真实接触阴影。
