# T13训练设置与损失梯度详解

报告日期：2026-10-12（Asia/Tokyo）。历史实验日期：2026-10-11。服务器：ushas；Conda 环境：lumimotion-ushas。

T13 从原始随机点云开始训练静态 Stage1，使用已知方向光解释 RGB，用预测几何的可见性解释遮挡，并从第2001步开始约束 GS 法线与期望深度法线的一致性。它在固定10000步终点取得 GS／Depth／Mesh 法线 MAE **3.25536746°／5.88760605°／4.75074359°**，满足原静态 EL 对照目标。

这一结论仅对应原约定的三项平均法线指标。后续专项审计确认 T13 鞋尖、脚掌三维支撑严重缺失，**脚部完整性为 FAILED**。理解这套设置时，必须同时看到它对大面积表面的收益，以及自一致性、透明度重置和裁剪对局部几何的风险。

## 1 数据和随机初始化

训练使用静态 DL 数据集的135张训练 RGB、原图自身 Alpha、相机参数及对应 GT 世界坐标光照方向。测试固定为第10、20、……、150帧，共15帧。训练每步从训练相机列表随机取一个视角，取完135个视角后重新建立列表。

没有使用 EL 图片、额外图像，或 GT 法线、深度、材质、阴影、光强作为训练监督。Scene 仍管理测试相机对象，但测试帧不参与训练损失或优化。

| 设置 | 实际值 | 含义 |
| --- | --- | --- |
| 初始化点数 | 100000 | 原共享随机方块点云，不继承已有模型几何 |
| 图像分辨率 | `resolution=2` | 原800×800图像按400×400训练 |
| 背景 | 黑色 | `white_background=false` |
| 总训练步数 | 10000 | 固定终点验收 |
| 保存节点 | 5000、8000、9000、10000 | 保留中间及终点检查点 |
| Python／NumPy 随机种子 | 0／0 | 沿用原 `safe_state` |
| PyTorch 随机种子 | 5000000 | 不应把所有随机源都简称为seed0 |

输入点云 SHA256 为 `f9a2601f8b96bb7381e8b9086c70d97790c4d93026932e332838e0e9e256c971`。随机种子固定不等于 CUDA 计算逐位确定；跨随机种子的稳定性未在本轮验证。

## 2 静态几何和可学习参数

T13 的“静态”限制的是帧间时间形变。MLP 的位置、旋转和尺度形变输出头均清零并冻结，因此任意时刻都满足：

$$
\Delta x(t)=0,\qquad \Delta r(t)=0,\qquad \Delta s(t)=0.
$$

这些零输出头保存在原 MLP 格式中，使原评测加载器重载后仍得到零形变。所有帧共用的基础几何继续学习，训练期间也允许增密与裁剪。

| 参数或分支 | T13中的状态 |
| --- | --- |
| 基础位置 XYZ | 可学习 |
| 基础旋转及其法线方向 | 可学习 |
| 基础尺度 | 可学习 |
| 透明度 | 可学习 |
| 每点反照率 | 物理阶段可学习 |
| 全局正光强 | 物理阶段可学习 |
| 时间位置、旋转、尺度形变 | 严格为零 |
| 时间颜色分支 | 进入物理阶段后关闭 |

前1000步使用原 SH 预热路径。原 `warm_up=1000` 判断是 `iteration < 1000` 时不调用形变 MLP；第1000步进入 MLP 调用条件，第1001步切换物理分支并冻结整个形变网络。因此，不能把这1000步描述成持续充分训练了时变颜色网络。最终物理模型的颜色来自共享反照率、光强、法线和可见性。

## 3 训练日程

| 步数 | RGB着色 | 可见性 | 法线一致性 | Distortion |
| --- | --- | --- | --- | --- |
| 1—1000 | 原 SH 预热 | 不参与物理着色 | 关闭 | 关闭 |
| 1001—2000 | 方向 Lambertian | 全部取1 | 关闭 | 关闭 |
| 2001—4999 | 方向 Lambertian | 全部取1 | 开启 | 关闭 |
| 5000—8000 | 方向 Lambertian | 当前预测几何追踪 | 开启 | 关闭 |
| 8001—10000 | 方向 Lambertian | 当前预测几何追踪 | 开启 | 开启 |

对应参数为 `static_dl_physical_start=1000`、`start_normal_reg=2000`、`static_dl_visibility_start=5000`、`dist_start=8000`。物理、法线和 distortion 分支分别使用严格大于判断；可见性使用大于等于判断，所以边界步数不同。

这一安排先用图像建立初步表示，再让方向光约束法线，较早把法线与几何绑定，之后加入遮挡和沿视线的表面集中约束。T13提前的是法线一致性，distortion仍在8001步才启用。

## 4 方向光着色和材质光强

物理分支在线性颜色空间中对每个 Gaussian 着色，再进行光栅合成。T13只有一个方向光强参数，逐帧方向已知：

$$
c_i^{\mathrm{linear}}=
\frac{\rho_i^{\mathrm{linear}}}{\pi}
I V_i\max(n_i\cdot\ell_t,0).
$$

其中，反照率 $\rho_i$、法线 $n_i$ 和光强 $I$ 来自模型；$\ell_t$ 是当前训练帧提供的世界单位光方向；$V_i$ 是预测几何给出的可见度。法线取旋转矩阵的第三列，并根据当前相机方向翻面使其朝向相机，翻面选择停止梯度。

反照率先从 sRGB 转到线性空间，计算每点颜色；原生 Gaussian 光栅在线性空间合成图像，再转换回 sRGB 与观测比较。渲染结果不在1处做上界截断，因此满码单边损失能够表达“预测达到或超过观测下界”。

| 设置 | 实际行为 |
| --- | --- |
| 反照率初始化 | 第1001步切换时，每点统一设为sRGB 0.5 |
| 高阶反照率系数 | 切换时清零，物理着色使用每点基础反照率 |
| 反照率参数投影 | 每次物理更新后限制到约0.031—0.969，避免长期停留在硬截断无梯度区域 |
| 光强参数化 | $I=\exp(\eta)$，保证为正 |
| 初始光强 | $\pi$ |
| 光强共享方式 | 所有训练帧共享一个标量，方向随帧变化 |
| log光强限制 | 更新后限制在−5至5 |
| 最终保存光强 | 6.6317067146 |

最终光强是当前模型和颜色转换下的拟合值，反照率与光强仍有歧义，不能直接当作真实物理能量。这个 Lambertian 分支没有显式镜面或间接光着色项。

## 5 预测可见性及梯度路径

从5000步开始，对当前 Gaussian 建立 BVH。每点向光方向追踪，射线起点沿光方向偏移0.03个场景单位：

$$
o_i=x_i+0.03\ell_t,\qquad d_i=\ell_t,\qquad
V_i=\operatorname{clamp}(1-\alpha_{\mathrm{trace}},0,1).
$$

`static_dl_bvh_interval=1`，每步重建 BVH；增密、裁剪和透明度重置也会使缓存失效。

整个可见性计算位于 `no_grad` 中。它在前向解释阴影，但 RGB 残差不会通过可见性导数直接更新遮挡物。由于下一步会用新几何重新计算可见性，停止当前反向梯度不意味着可见性在整个训练期间固定。

| 梯度路径 | T13中的行为 |
| --- | --- |
| RGB → Lambertian法线 → 旋转 | 开启 |
| RGB → 反照率、log光强 | 开启 |
| RGB → 主相机投影、Alpha合成 → 几何 | 开启 |
| RGB → 可见性 → 遮挡XYZ等参数 | 停止 |
| 法线一致性 → GS法线及预测深度两端 | 开启 |
| 法线一致性 → XYZ、旋转、尺度、透明度 | 允许接收梯度 |

T13没有启用T05、T11、T12的遮挡XYZ梯度分流，也没有方向加权。可见性停止梯度并没有消除RGB经相机投影或Alpha合成影响几何的路径。

## 6 物理阶段损失

从第1001步起，实际总损失为：

$$
L=L_{\mathrm{photo}}+0.1L_{\alpha}
+\mathbf{1}_{k>2000}\,0.1L_{\mathrm{normal}}
+\mathbf{1}_{k>8000}\,1000L_{\mathrm{dist}}.
$$

### 6.1 鲁棒RGB和满码单边损失

普通通道的残差为 $r=\hat C-C$，采用平滑绝对误差 $\phi(r)=\sqrt{r^2+10^{-6}}$。对于原图前景中观测值恰好为1的通道，只保留预测不足下界的残差：

$$
\tilde r_{p,c}=\begin{cases}
\min(\hat C_{p,c}-1,0), & C_{p,c}=1\ \text{且}\ A_p>0.5,\\
\hat C_{p,c}-C_{p,c}, & \text{其他通道}.
\end{cases}
$$

因此，预测不足1时继续受罚，达到或超过1后不再由该通道产生向下拉回的图像梯度。平滑误差仍保留常数底值，不能把它写成损失数值严格为零。该规则逐通道作用，饱和集合只依赖固定观测和原图Alpha。

鲁棒权重使用单边处理前的RGB平均残差，并停止权重梯度：

| 原始三通道平均残差 | 原图前景权重 |
| --- | ---: |
| 预测比观测亮超过0.08 | 0.25 |
| 预测比观测暗超过0.08 | 0.5 |
| 其余情况 | 1 |
| 背景 | 1 |

损失为整张图、所有通道上的 $\operatorname{mean}[w_p\phi(\tilde r_{p,c})]$。权重不改变分母，背景仍参与约束。这里的shadow／highlight名称只是残差分组，不是GT阴影标签。

前1000步SH预热使用原图像损失 $0.8L_1+0.2(1-\mathrm{SSIM})$。进入物理阶段后改用上述损失；配置保留的 `lambda_dssim=0.2` 不代表物理阶段仍加入SSIM。

### 6.2 Alpha轮廓损失

$$
L_{\alpha}=\mathrm{BCE}(\hat A,A_{\mathrm{image}}),\qquad \lambda_{\alpha}=0.1.
$$

它使用原图Alpha约束人物与台面的组合前景。脚后方仍有台面时，删除脚也可能保持Alpha接近1，因此组合轮廓不能唯一保护内部人物表面。

### 6.3 期望深度法线一致性

从2001步起，比较两个归一化后的预测法线：Gaussian旋转产生并合成的GS法线，以及预测期望深度反投影后计算的表面法线：

$$
L_{\mathrm{normal}}=
\frac{\sum_p M_p\left(1-\hat n_{\mathrm{GS},p}\cdot\hat n_{\mathrm{depth},p}\right)}
{\max(\sum_p M_p,1)}.
$$

法线一致性权重为0.1，没有GT法线或GT深度监督。期望深度可表示为：

$$
D_{\mathrm{expected}}(p)=\frac{\sum_i w_i(p)z_i(p)}{\sum_i w_i(p)},
$$

其中 $w_i$ 为沿相机射线的Alpha合成权重。代码将光栅累计深度除以累计Alpha，得到这一统计量。

实现保留主渲染 `depth_ratio=1`，另用同一基础几何和常量颜色做一次几何渲染，仅该副本设 `depth_ratio=0`，得到expected深度。两次渲染共享真实参数，没有第二套独立优化的几何。

损失区域先选原图Alpha大于0.99的前景，再做5×5腐蚀，最后乘上停止梯度的预测Alpha大于0.5指示量。腐蚀主要处理组合前景外轮廓，不能排除脚与台面的内部深度边界。

两端均可导，允许法线跟随深度，也允许深度表面跟随法线。尺度、透明度没有被冻结：透明度改变会改变深度混合和法线合成，这既提供几何优化自由度，也允许模型通过减少复杂表面降低自一致性损失。

### 6.4 深度Distortion

从8001步起，使用原生光栅的深度distortion输出均值，权重为1000，促使同一视线上的表面贡献集中，减少多层或厚表面。它没有GT深度监督。不同损失原始量级不同，不能只按1000与0.1判断相对梯度强弱。

### 6.5 配置中保留但物理阶段未使用的项

`lambda_separation=0.001`、`d_xyz_loss_weight=0.001`、`d_color_reg_loss_weight=0.01`等参数来自原Stage1入口。T13物理分支的总损失不加入这些项；原SH路径相应正则还要求步数大于1000，而T13在1001步已经切换分支。它们不能作为T13物理阶段仍训练运动分离或时变颜色的依据。

## 7 学习率和点集变化

基础Gaussian使用Adam，`eps=1e-15`；log光强另用Adam。原模型实现固定 `spatial_lr_scale=5`，对位置和尺度学习率乘5：

| 参数 | 配置值 | 优化器实际值 |
| --- | ---: | ---: |
| XYZ初始学习率 | 0.00016 | 0.0008 |
| XYZ衰减终值 | 0.0000016 | 0.000008 |
| 旋转参数 | 0.001 | 0.001 |
| 尺度参数 | 0.002 | 0.01 |
| 透明度参数 | 0.05 | 0.05 |
| 基础反照率 | 0.01 | 0.01 |
| log光强 | 0.001 | 0.001 |

XYZ保留30000步指数衰减日程，未按10000步压缩，因此10k结束时没有到达衰减终值。学习率作用于参数化变量：透明度是logit、尺度是其内部参数、反照率是基础系数、旋转是四元数，不能直接等同于每步物理属性变化量。

| 增密和裁剪设置 | 实际值或行为 |
| --- | --- |
| `densify_from_iter` | 500；严格大于判断且间隔100，首次在600步触发 |
| `densification_interval` | 100步 |
| `densify_grad_threshold` | 0.0002 |
| `densify_until_iter` | 20000，本次10k内持续允许 |
| `percent_dense` | 0.01，沿用原克隆与分裂判定 |
| `min_opacity` | 0.01，低于此值可被裁剪 |
| `opacity_reset_interval` | 3000步，实际在3000、6000、9000步重置 |
| 重置规则 | 每点透明度压到不高于0.01 |
| 尺度裁剪 | 沿用原实现，3000步之后启用屏幕半径上限20及相应世界尺度过滤 |
| 最终点数 | 57465，初始化为100000 |

法线几何副本产生额外屏幕位置梯度。增密统计先将它与主渲染的屏幕梯度按向量相加，再取一次范数并累计一次分母。主渲染梯度包含RGB、Alpha及启用后的distortion；副本提供normal梯度。这样避免分别取范数后相加或重复统计，也不向已累计的真实XYZ梯度再次加入同一导数。

物理分支保存发生在本步增密、裁剪、重置和优化器更新之前，因此9000步检查点是该步透明度重置前的状态。复核脚部消失时必须按这个顺序解释检查点。

## 8 对照结果及脚部完整性

T14与T13使用相同随机点云、输入、损失、学习率、10k预算和其他日程，仅将normal开始时机从2001改为8001步。

| 模型 | GS法线MAE | Depth法线MAE | Mesh法线MAE |
| --- | ---: | ---: | ---: |
| 原静态EL Stage1 35k | 3.50676425° | 7.35467544° | 5.45750273° |
| T14晚启一致性 10k | 4.16876102° | 6.40832183° | 5.59149148° |
| T13早启一致性 10k | **3.25536746°** | **5.88760605°** | **4.75074359°** |

T13相对T14降低约0.91339°／0.52072°／0.84075°，支持当前配置下提前法线一致性的收益。但normal有效步数也由约2000增加到约8000，尚未分离启用时机与累计正则剂量。与更早历史实验相比还同时改变了损失、深度统计和训练继承历史，不能把全部改善都归因于这一个时间参数。

T13按原完整15帧、原掩膜和有效像素加权口径验收，三项严格低于3.51°／7.35°／5.46°。有效覆盖率分别为99.722741%／96.522444%／99.312205%；expected深度绝对误差为0.01780551米。该模型没有继续训练Stage2。

后续专项审计确认，T13原脚部区域约71%的预测expected-depth反投影落在台面附近，脚部深度误差18.44厘米。该比例是固定视线上的表面替代诊断，不是整个三维脚体积消失百分比。台面占前景约82.48%，脚部仅占1.35%，所以整体法线平均误差可以改善，脚部却严重退化。

与设置直接相关的机制是：透明度重置后，expected深度混合脚与后方台面；法线自一致性可能压低脚部透明度；低透明度裁剪随后删除对应点；组合Alpha仍可由台面填满。T14在9000—10000步窗口有强机制证据，T13在5000步已严重缺脚，最早失效不能直接归到9000步重置。

因此，T13的历史三法线数值判定保留 **PASS**，脚部完整性另记 **FAILED**。该结果不证明完整人体重建、所有像素正确、材质和阴影外观正确，也不证明动态推广或跨种子稳定性。
