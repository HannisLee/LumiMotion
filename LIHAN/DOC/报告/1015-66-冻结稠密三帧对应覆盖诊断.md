# T70：冻结稠密三帧对应覆盖诊断

## 结论

当前RAFT Small直接匹配配置不能提供足够可信的跨时间监督，候选可用性FAILED；不是所有稠密匹配方法失败的证明。无主线更新，Goal仍ACTIVE。

从T16既有236个视角兼容训练三元组中等距预选12组，400×400图像、4像素网格。RAFT Small C_T_V2冻结，12次推理迭代；这属于外部预训练先验，不能声称仅从场景图像学习。未读取场景GT，未使用默认几何目标重投影筛选。

## 实测

初版probe完成，但掩码以uint8插值，边界会取整；保留该版结果，不作为最终严格覆盖统计。gate_audit将掩码转float32插值，并增加各筛选阶段统计，重新完成同12组；两个实际执行源码快照均与各自result输入SHA一致。

共25715个源前景网格观测，23155个满足三帧目标支持，4708个还满足三帧未饱和邻域。数字是跨三元组观测总数，不是独立表面点数。

| 三边双向及三帧循环阈值 | 不排饱和的自洽候选 | 排除饱和后 |
| --- | ---: | ---: |
| 1像素 | 23 | 0 |
| 2像素 | 319 | 0 |
| 4像素 | 554 | 14 |

各组目标支持上的三帧循环误差中位数7.96～40.34像素。零有效2像素匹配并非仅由饱和造成：循环自身已淘汰绝大多数候选；但自洽候选也集中在饱和区域。不能将不排饱和的319个点当作可靠光度对应。尚未按动态主体分区，因此14个候选也不能称动态覆盖。

## 目检与下一步

实际查看gate_audit/matches_06.png：三帧RGB可见显著人体动作、阴影变化和画面旋转，2像素结果无连线。T16只约束光轴夹角≤25°，没有限制完整相机旋转；该例说明光轴相近并不保证图像朝向接近。下一步先依据原相机旋转做图像方向对齐，固定相同抽样及阈值再测；须把流逆映射回原像素并检查有效支持，不能把旋转配准解释成平移或非刚性运动已解决。

四类验收：RGB仅检查上述源图；Alpha已用于内部筛选但未独立目检；Normal与动静分离没有新输出，未验收。没有新几何、Depth、Mesh或换光结果。模型渲染命令不适用（没有加载/更新Stage1模型）；图像诊断完整命令、日志及来源见实验README。
