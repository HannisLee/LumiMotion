# 独立EL加可见DL前向与真实梯度验证

2026-10-19，ushas / lumimotion-ushas。

新增 `scene/eldl_v3_photometric.py`、`scene/eldl_v3_trainer.py` 与 `scripts/train_eldl_v3.py`。前向为 `albedo_linear * (EL_RGB + V * DL * max(n·l,0)) / π`；EL是独立、非负、全空间/时间共享的RGB常量，不乘方向光可见度。首版DL白光固定尺度π，方向与EL/DL比由TRAIN估计；绝对光能与反照率尺度不可辨识，不声称恢复Blender绝对功率。

训练器继承历史可验证的normal-opacity保护、真实XYZ/rotation/scale梯度、拓扑/重置/保存次序。`scene/static_unknown_light.py`新增前向/光度loss覆写接口，默认仍调用旧DL实现；只为固定参数增加明确的无梯度审计。新入口要求V3来源、内部估光验证通过和源绑定灯光资产。合成工程灯只允许smoke，不得进入正式训练。

V3满码通道不再套用旧黑暗阈值或暗/亮残差降权。采用逐通道删失和对称Charbonnier，其余通道继续提供监督。16bit解码时保存缩小前满码标记，使用非负AREA缩小，`utils/camera_utils.py`向相机保留逐通道饱和掩膜。原未声明rgba16的路径不变。

## 工程验证

- 单元前向：`output/smoke_test/1019-03-LH-static-jumpingjacks-ELDL-V3-混合前向单元验证/result.json`，EL不随V衰减、遮挡DL为零、背光EL保留、Lambert尺度和分量和式通过；法线角参数导数 -0.506243845 与中心差分 -0.506243845 一致；满码单边及未饱和通道导数通过。该测试不替代真实CUDA梯度。
- 实际20步：`output/smoke_test/1019-04-LH-static-jumpingjacks-ELDL-V3-混合真实光栅梯度`，真实exit0；固定灯光逐值保持PASS，normal-opacity导数确实缺失，而XYZ/rotation/scale范数分别0.5972/0.04749/0.01821。完整physical+visibility+normal+dist分支XYZ/rotation/albedo梯度非零有限。
- 压缩8步reset执行、16步跳过，opacity/Adam/其它参数/RNG检查全部通过。只证明候选机制可执行，不证明T08策略在V3最优。
- 原生及static_sh20步冒烟exit0，静态版相机中心、有效Alpha、16位与饱和掩膜实际装载通过。

第一次smoke沿用历史native编译缓存触发重编译；已先保存旧.so，再复制编译缓存到V3总控独立目录，随后逐SHA恢复历史.so。证据总控 `cache_preservation/before.json`、`restored.json`。之后所有V3任务使用独立缓存，不改旧实验模型/结果。

正式光照估计和几何精度尚未完成。完整渲染、分区定量和四类目检由独立V3评测入口开展，不能将工程PASS写成科学目标PASS。

## 后续精确差分失败与定位

低透明度20步真实模型XYZ/scale中心差分相对误差约62–68%，旋转约8–11%；成熟I00@8000的scale/rotation通过，但XYZ三个尺度约15.6/16.2/14.5%，不满足至少两尺度<15%的原门槛。两次均FAILED并保留，不能用非零有限梯度替代精确导数验证。

第三次零更新图像VJP将线性图像余切点积与float64最终loss差分比较：XYZ差2.6–4.0%，scale差0.5–0.9%，而原生AD仍偏62–68%。实际float32扰动AD保持一致、facing/cosine变支为零，差异主要定位原生渲染导数；尚不能唯一归因某一CUDA分支。各负梯度小步均下降、参数精确恢复。详见报告1019-04；后续完整训练若采用原生近似梯度，必须标明限制，原FAILED不改写。
