# 新增表面轨迹缓存与未知主光材质拟合

新增 `scripts/cache_dl_surface_tracks.py`：由默认Stage1预测几何和训练相机建立体素代表点轨迹，检查相机可见性、深度／法线支持、像素重复及饱和，保存可审计缓存和默认模型四类可视化。不读取GT光向、材质、深度或测试集。

新增 `utils/dl_selfcal.py`：共享有效反照率、单位方向时间表、训练均值固定的正能量，以及未知光候选初始化和截断稳健损失。

新增 `scripts/fit_dl_surface_tracks.py`：固定120拟合时间／15保留时间，执行随机／RGB／SH辅助初始化对照，保存完整参数、优化器与恢复一致性检查。当前仍为固定表面观测模型，未实现光源遮挡、真实几何更新或完整重渲，不能冒充最终Stage2。

验证结果待实际运行后追加。

新增独立 `scripts/eval_dl_light_fit.py`，仅在训练结束后读取GT方向与最终结果做角误差评测，不调用任何训练或参数保存接口。验证同向多SUN才合并为一个有效方向；忽略GT能量，避免将Blender参数等同于标定辐照度。

未知光六组完成后将拟合器提取为共享函数，并新增独立 `scripts/fit_dl_oracle_tracks.py`。GT方向仅由该参考组入口显式传入并冻结，普通未知光命令没有GT路径参数。首次六组运行源码快照保存在总控 T02_initial_snapshot，避免后续重构混淆来源。

新增 `scripts/preview_dl_surface_fit.py`，核验缓存哈希后显示真实拟合的采样点RGB、预测RGB和绝对线性残差；明确不是完整物理重渲。

实际验证：静态／动态缓存生成成功，8组各600次GPU更新、checkpoint恢复预测差0、能量均值规范通过；CPU模型契约检查覆盖方向单位长度／端点、能量平移规范和饱和残差梯度；离线评测验证同向多SUN约定。科学光向恢复未通过，完整结果与失败原因见报告1015-02。未修改现有训练器或历史实验结果。
