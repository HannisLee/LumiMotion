# 0824-05 逐 GS GT 位置光方向消融模式

日期：2026-08-24

## 修改目的

原 `gt_directional` 从每帧 GT 光源位置到固定场景中心只计算一条方向，并将该方向用于全部 Gaussian。它可稳定标定固定光强，但会忽略物体空间范围内各 Gaussian 到有限距离光源的方向差异。

本次新增 `gt_point_direction_only`，作为仅研究方向精度的消融模式。它直接保存 `lights.json` 的逐帧 `light_pos_world`，并在每次 Lambertian 前向中使用变形后的 Gaussian 世界坐标实时计算方向。

## 数学定义

对帧 `t` 的第 `g` 个 Gaussian：

```text
surface_to_light[g,t] = normalize(light_position_world[t] - gaussian_position_world[g,t])
ray_dir[g,t] = -surface_to_light[g,t]
attenuation[g,t] = 1
```

其中 `gaussian_position_world` 是 rasterizer 当前使用的变形后 `means3D`，因此静态与动态 Gaussian 均使用当前时刻的实际世界坐标。

## 接口与兼容性

- 新入口：`--photometric_light_mode gt_point_direction_only`。
- `lights.json` 的记录数必须与场景 timestep 数一致，且 `light_pos_world` 必须为有限三维坐标。
- 光源位置、模式、方向约定及是否启用衰减均进入 photometric checkpoint 与 `light_dirs.json` 元数据。
- 该模式的光源位置和参考方向表固定，不创建光源优化器，也不产生光源学习率或平滑损失。
- 既有 `learned_directional`、`gt_directional` 和带 `1/r²` 的 `gt_point` 不变，旧 checkpoint 可继续加载。

## 数值与物理边界

- 方向归一化沿用 `1e-6` 最小距离保护，避免除零产生 NaN。
- 固定光强沿用 CV3s directional 标定值 `5.5043499`，距离仅作为诊断输出，不参与亮度，从而确保实验只改变方向。
- 原数据光源类型是 `AREA`；本模式使用面积光中心点，只能称为“逐 GS 中心方向 oracle”，不包含发光面积、软阴影、遮挡或能量距离衰减，不能视为完整物理面积光 GT。

## 验证

- 单元测试覆盖：不同 GS 的方向差异、单位长度、无距离衰减、距离不改变亮度、固定参数、非法坐标、checkpoint 往返及轨迹位置保存。
- 修改前 baseline：`22f0576`；修改后版本：`1faccef`。
- `tests` 目录完整 59 项单元测试通过；CV3s 1200 iter 冒烟与 35000 iter 正式消融结果分别记录在对应 `output` 和 `DOC/训练` 文档中。
- 35000 iter 正式训练、120 帧完整渲染、独立 GT normal 评估均通过。相对 0823 directional 三法线对照，normal mean/median/p95 分别改善约 0.87°/2.46°/3.86°，最佳 PSNR 下降约 0.69 dB；因此该模式作为消融 preset 保留，不替换默认方向光模式。
