# 隔离灯向参考与几何梯度控制

新增scripts/train_dl_geometry_controls.py，独立于未知光入口，提供显式oracle／regularizer模式。前者读取GT训练灯向并记录权限与来源，后者从几何目标排除光度项但保持相同材质更新预算。未知光T07入口及其已运行源码不修改。

正则控制使用autograd.grad只给材质／能量赋梯度，随后对几何正则反传；实际断言几何未接收光度累积梯度。finite difference使用纯几何目标，不能以detach造成的数值／梯度不一致逃过检查。完整计划见训练1015-09，结果执行后追加。

新增scripts/diagnose_dl_regularizer_gradient.py做零更新、双精度标量归约及七档步长分支差分。原纯正则最大梯度坐标在较大步长失败，小步长收敛；新增仅regularizer可用的--local-gradient-audit，三个小步长均≤20%才继续，新目录保留原失败。训练仍用原float32损失和学习率。两版本分别快照，新旧热身指标最大差1.49e-8，不声称位级一致。

oracle和regularizer_localfd实际各1200次材质、600次几何更新，工程PASS；原regularizer只有600次材质、0次几何，FAILED。独立GT和零训练参数反事实表明覆盖损失主要应检查XYZ路径，科学目标未通过，详见报告1015-07。没有修改未知光T07入口或CUDA实现。
