# 动态V3无泄漏输入与原生Stage1隔离入口

新增`LIHAN/scripts/dynamic_v3_prepare.py`与`dynamic_v3_stage1.py`。前者固定TRAIN117/DEV18/TEST15，保留16位原RGB和原物体Alpha，写入同序列归一化时间，独立构造原生100k随机点云及TRAIN等帧线性亮度统计。原image Alpha全满码，故只取albedo PNG的Alpha；禁止材质RGB参与训练。训练目录无DEV/TEST图像、GT法线、灯向与网格。

`git diff original -- scripts/train_stage1.py`为空；Stage1不加入本轮PS或Lambertian。独立源码快照绑定所有实际运行代码及SHA，smoke和正式输出各自独立，禁止覆盖已有模型。
