# 外观消融训练安全监督器

新增 `LIHAN/scripts/goal4_appearance_train_job.py`，用于冻结几何外观损失消融。监督器核对当前主机与对应 Conda Python、`scripts.train_static_dl_appearance` 独立快照的 manifest 和逐文件 SHA、物理 GPU UUID 与可用显存，再启动训练。模型输出必须落在任务独立 `output/` 子目录；并行任务不超过每卡两个；既有运行结果、日志和状态不能覆盖。

训练运行期间，监督器保存完整命令、环境、快照证明、真实训练 PID、GPU UUID／显存占用和退出码。它会并行调用 `goal2_capture_runtime.py`，在训练 PID 存活期间记录原生 CUDA rasterizer 与 surfel tracer 的实际映射和 SHA；另记录该 PID 已加载的共享库来源。监督结果只有在训练退出码为0、真实GPU绑定通过、存活期runtime捕获PASS时才记为 `PASS_TRAINING_AND_LIVE_RUNTIME`。异常记为 `FAILED_OR_INCOMPLETE`，并保留训练现场。

启动清单为 JSON：`argv` 是完整参数数组，`gpu_physical` 是物理 GPU 序号，`snapshot_manifest_sha256` 和 `entry_sha256` 绑定冻结快照及训练入口；可选 `child_env` 提供允许的线程和 CUDA 环境覆盖。`--dry-run` 只检查启动前置条件，不启动训练。

本次使用 `lumimotion-ushas` 完成监督器 AST 和两条 smoke spec 的 `--dry-run` 核验，入口／快照 SHA、GPU UUID、环境及输出门禁均通过。随后按授权启动两组110步 smoke，但都在 GPU 分配前因实际CUDA扩展 SHA 与 T06登记值不符而退出1；两个失败结果分别留在 `output/smoke_test/1013-01-LH-static-jumpingjacks_DL_V2-T01-censored外观smoke` 和 `output/smoke_test/1013-02-LH-static-jumpingjacks_DL_V2-T02-MSE外观smoke`，未产生训练更新。根因定位为源码SHA不变、当前扩展SHA与T06登记SHA不同。重试须使用修复后的新快照和新输出编号。正式训练和评测尚未启动。
