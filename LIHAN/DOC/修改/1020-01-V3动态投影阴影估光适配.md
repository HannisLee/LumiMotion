# V3动态投影阴影估光适配

新增独立入口`LIHAN/scripts/dynamic_v3_projection.py`，复用`scripts/fit_dl_shadow_tracks.py`的投影/采样纯函数。原脚本内部每九帧保留一帧不适用V3，本入口改为严格117个TRAIN输入，并使用真实时间间隔的DP。

适配包括：稠密观测代表点、每帧完整预测几何遮挡点、稳定接收面、多灯底亮归一化对照、预先固定的局部球面细化，以及拟合与GT评价分进程。详见同日训练计划；不改旧训练或冻结结果。

新增CPU评价入口`LIHAN/scripts/evaluate_v3_projection.py`，校验冻结文件SHA，使用原DirectionalLightTable插值计算150帧角误差、绘制对照曲线。评价不回写估光结果。

实际执行完成：拟合退出码0；CPU评价首次因list/Tensor参数类型失败，修正评价端后重试退出码0，原失败日志保留，拟合资产未改。另在本次output目录保存`inspect_failures.py`用于冻结后的只读失败帧投影诊断。主方案TEST平均3.878016度，全序列最大73.768478度；均值改善通过，时间稳定性失败。完整结果见`LIHAN/DOC/报告/1020-02-V3动态投影阴影估光结果与跳变失败分析.md`。
