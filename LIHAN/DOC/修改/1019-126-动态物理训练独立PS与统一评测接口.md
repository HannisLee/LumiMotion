# 动态物理训练独立PS与统一评测接口

日期2026-10-19 UTC，ushas / lumimotion-ushas；本轮不接入Stage3/PBR，不改正在运行的原生Stage1。

## 代码修改

- `dynamic_v3_surface.py`：共享world法线SH2环境与完整动态BVH的Vis-Lambertian，Expected depth_ratio0，独立物理状态/原生PLY/MLP检查点及SHA重载。固定TRAIN确定法线符号，不按查询相机翻转。Stage2图像使用固定TRAIN灰背景透射项移除，原生Stage1继续原计划码值处理。
- `dynamic_v3_radiometry.py`：核验原16位TRAIN固定背景、逆sRGB、背景移除、边界负值诊断；不移除物体环境照明、不引入逐帧曝光。
- `dynamic_v3_estimate_light.py`：仅新TRAIN实际动态阴影估计受约束平滑Lt与统一D；辅助共享rho/SH不进入B的观测。每时刻重建完整当前BVH，连续方向阶段采用固定V近似梯度，终点重算真实遮挡。
- `dynamic_v3_tracks.py`、`dynamic_v3_ps_math.py`：真实投影/深度/Alpha/混合法线/切平面核验；观测驱动局部多观测法线，精确加性四元数运输，逐通道真实算子局部JVP辨识度，饱和删失、近零V不除法放大、detach目标；同时约束canonical轴与ExpectedDepth。
- `dynamic_v3_train.py`：四组相同同父预算、外观/几何/形变阶段、固定PS刷新、重置与normal-opacity恢复保护；保护期opacity采用原生0.05学习率，其余按计划衰减。关闭PS组保留独立诊断但权重0。没有增密/分裂或GT监督。
- `dynamic_v3_dev.py`、`dynamic_v3_pipeline.py`：独立18DEV准备与确定性资格/选模；固定35000→四组8100→同父灯向8100串联，最多3个本任务训练，外部GPU进程不干预；记录PID、命令、退出码、快照摘要。流水线不运行TEST/GT评价。
- `dynamic_v3_verify.py`、`dynamic_v3_ps_math_smoke.py`：真实几何梯度、分量相加、独立重载、配对前缀、normal-opacity隔离及已知数学控制。
- `dynamic_v3_evaluate.py`、`dynamic_v3_gt_correspondence.py`、`dynamic_v3_old_eval_gt.py`：统一新旧固定分母法线/深度/RGB/人体腿足鞋，逐时刻TSDF、完整性、经持久顶点证明的动作扣除残差、150帧四类视频。旧GT补齐语义；公共GT生产器按各自时间元数据记录，旧版生产代码另存不可覆盖快照。
