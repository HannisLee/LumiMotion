## 1. 背景与动机

### 1.1 现状：单一标量 5.5 的来源与链路

`scripts/calibrate_directional_light.py` 对 only_clothV3 的 120 帧 GT 做**全局**最小二乘拟合
`target_linear = albedo_linear/π · I · max(N·L,0)`，得到 `I = 5.5043499`，训练取
`--photometric_gt_light_intensity 5.5`（或 5.5043499）。链路：

- `arguments/__init__.py`：`self.photometric_gt_light_intensity = 5.5`（2026-08-24 时点约 L237）
- `scene/photometric_lambertian.py`：`from_args` 默认 5.5 → 注册为**冻结 buffer** `gt_light_intensity`
- `forward` 中 `irradiance = I · color`（directional）或 `I/d² · color`（gt_point）
- `tests/test_photometric_lambertian.py` 有测试固定该默认值（`test_from_args_uses_world_normal_calibrated_default_intensity`）

### 1.2 证据：为什么单一标量不够（2026-08-24 实测复核）

直接读取 `output/0816-only_clothV3-coordinate-pipeline-audit/calibration_camera_facing/calibration.json`：

| 证据 | 数值 | 含义 |
| --- | --- | --- |
| 逐帧拟合光强 | min 4.610 / median 5.799 / mean 5.637 / p95 6.547 / max 6.579，std ≈ 0.704 | 单一标量相对逐帧真值有 **±20% 系统性偏差** |
| 逐通道拟合 | R 5.660 / G 5.394 / B 5.396 | 另有 ~5% 色不平衡未被利用 |
| 逐帧光强 vs 灯距 | corr = −0.669；与 1/d² 形状 corr = +0.697 | 方差的相当部分是**真实物理衰减**（灯距 6.41–8.68 m，方向光模型按设计忽略距离） |
| 最优全局标量的 GT 重建上限 | 前景 PSNR mean 16.32 dB（min 12.06 / max 22.80） | 单方向 Lambertian 解释不了 area light 软阴影/GI/色调映射；标定只能补曝光尺度 |
| `lights.json` 物理参数 | AREA 灯，功率 1800 W，发光面 1.25×1.0 m²，逐帧位置 | 未被利用；物理辐照度估计（面光近似）中位 ≈ 10，与拟合 5.5 同量级，说明 5.5 是含色调映射的曝光折中 |
| 跨数据集 | CV3L 单独标定为 7.8435（见 `output/0817-05-*` 目录） | 标定量不跨数据集移植，每个数据集都要重标 |

**核心问题**：逐帧 ±20% 的曝光偏差不存在于光照参数里，就只能被 albedo / 几何 / 法线吸收——这正是 08.18 报告警告的病理（"让 albedo 或 rotation 去补亮"），而 Stage 1 要恢复的恰恰是 albedo 与法线。

### 1.3 为什么选方案 D（损失级归一化）

候选方案对比（详见 2026-08-24 会话分析；A=逐帧标定表、B=物理归一化、C=可学习逐帧曝光、E=稳健标定改进）：

| 方案 | 主要优点 | 主要缺点 |
| --- | --- | --- |
| A 逐帧标定表（冻结） | 确定性、最小改动 | 仍是逐数据集标定；拟合值混入模型失配 |
| B lights.json 物理归一化 | 物理可解释 | 需补导出灯面朝向；色调映射决定仍需经验缩放 |
| C 可学习逐帧曝光 | 训练中自适应（PBR 分支已有同构实现） | 新增自由度可能继续吸收几何误差，需锚定与消融 |
| **D 损失级归一化（本文）** | **完全免逐数据集标定、天然跨数据集；光度立体/内在分解与 NeRF-W 式曝光补偿的标准做法** | 绝对亮度不可观，需 gauge 锚定；实现需谨慎 |

选择 D 的理由：消除"每个数据集手标一个数"的环节，把曝光尺度问题从**超参数**变成**训练目标内部的不变量**；与现有冻结光强机制正交（渲染器不动），回退成本最低。

## 2. 方案的数学形式

对每张训练图，在**线性空间、前景有效像素**上拟合一个逐图增益：

```
α* = ⟨p̂, g⟩ / ⟨p̂, p̂⟩        （内积遍历有效像素与 RGB 通道）
```

其中 `p̂` 为渲染的线性图（`render_pkg["render_linear"]`，alpha 合成后的线性空间），`g` 为 GT 线性图
（`srgb_to_linear(gt_image)`）。归一化后对 `p̃ = α*·p̂` 与 `g` 计算现有 L1+DSSIM 损失。

性质：

- **尺度不变性**：`p̂ → c·p̂` 时 `α* → α*/c`，`p̃` 不变。训练对全局曝光误差免疫，逐帧光强变化（±20%）不再需要 albedo 吸收。
- **gauge 自由度**：绝对亮度不可观，需要锚定（见决策 D4）。
- **与 5.5 的关系**：训练收敛后 `α* ≈ I_真实帧曝光 / 5.5` 的逐帧统计可直接读出；若未来转方案 A/C，`5.5·α*_t` 就是现成的逐帧光强表初始化。

## 3. 设计决策（逐项：选项 / 推荐 / 理由）

| 编号 | 决策点 | 选项 | **推荐** | 理由 |
| --- | --- | --- | --- | --- |
| D1 | 拟合空间 | 线性 / sRGB | **线性** | 曝光在物理上是线性空间的乘性因子；`render_linear` 已在 Lambertian 路径可用（`gaussian_renderer/__init__.py` 合成后、sRGB 转换前保存） |
| D2 | 增益自由度 | 标量 / 逐通道 RGB | **标量**（逐通道留作开关） | 逐通道差仅 ~5%，先用标量控制变量；`per_channel` 参数预留 |
| D3 | α* 的梯度 | 参与反传 / detach | **detach** | 尺度不变损失对全局尺度梯度为零，让 α* 带梯度只引入噪声；detach 最简单稳定 |
| D4 | gauge 锚定 | 无锚定 / 锚定损失 / albedo 均值正则 | **锚定损失**：总 RGB 损失 = 归一化损失 + `λ_anchor · L1(p̂, g)`（未归一化原损失） | 保留绝对曝光信号，防止 albedo 整体漂移；λ 默认 0.1，可调至 0 做纯不变性消融 |
| D5 | 有效像素 mask | 全图 / alpha mask / alpha+饱和剔除 | **(rend_alpha ≥ τ) & (gt_alpha ≥ τ) & (gt_srgb.max < 0.995)** | τ 默认 0.5，与现有 `photometric_normal_*_alpha_threshold` 一致；剔除饱和像素与标定脚本的 `target < 0.995` 一致（Blender 色调映射高光区乘性模型失真）；白背景情况下背景被 mask 自然排除，无需额外处理 |
| D6 | 退化保护 | — | 有效像素 < `min_pixels`（默认 64）或 `⟨p̂,p̂⟩ < 1e-8` 时**跳过归一化**（本帧回退原损失）；α* 截断到 `[gain_min, gain_max]`（默认 [0.2, 5.0]） | 防止训练早期近黑渲染导致 α* 爆炸、以及空帧除零 |
| D7 | 损失形式 | 归一化 L1+DSSIM / 追加 log-linear 项 | **归一化 L1+DSSIM（复用 lambda_dssim=0.2）**；log-linear 辅助项留作开关、默认关 | 最小改动；log-linear（借鉴 PBR 分支）可作为后续增强 |
| D8 | 评测口径 | 单口径 / 双口径 | **双口径**：主指标 = 固定 gauge（现有 intensity=5.5 渲染+现有 eval，不变）；诊断指标 = 逐图拟合 α* 后的 gain-fitted PSNR | 分解收益来源：固定 gauge 衡量绝对曝光一致性，gain-fitted 衡量形状/材质质量；防止"归一化把指标洗好看但绝对亮度漂了"被掩盖 |
| D9 | 启用方式 | 改默认 / 新参数+预设 | **新参数 `--photometric_exposure_norm`，默认 `none`；注册新预设 `lambertian_exposure_norm`** | 与 0823-01 重构的兼容原则一致：默认关闭、既有实验零漂移 |
| D10 | 启用时机 | 全程 / 延迟 | 提供 `photometric_exposure_norm_start_iter`，默认 0，**建议实验时设 500**（与 `warm_up` 对齐） | 训练最初期渲染近黑、α* 截断在 5.0 仍可能引入抖动，延后至渲染成形后启用更稳 |
| D11 | 作用范围 | 全部 render_mode / 仅 Lambertian | **仅 `photometric_lambertian` 非 PBR 分支** | PBR 分支已有 `raw_global_intensity`+逐帧 `raw_exposure` 机制（`scene/photometric_perlight_pbr.py`），不重复；`original_sh` 分支无物理光照语义，不适用 |

### 4.2 `scripts/loss.py`（核心）

1. 新增模块级函数 `fit_photometric_gain(render_linear, gt_image, rend_alpha, gt_alpha_mask, opt) -> tuple[α, valid_mask, skipped: bool]`：
   - 输入：线性渲染图（C,H,W）、sRGB GT（C,H,W）、`rend_alpha`（1,H,W 或 H,W）、`viewpoint_cam.gt_alpha_mask`（可为 None，无 GT mask 时仅用 rend_alpha）；
   - 按 D5 构造有效 mask；按 D6 判定跳过；按 D1–D3 在线性空间拟合标量 α（`per_channel` 时拟合 3 维）；**返回 detach 后的 α**；
   - 纯函数、无状态，便于单测。
2. 修改 `compute_stage1_loss()` 的**非 PBR 分支**（2026-08-24 时点约 L356–371 的 `weighted_l1/weighted_dssim` 块）：
   - 仅当 `tr.photometric_active and opt.photometric_exposure_norm == "per_image" and tr.iteration >= opt.photometric_exposure_norm_start_iter and tr.photometric_rgb_loss_weight > 0` 时：
     - `p_lin = render_pkg_re["render_linear"]`（Lambertian 路径恒可用）；`g_lin = srgb_to_linear(gt_image)`（`srgb_to_linear` 已在 loss.py 导入）；
     - `α = fit_photometric_gain(...)`；未跳过时：`p_norm = linear_to_srgb(α · p_lin)`、`g_norm = gt_image`（GT 本身不变），用 `(p_norm, g_norm)` 替换 `(image, gt_image)` 计算 L1+DSSIM；
     - 追加锚定项 `loss += rgb_weight · λ_anchor · l1_loss(image, gt_image)`；
     - `linear_to_srgb` 从 `scene/photometric_lambertian.py` 导入；
   - 跳过或关闭时：逐位走现有路径。
3. `audit_loss_terms`：新增键 `"rgb_exposure_anchor"`（置于现有键**之后**，不打乱既有键名与顺序；实施时确认 `audit_loss_gradients` 与 `scripts/plot_stage1_gradient_audit.py` 对键集合是动态遍历，若写死需同步）。
4. `Stage1LossResult`：把本帧 `α*`（或跳过标志）带出（新增字段 `exposure_gain: float | None`），供主循环记录。

## 7. 风险与对策

| 风险 | 机制 | 对策 |
| --- | --- | --- |
| gauge 漂移：albedo 整体尺度自由 | 归一化消除尺度约束 | D4 锚定项（λ=0.1）+ 双口径评测监控 + albedo 目检 |
| 训练早期 α* 抖动/爆炸 | 近黑渲染使 `⟨p̂,p̂⟩` 极小 | D6 截断+跳过 + D10 延迟到 500 iter 启用 |
| α* 吸收几何误差（重蹈"albedo 补亮"覆辙的镜像问题） | 逐图增益容量过大 | 标量增益（D2）+ 截断区间窄（[0.2,5]）+ 与法线一致性损失共训，Step 2 判据 1 直接监控 |
| 色调映射高光区乘性模型失真 | Blender GT 经 Filmic/AgX | D5 剔除饱和像素（阈值与标定脚本一致） |
| 与 `photometric_rgb_loss_weight=0`（N0 oracle）交互 | RGB 损失整体关闭 | 门控条件含 `photometric_rgb_loss_weight > 0`，N0 预设不受影响 |
| audit 键顺序被破坏 | 梯度审计依赖键顺序 | 新键只追加在末尾 + Step 0 等价冒烟覆盖 |

## 8. 与后续路线的衔接

- **→ 方案 A（逐帧标定表）**：Step 2 收敛后的逐帧 `5.5·α*_t` 即现成的逐帧光强表，可作为冻结表方案的输入或初值；
- **→ 方案 C（可学习逐帧曝光）**：若 D 的增益统计显示逐帧残差仍有结构（如与灯距强相关），再以 α* 表初始化 `raw_exposure[T]`；
- **→ 跨数据集**：D 生效后，新数据集无需先跑 `calibrate_directional_light.py` 定光强即可起训（5.5 只影响收敛初期的 gauge，锚定项会自动校正）；这是本方案相对 A/B/C 的独有优势，建议首个跨数据集验证放在 CV3L（GT 为纯 Lambertian，标定最干净）。

## 附录 C：方法学参考

- 逐图曝光/白平衡补偿：NeRF-W（Martin-Brualla et al., 2021）的 per-image appearance embedding 思路的标量退化形式；
- 尺度不变损失：scale-invariant log loss（Eigen et al., 2014 深度估计；本仓库 PBR 分支 `log_linear` 项同族）；
- 光度归一化/内在分解：photometric stereo 中对逐图光照尺度归一以解耦反照率与光照的标准做法；
- 仓库内部先例：`photometric_perlight_pbr.py` 的零均值化逐帧 `raw_exposure` + L2 正则（`lambda_photometric_pbr_exposure`）。
