# 新增明暗轨迹投影代理主光估计

新增 `scripts/fit_dl_shadow_tracks.py`。从默认表面轨迹中识别稳定接收平面，以训练时间分位数归一化同一表面亮度，建立明暗约束；用预测物体的离散投影对512个候选主光计分，输出独立解与时间动态规划解。未知光入口没有GT路径参数，既有RGB解仅作同代理评测对照。

本入口不更新几何／形变／材质，不替代最终Stage2。忽略粗平面自遮挡、离散栅格与经验明暗阈值均是明确近似，需要实测可靠性；不能预先写成功。验证结果运行后追加。

首次运行后修正独立对照的支持不足时刻：仅在有效训练时刻选候选，其他时刻插值，避免全零代价默认方向。原实验不覆盖。总控T05_initial_snapshot的复制在修正后完成，因此该副本不是首版执行前快照；首版以精确逆补丁重建为fit_dl_shadow_tracks_reconstructed.py，来源限制明确写入provenance.json。新增geometry-state和brightness-reference两个显式消融开关，默认行为保持原动态几何和canonical亮度归一化；只作单因素受控实验。

新增 `scripts/preview_dl_shadow_tracks.py`，固定早中晚三个保留时间显示同支持上的标签、基线、新投影及错误。离线评测器删除硬编码600步的协议描述，预算以源结果为准。完成两场景3种子、单因素消融及动态保留RGB随机替换检查：灯向逐元素不变。结果与局限见报告1015-04；未改动实际几何训练路径。
