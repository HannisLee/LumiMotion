# 隔离评价全帧与固定局部只读目检接触表

新增`LIHAN/scripts/dynamic_v3_review_pages.py`，只读取已完成评价的PNG/manifest，写入全新目录，不改冻结评价、指标、模型或选择。适用于原始150帧图像的逐帧缩略总览及固定15TEST人体/腿/足/鞋四类局部原尺寸面板。

## 接口及范围

```bash
OMP_NUM_THREADS=4 /home/han.li/miniconda3/envs/lumimotion-ushas/bin/python -m LIHAN.scripts.dynamic_v3_review_pages --evaluation <已完成评价目录> --output <总控/eval_only/manual_review_pages_v2/模型名>
```

每一连续类别按1–50、51–100、101–150三页，每页50帧，保留原面板全部内容、等比缩放后补黑边。每一人体/腿/足/鞋分区按固定15TEST、四行类别、每页五帧生成12页，保持原1024×288行尺寸；缺失时保留帧槽并标注manifest原因。每个新目录独立manifest记录输入/输出SHA、代码SHA、完整argv与人工PENDING。不同类别重复读取锁定首次输入SHA，结束复核无变动；OpenCV线程固定4。禁止覆盖既有目录。

缩略图不能代替细节，局部只限15TEST；Mesh/GT只15TEST，其余135帧明确未重建。模型gate不是GT运动分割。接触表不包含视频实时播放，不能宣称已经播放视频或由缩略图证明抖动改善。
