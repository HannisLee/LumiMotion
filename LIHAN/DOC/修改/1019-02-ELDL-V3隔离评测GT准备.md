# ELDL-V3 隔离评测 GT 准备

新增 `LIHAN/scripts/eldl_v3_prepare_eval_gt.py`，配套协议为 `LIHAN/DOC/报告/1019-02-ELDL-V3固定评测协议.md`。本修改只准备评测几何、相机一致性和语义分区，不执行训练或模型评测，不读取灯光和材质节点参数，也不向训练输入目录写入。

旧几何准备算法可复用，但旧Blender导出器的scene_audit会导出材质和灯值，新入口独立实现必要的evaluated mesh提取，仅记录几何、单位和非光照色管元数据。输出硬限制为 `output/1019-01-LH-static-jumpingjacks-ELDL-V3-总控/eval_only` 子目录，禁止覆盖已有输出；失败保留网格、深度、统计和日志。

GT取全部150帧相机、世界顶点、拓扑和逐角点法线哈希，验证真实静态几何；逐像素中心+0.5未归一化射线求交给出正camera-Z和射线距离。每帧保留物体ID、人体/腿/足/鞋/平台语义、Alpha、EXR法线以及c2w/K。Alpha只使用原albedo已有16位透明度，颜色不统计、不保存。GT只供评测，不产生训练初始化依据。

分区采用对象名和骨骼顶点组，足组优先、三角面相关组权重占比≥0.5；缺组或零面明确NOT_AVAILABLE，禁止用高度带冒充解剖标签。具体定义见固定协议和输出partition_definition.json。深度准备验证Alpha/首次射线命中IoU≥0.97、内部区网格与EXR无向法线平均误差≤3°；这些是GT一致性检查，不是模型质量分数。
