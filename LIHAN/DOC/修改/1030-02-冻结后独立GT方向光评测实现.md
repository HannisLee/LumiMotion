# 冻结后独立GT方向光评测实现

日期：2026-10-30。服务器：ushas。环境：lumimotion-ushas。

## 范围与隔离

新增 `LIHAN/scripts/static_rgb_light_evaluate.py`，仅用于方法、参数、Stage 1 基线及预测全部冻结后的独立评测。实现与验证阶段未打开 `lights.json`，未读取历史角度误差、GT 法线、深度或 Alpha。评测不训练、不修改预测，也不按 GT 误差选择 E0—E4。最终验收方法必须在冻结清单中预先指定。

## 方向约定的静态代码证据

原始数据目录为 `data/LH-data/static/LH-static-jumpingjacks-ELDL-V3`。仅检查该目录 `_export` 中的 Python 导出代码：

- `skill_exporter_original.py:490-491` 的 `surface_to_sun_dir` 将灯局部正 Z 轴左乘灯的世界旋转矩阵并归一化。
- 同文件 `write_lights_json` 在顶层每帧 `light_dir_world` 写入该方向，帧键采用四位、从 1 开始。
- `run_export.py:151` 对 SUN 灯调用同一函数；第 157 行明确约定为“从表面指向太阳的单位向量”，着色使用 `max(dot(normal, light_dir_world), 0)`。

因此评测直接比较预测与顶层 GT 的世界坐标表面指向灯方向。仅归一化，无取负、坐标变换或试探性比较符号。

## 冻结清单协议

输入默认为 `output/1030-01-LH-static-ELDL-V3-RGB方向光初始化/predictions.npz` 和同目录 `freeze_manifest.json`。

预测必须含 `frames`（严格按顺序为 1—150）及 `E0`—`E4`（各为 150×3 的有限单位方向，模长误差小于 0.0001）。漏帧、重复帧、乱序、零向量、非有限值均报错。

冻结清单必需字段：

```json
{
  "frozen_at": "冻结时间的ISO字符串",
  "GT_read_before_freeze": false,
  "final_method": "E4",
  "coordinate_system": "world",
  "direction_convention": "surface_to_light",
  "frames": [1, 2, "示意省略，实际必须完整到150"],
  "predictions_sha256": "预测文件SHA256",
  "files": {
    "方法代码.py": "SHA256",
    "冻结Stage1模型.pth": "SHA256"
  }
}
```

`files` 的路径相对仓库根目录或为绝对路径，至少含 Python 方法文件及一个 `.pth`、`.pt` 或 `.ply` 基线模型。核验全部 SHA256 后才允许读取 GT；禁止把 `lights.json` 放入核验文件列表。协调任务负责记录无 GT 基线选择依据和未按角度误差调参声明。

## 命令与产物

不读取 GT 的冻结核验：

```bash
conda run -n lumimotion-ushas python LIHAN/scripts/static_rgb_light_evaluate.py --validate-freeze-only
```

收到冻结完成信号后才可执行：

```bash
conda run -n lumimotion-ushas python LIHAN/scripts/static_rgb_light_evaluate.py --allow-gt-evaluation
```

输出为上述实验目录内新建的 `evaluation` 子目录；已有目录一律拒绝覆盖。完成冻结核验后、打开 GT 前，在冻结清单所在目录排他创建 `gt_evaluation_receipt.json`。已有收据即拒绝再次读取 GT，更换输出目录也不能绕过；失败同样保留收据及已有产物，禁止自动重开。只有故障修复且有明确记录的人工批准才能另行处理，本轮正常流程不重开。产物包括：

- `results.json`：E0—E4 各自 Mean、Median、P90、误差不超过 5° 的帧数与比例、完整 150 帧计数，以及预测、冻结清单、代码和 GT 哈希；仅按冻结的最终方法判定 `PASS` 或 `FAILED`。
- `per_frame.csv`：150×5 条逐帧记录，包含预测、GT、角度误差及阈值判定。
- `angular_error_curve.png`、`angular_error_cdf.png`、`direction_components.png`、`failure_cases.png`：误差曲线、累计分布、最终方法与 GT 的方向分量、最终方法最差 12 帧。
- `failure_cases.json`：最差 12 帧的预测、GT 与误差；这些定位信息不用于修改预测。仅凭角度误差不能区分法线偏差、阴影、材质混淆或不可辨识性。

脚本运行日志由主任务重定向到同一实验目录，实验 README 的渲染命令、基线迭代、图表目检及完整验收记录由主任务汇总。
