# 静态 DL 同起点遮挡 XYZ 分流与相机旁路审计

## 证据与待验证假设

开始本轮前已重读 Goal 与训练 1011-07／08／09。10k 原完整 15 帧 GS／Depth／Mesh MAE：T01 为 `11.2572/22.8365/16.8531°`，T02 为 `6.1876/11.3795/7.9344°`，T03 为 `6.6042/12.7803/8.6180°`。T02/T03 仅有可见度差别，当前停止可见度梯度的 T03 尚无收益；T01/T02 是组合改动，不能单独归因光方向。三组均未达标。

新增 T02 35k 原完整评测为 `8.00334/18.56850/13.99961°`，三项较 10k 均退化；预测深度绝对误差 `0.06727`，10k 为 `0.03536`。最终 35k 必须如实保留，不能只用较佳中间检查点替代它；后续 Stage2 起点仍需依据 20k/30k 和 T03 最终评测选择。

反照率均值为预测 Gaussian 的各颜色通道均值，没有面积或像素加权；点数改变时不能当作图像平均材质的严格同分布比较。补充 T02 20k 原完整评测为 `7.88409/18.61049/14.22656°`，说明明显退化在 10k→20k 已发生，而 20k→35k 的最终差异较小；这仍不把原因直接归于增密或某一正则。

normal 乘权重 `0.1` 后由约 `0.00305` 上升至 `0.00761`，distortion 乘 `1000` 后约 `0.00009`。这支持“photo 基本不改善、法线一致性反而恶化、光强和反照率持续漂移”的观察，但不能证明某个梯度项是唯一原因，也不能说 normal 正则已经使几何收敛到更一致的错误解。增密在 20k 停止后点数固定，退化时段需完整中间 MAE 定位。原 DL 元数据声明 Standard sRGB，没有证据归因未逆 AgX/Filmic。

1011-18 的单高斯数值探针已证明平滑区原生 trace 的 XYZ 局部导数正确，同时确认 `.97` Alpha 饱和及 bias 漏遮挡限制。本轮增加完整相机合成的路径审计，仍不把“代码可微”当作“重建必然有效”。

## 最小两组对照

共同起点为同一只读物理 checkpoint 的 PLY、零几何头 deform 和训练 RGB 光强；两组使用相同相机顺序、优化器初值、学习率、损失和更新预算。冻结点数、尺度、透明度、共享形变网络和全部增密行为。此处没有正式命名或启动 T04/T05，参数与起点待最终指标确定。

两组前向均使用同一 Lambert + 原生可见度。共同 RGB 接收路径保留真实四元数 `q→normal→n·l`、反照率和 RGB 学得光强；可见度停止反传，主相机 XYZ、q、尺度和透明度合成均停止反传。共同几何正则独立使用原图 RGBA Alpha、预测 GS/depth 法线一致性和深度畸变，允许真实 XYZ/q 更新。

- **control**：只有共同接收路径和几何正则。
- **split**：额外允许同一 RGB 残差通过可见度更新遮挡 Gaussian XYZ；接收点／光方向／遮挡 q／scale／opacity／材质／光强在该路径全部 detach。

颜色表达为 `C_recv + (C_shadow - C_shadow.detach())`。括号内的前向值精确为零，仅加入遮挡路径的导数；全程只计算一份 RGB loss，不能给 q/材质/光强重复加损失。角色属于一条光线路径，同一个 Gaussian 可以在不同光线上分别接收和遮挡。

## 新增文件及保存契约

- `scene/static_dl_shadow_split.py`：原生 BVH 重建、遮挡 XYZ 可见度路径、相机合成阻断、独立真实几何正则和原生光栅 provenance 检查。
- `scene/static_dl_shadow_split_audit.py`：选定真实 checkpoint 后，用第一张原训练相机检查允许/禁止路径；没有模型更新，失败阻止正式训练。
- `scripts/train_static_dl_shadow_split.py`：同起点两组 Stage2 入口；所有科学参数必填，没有默认起点/预算。只加载 `transforms_train.json` 的 135 张原训练图和对应方向，不加载测试图片；不创建形变网络，不调用增密/裁剪/opacity reset。
- `LIHAN/scripts/goal_shadow_split_probe.py`：10 个解析 Gaussian、64×64 相机的完整数值审计，无数据集读取、优化器、模型训练或 MAE。

旧 `scene/static_dl_photometric.py`、`scene/gaussian_model.py`、`gaussian_renderer/__init__.py`、`scripts/train_static_dl.py` 保持不变。正式入口要求标准 bootstrap 的原生光栅 SHA。模型继续保存普通 PLY 和原样零头 `deform.pth`，保存普通 `static_dl_training.json`、`static_dl_lighting/iteration_N/lighting.json`；前向与原 `lambertian_visibility` 相同，另写 `shadow_split_training.json` 描述梯度开关。评测仍需同 checkpoint fresh BVH 的真实 parity，不仅检查字段兼容。

原生光栅会建立独立屏幕空间梯度代理；新入口将其命名为未使用诊断量，不优化该张量，也不将其梯度送入增密统计。共有几何正则允许的 XYZ/q 梯度与 RGB 相机旁路严格区分。

## 数值审计和执行历史

第一轮：`output/smoke_test/1011-08-staticDL-完整相机梯度分流`，GPU1，退出码 **1**，结果和源码快照完整保留。

- control/split 的 RGB、linear RGB、Alpha、world normal 和 surface depth 最大差全部为 `0`；与旧物理 renderer 的五项差也全部为 `0`。
- 纯 RGB 下，control 的 XYZ 梯度为 None，q／material／light 梯度非零；split 的 XYZ 梯度范数 `0.0189553`；q／material／light 两组最大差不超过 `2.33e-9`。
- split XYZ 等于独立 shadow-only XYZ 的相对误差 `1.87e-7`；遮挡路径禁止参数均为 None。
- 独立相机 Alpha/depth/normal 合成对被禁止参数的梯度均为 None 或精确零；重新启用相机 XYZ/q 的负对照有非零梯度。
- 几何正则的 XYZ/q 梯度有限非零，其他参数无梯度。
- 唯一失败项是“加共有几何正则后 q 最大绝对差必须 <1e-7”：实测 `6.56e-7`，q 梯度范数约 `0.258`，XYZ 差分相对误差 `4.36e-5`。这不能标整体验收 PASS；新增相同 control 重复 backward 基线，区分浮点归约差与路径差，使用明确的 FP32 绝对及相对容差复核。

第二轮：`output/smoke_test/1011-09-staticDL-相机分流浮点复核`，经 trainer 协调并即时核验 GPU1 余量 `26274 MiB` 后执行，PID `2004350`、耗时 `1.079 s`，退出码 **0**，五项检查全部 **PASS**，结束后立即释放 GPU。共有 q／material／light 比较同时要求最大绝对差 `≤2e-6` 且相对 L2 差 `≤1e-5`，XYZ 差分相对误差 `<1e-4`。这些量级远不足以掩盖 RGB 梯度重复累加；保留第一轮失败，不改实际算法来迁就比较。

- 同一 control 重复反传：XYZ 最大差 `1.31130e-6`，q 最大差 `3.72529e-7`，说明重复相同计算本身存在 FP32 归约差。
- control/split 共有 q 最大差 `5.81145e-7`，相对 L2 差 `2.44566e-6`；material/light 相对差分别 `6.47785e-7/3.09204e-7`。
- 加同一几何正则后，两组 XYZ 差分与独立遮挡梯度相对误差 `2.37046e-5`。
- 五类前向结果及与旧物理 renderer 的 fresh BVH parity 仍全部最大差 `0`。
- 其他允许/禁止路径及负对照全部 PASS，完整张量范数、来源 SHA、命令、日志和源码快照保存在两个独立输出目录。三个新增入口/模块和真实 checkpoint 审计模块均通过 `py_compile`。

两轮完整命令在各自 `command.sh` 和 `README.md`；仅是解析数值审计，无训练 source/model/iteration，无图片视频、四类目检不适用。正式训练入口另提供 `--audit_only`，会在模型输出目录保存 `initial_checkpoint_gradient_audit.json` 后退出，不建立优化器或更新参数；当前尚未对真实 checkpoint 执行该模式。

第三次集成核验：`output/smoke_test/1011-10-staticDL-分流审计入口集成验证`，仍是解析场景，没有读取真实 checkpoint 或数据集；实际退出 `0`、耗时 `1.158 s`，六项全部 **PASS**，新增的真实 checkpoint 审计 helper 的 11 个内部路径断言全部通过。q/material/light 最大差为 `3.73e-9/5.12e-9/7.45e-9`，XYZ 差等于独立遮挡路径的相对误差 `4.61e-7`；重新开放相机 q 后与 control 的 q 梯度差为 `0.005956`，说明负对照确实增加相机旋转旁路。GPU1 使用前再次核验余量并获 trainer 窗口，结束即释放。

此后 helper 仅补充记录真实输入的初始 photo 与预测 visibility 统计字段，运算路径不变，语法检查通过。第三次执行源码已按其 result.json SHA 原样保留。主训练入口本轮只完成实现与语法检查，尚未执行实际图像训练；不能把上述解析审计称为真实 checkpoint 冒烟或保存重载验收。

## T03 最终结果补充与起点权衡

评测 Agent 返回 T03 35k 原完整 15 帧 `23.03010/33.11791/29.22880°`，coverage 约 `0.99870/0.96664/0.98974`，预测深度绝对误差约 `0.22467`。原协议完整性 PASS、三阈值 FAILED；最终物理渲染及 fresh parity 仍由评测 Agent 独立完成。

T03 的 10k/20k/30k/35k 末 1000 步日志均值：photo 为 `0.01064/0.02078/0.02157/0.02358`，normal 为 `0.02450/0.06371/0.09728/0.13075`，平均可见度为 `0.41790/0.38159/0.40759/0.41475`，光强为 `8.342/8.242/10.355/11.767`；20k 后点数固定 `112977`。因此不能说当前退化换来了更好的训练图像拟合，也没有平均可见度持续塌陷的证据。局部错误可见性、RGB 合成几何旁路、法线与深度的相互反馈等仍需受控测试区分。

共同起点不应自动取坏的 35k。B10k 的 MAE 更低，但它未学可见度，接入本轮前向会首次启用 V，初始材质/光强存在适配风险；C10k 略差，却已采用相同完整前向和较高光强，对梯度路径最小消融更直接。建议先对两个 10k 做无优化 audit_only 并记录初始 photo/visibility，再选择共同起点；不据此增开多个正式配置。正式两组可采用短程诊断预算，具体步数与学习率须先落训练计划。
