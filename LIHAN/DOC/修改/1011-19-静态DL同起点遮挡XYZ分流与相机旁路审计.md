## 最小两组对照

共同起点为同一只读物理 checkpoint 的 PLY、零几何头 deform 和训练 RGB 光强；两组使用相同相机顺序、优化器初值、学习率、损失和更新预算。冻结点数、尺度、透明度、共享形变网络和全部增密行为。此处没有正式命名或启动 T04/T05，参数与起点待最终指标确定。

两组前向均使用同一 Lambert + 原生可见度。共同 RGB 接收路径保留真实四元数 `q→normal→n·l`、反照率和 RGB 学得光强；可见度停止反传，主相机 XYZ、q、尺度和透明度合成均停止反传。共同几何正则独立使用原图 RGBA Alpha、预测 GS/depth 法线一致性和深度畸变，允许真实 XYZ/q 更新。

- **control**：只有共同接收路径和几何正则。
- **split**：额外允许同一 RGB 残差通过可见度更新遮挡 Gaussian XYZ；接收点／光方向／遮挡 q／scale／opacity／材质／光强在该路径全部 detach。

颜色表达为 `C_recv + (C_shadow - C_shadow.detach())`。括号内的前向值精确为零，仅加入遮挡路径的导数；全程只计算一份 RGB loss，不能给 q/材质/光强重复加损失。角色属于一条光线路径，同一个 Gaussian 可以在不同光线上分别接收和遮挡。

## 后续候选：触顶 RGB 通道的单边约束（未实现、未训练、未验证）

本节仅分析候选，不改变正在进行的 T04/T05 单因素对照，也不预先决定后续配置。根代理只读原 135 张训练 image RGBA 得到：8bit 实际训练读数中，前景任一通道满码占 `53.9346%`、三通道全满码占 `21.0959%`；原 16bit image 中对应 `53.5274%/20.5393%`。这说明满码现象主要不是 16→8bit 量化引入，但尚未定位渲染链具体在哪一层达到上限，不称为已证明的物理传感器饱和。

证据为 `output/1011-09-静态DL-Goal训练总控/diagnostics/rgb_upper_limit/summary.json` 和 `raw16_summary.json`，输入仅原训练 RGB 自身 RGBA，无 GT 材质、光强或阴影。Standard sRGB 元数据与当前传递函数一致；不能因此推导所有满码像素都符合无镜面 Lambertian 模型。

### 一个参数无歧义的首个候选

沿用当前 sRGB 域预测 `p=linear_to_srgb(render_linear.clamp_min(0))`，**不增加预测上界 clamp**。目标 `y` 为现有 loader 输出的原训练 RGB，`a` 为其自身 Alpha。逐通道固定观测掩膜为 `M=(y==1.0) AND (a>0.5)`，Alpha 广播到三个颜色通道；只对精确满码触发，不把统计用的 `>=250` 另行设成训练阈值。

首个候选固定下界 `b=1.0`（sRGB 域），不针对 GT 或评测结果调阈值，也不添加可学习曝光/白平衡变量。它把满码视为名义显示上界处的下界观测；8bit 最后一个量化区间内的微小误差及具体截断层仍是此简化的边界，不能称严格恢复了原始线性辐亮度。

逐通道残差定义：

```text
r_raw = p - y
r_censored = where(M, minimum(p - 1.0, 0.0), r_raw)
signed = mean_channels(r_raw.detach())
```

为了只改变触顶通道是否提供双边约束，首个候选的鲁棒权重仍按原 `signed` 计算：`signed>0.08` 时权重 `0.25`，`signed<-0.08` 时 `0.5`，其他为 `1.0`；背景仍按原实现权重 `1.0`。权重停止梯度，不改成由新残差重新分组。损失为 `mean(sqrt(r_censored²+1e-6)*weight)`，保留全图固定分母，不除以未触顶通道数，不筛除满码像素或改变覆盖率。几何损失、光强参数化、相机路径、V 路径和保存/评测完全不变。

这是一个观察模型假设：满码通道只要求预测足够亮，不把更亮的有效预测继续拉回 1；没有把这些通道当作完全无信息。预测低于下界时仍有提高亮度的梯度。未满码通道继续提供原双边残差，因而错误过亮预测仍能纠正。

不能直接将全图预测 `clamp_max(1)` 后照常比较：对于 `y=0.6,p=1.3`，这种做法产生非零误差却把预测梯度截成 0，使一个未满码观测无法纠正过亮模型。上述单边约束只由固定观测掩膜触发，没有这个额外死区。

### 必要的数值正负对照

1. 标量方向：`y=1,p=0.8` 必须保留负导数；`y=1,p=1.3` 导数必须精确为 0；`y=0.6,p=1.3` 必须保留正导数；`y=0.6,p=0.5` 必须保留负导数。常数 Charbonnier 底值不要求损失本身为 0。
2. 错误方案负对照：对 `y=0.6,p=1.3` 显示全图 `clamp_max(1)` 的导数为 0，而单边候选非零；不能只验证满码预测变亮后 loss 下降。
3. 混合通道：如 `y=(1,0.4,0.7),p=(1.3,1.2,0.2)`，只有红通道失去上界惩罚，绿/蓝通道仍有相应正/负导数；不能按像素任一通道满码后屏蔽整颗 RGB。
4. 完全未触顶的输入必须与原损失及其全部参数梯度一致；掩膜只由观测产生并停止梯度，不能依赖预测亮度动态把困难观测移出监督。
5. 接入真实 checkpoint 后重复本轮完整路径审计：同一固定输入的 control/split forward 不变，q/material/light 导数不重复累加，禁止的相机/材质/光强旁路仍为 None/0。真实训练仍只读原 135 帧。

### 需要同时保留的诊断和判定

后续若决定实施，应只开“原损失／单边候选”两个同起点、同路由、同预算配置；不同时加入 H 权重、镜面项、光强锚定或新几何正则。完整 15 帧三类 MAE 和原覆盖率仍是验收标准。

训练侧同时记录：未触顶通道 RGB 误差、满码通道下界违反率、预测未 clamp 的线性强度 `p95/p99/max`、预测超过名义显示上界的比例、训练 RGB 光强和预测 albedo 的分布及边界比例。两组用相同的固定观测掩膜作这些诊断；不得把诊断子集替代全量评测。单边约束可能使光强/材质的尺度歧义更明显，若只出现亮度上尾或光强漂移增大而几何不改善，应拒绝把 loss 降低称为收益。

局部方向 H 的后续诊断应区分“未触顶的近似等式观测”和“满码的下界观测”。后者只有违反下界时提供当前有效导数，不能当成恒定精确辐亮度去累加相同的信息量；大量满码会降低实际法线可观测性。此处尚未实施 H 训练权重，也不以该解释宣称触顶是当前几何退化的唯一原因。
