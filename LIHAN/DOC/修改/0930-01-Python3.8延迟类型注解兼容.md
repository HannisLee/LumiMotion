# 0930-01 Python 3.8 延迟类型注解兼容

日期：2026-09-30

## 修改原因

官方 LumiMotion 安装说明固定使用 Python 3.8.18。当前工作区 Stage 1 损失模块包含 `torch.Tensor | None` 注解，Python 3.8 在导入时会实际求值该表达式并抛出 `TypeError`，导致训练在初始化前终止。

## 修改内容

- 在 `scripts/loss.py` 加入 `from __future__ import annotations`，使类型注解延迟求值，兼容官方 Python 3.8 环境。
- 不改变训练损失计算、优化参数、数据加载或渲染行为。
- 首次启动失败日志保存在 `output/0930-01-jumpingjacks150_v5_spec32-official_pipeline/logs/chapelday_goldenbay_jumpingjacks150_v5_spec32_stage1_attempt1_startup_failure.log`；重跑使用新的阶段日志路径，保留初次失败证据。

## 验证

通过后续 jumpingjacks 原生训练命令验证模块导入及实际训练启动；验证结果记录在对应实验 README。
