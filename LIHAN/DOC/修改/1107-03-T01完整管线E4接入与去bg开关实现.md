## 5 评测与监测实现要点

- 口径：400×400 黑底全浮点 sRGB；PSNR 以 float64 计算并用 NumPy 独立复算校验（差 >1e-4 dB 报错）；SSIM 用 `utils.loss_utils.ssim`；LPIPS 用 `lpipsPyTorch`（vgg），权重不可用时该列记 None 并在 `lpips_note` 写明原因；前景 PSNR、包围框 SSIM/LPIPS 沿用 `render_stage2.evaluate` 口径。`torch.manual_seed(--seed)`。
- 分量探针：`install_probe` 在 `install_evaluation()` 之后替换 `render_ir.rendering_equation`，复刻 `stage3_el_eldl_mixed.equation` 的合成逻辑（环境分支保留一次 SH 间接，SUN 分支 `wo_indirect=True`），额外记录环境/SUN/间接能量、环境可见度 V、SUN 可见度和 `s = cos·V_sun`。合成输出与原函数同式，只记录。
- M1-M6 按规划第 6 节实现，旗标阈值全部取自预注册；各模型用自己的 V 与 s 分层。

## 7 遗留问题与需裁定事项

1. **冒烟 A 的几何 warmup**：`validate_pbr_geometry` 要求 `warmup < iterations-load_iter`，默认 2000 与 24 循环冲突。`run --smoke A` 对 E1/E2 默认追加 `--pbr_geometry_warmup 8`（可用 `--geometry-warmup` 改），保证冒烟 A 也走通几何代码；预注册命令不含此项。规划未写明，属实现层处理，请确认。
2. **M5 像素版为 N/A**：规划要求“渲染法线相对 B00 的逐像素角度并按 V 分层”，但评测入口不渲染 B00 法线（B00 无 `stage2_config.json`），逐 Gaussian 没有 V。已实现逐 Gaussian 旋转法线相对 B00 的 mean/p50/p90/p99 与 ≥59° 占比，M5 旗标改用“全体 p90 变化量 E2−E1 >2°”，在 JSON 中注明 `flag_basis`。如需像素版，需要为 B00 追加一个只渲染法线的评测入口。
3. **M1“受光档差异”歧义**：规划原文“受光档”为 s≥0.05（含全部 V）。旗标按原文用该档；同时输出“受光且 V≥0.8”的对照档作补充（`lit_highV_relative_change_supplementary`，不参与旗标）。若真实数据里受光档混入大量低 V 像素，原文旗标可能偏钝，由 analysis 解读。
4. **M3 比值条款**：“|mean| 达到 E1 的 2 倍”在两者都接近 0 时会被噪声触发（合成测试中已遇到）。按预注册原文实现，未加最小量级下限；analysis 报告时请同时看均值绝对值。
5. **TEST 方向来自 E4（D3）**：E4 拟合用过全部 150 帧 RGB（含 TEST 视角），汇报须披露。
6. **N1 首次与混合光组合**：门禁放宽后几何微调未在真实训练中验证，依赖冒烟 B 的预注册回退。
