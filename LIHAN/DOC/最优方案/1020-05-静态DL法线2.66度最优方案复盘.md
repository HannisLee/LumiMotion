# 静态 DL 法线 2.66° 方案：训练链路、损失、机制与边界复盘

整理日期：2026-10-20  
适用场景：`LH-static-jumpingjacks_DL_V2` 静态 DL、已知训练光方向、Stage1 几何与着色联合优化  
主要来源：1011-02 两度目标、1012-05 两度实验归档、1012-09 增密配对报告、1012-10 中间检查点轨迹审计。

## 结论先读

目前记录中最低的单一模型 GS Normal MAE 是 **F-T04@16500：2.6638576134°**。同一检查点的 Depth Normal MAE 为 **5.4699504733°**，Mesh Normal MAE 为 **4.1798230593°**。它从 G2-T06@16000 继续训练 500 次得到，沿用原损失和原增密路线；它不是 Stage2 结果，也没有完成鞋尖和脚掌的三维恢复。

静态 EL 的精确参考为 GS／Depth／Mesh `3.50676425°／7.35467544°／5.45750273°`（常用验收显示为 `3.51°／7.35°／5.46°`）。T06 和 F-T04@16500 的三项 MAE 均低于这条 EL 参考；两度 Goal 的 GS `<2.00°` 则仍未达到。

G2-T06@16000 的三项为 **2.6683778384°／5.4045777992°／4.2084872870°**。相较 F-T04@16500，它的 GS 高 0.00452°、Depth 低 0.06537°、Mesh 高 0.02866°。因此，按 GS 单项选 F-T04@16500，按更低 Depth 选 G2-T06@16000；现有数据没有一个在三项上全面支配另一个的唯一“综合最优”。

这条 2.6° 结果线的关键设计是：保留静态方向光、鲁棒 RGB、Alpha、expected-depth 法线一致性和 distortion 的联合目标；在自然 opacity reset 之前照常训练，reset 之后只切断 normal loss 到 opacity 的梯度；随后以原增密规则短程续训，并从已保存检查点中保留早期低误差点。它把法线优化对几何位置、旋转和尺度的作用留下，同时避免 normal 项在 opacity reset 后继续单独压低透明度。

这是一项**Stage1、单种子、已知训练光方向**的静态结果。没有完成 GS MAE <2° 的新 Goal 核心目标，也没有通过鞋足完整性验收。数值低于静态 EL 参考线，不能据此称为完整几何恢复或通用最优方案。

## 1. 名称和结果口径

这里的“2.6°”是 GS 渲染法线的全测试集 MAE，不是三类法线都约 2.6°。三类指标分别为 GS Normal、Expected-depth Normal、Mesh Normal；三项必须来自同一模型检查点，不能把不同模型的单项最低值拼起来。

还要区分两个同名编号体系：

- **G2-T04** 是两度 Goal 中“reset 前阻断 normal→opacity”的对照。
- **F-T04** 是足部增密实验中“原增密路线”的实验。本文提到 2.6639° 时，指 **F-T04@16500**。

法线评测沿用原完整 15 张测试图（帧 10、20、……、150）、固定掩膜、固定像素加权 MAE 和固定缺失像素处理；协议 SHA256 为 `7cf1e7f6e1ce7f223319899febdfb1d443440add68cddee191fe5bf47e1646be`。训练只加载原 135 个 TRAIN 视角。GT 法线、深度、材质、阴影、语义对象和 15 张测试图都没有进入训练监督；已知训练光方向作为物理着色条件使用，GT 几何只在离线评测中使用。

本方法没有训练 Stage2 外观模型。T06 和 F-T04 都属于静态 Lambertian 方向光下的 Stage1 几何／法线优化；不是完整 PBR 材质恢复，也不是未知光估计。

## 2. 2.6°检查点的完整训练谱系

```text
静态 DL 随机初始化
  └─ T13 Stage1 @10000
       └─ G2-T01 纯直射续训 @12000
            └─ G2-T03 normal→opacity 全梯度控制 @14000
                 ├─ G2-T05：跨 15000 reset 后继续 full @16000（对照）
                 └─ G2-T06：跨 15000 reset，15001 起 detach_opacity @16000
                      └─ F-T04：原增密路线续训，保存 @16500/@17000/@17500/@18000
                           └─ 当前最低 GS 保存点：@16500
```

各段的作用和训练事实如下。

| 阶段 | 起点与更新 | 主要设置 | 结果与作用 |

每个续训段从模型资产重新初始化优化器，Adam 动量从零开始。因而这是“参数检查点接续、优化器状态重建”，不是保留完整 Adam 轨迹的无缝续跑。F-T04 也清零了增密累计统计。F-T04@16500 是 18000 训练轨迹中保存的中间点，不是另外训练 500 步后终止的独立实验。

## 3. 训练渲染和物理前向

每张训练图只使用对应方向向量，不读入光源能量、颜色或位置。模型从训练 RGB 学习每个灯槽的正光强，并用当前预测 Gaussian 建立 BVH 来估计直射可见度。漫反射着色的核心形式是：

\[
 C_{linear}=\rho_{linear}\,\frac{1}{\pi}\sum_l I_l\,V_l\,\max(0,\mathbf n\cdot\mathbf d_l),
\]

其中 \(\rho\) 是线性域反照率，\(I_l\) 是学习到的正光强，\(V_l\) 是预测几何得到的可见度，\(\mathbf d_l\) 是训练集提供的单位方向。该轮环境底项固定为 `ambient=0`。可见度本身在 `no_grad` 路径计算，所以 RGB 几何梯度不会穿过 BVH 遮挡判定；RGB 仍通过漫反射余弦、Gaussian 光栅合成和反照率对可训练参数反传。

输出在 sRGB 域与原训练 RGB 计算光度残差；着色、反照率和漫反射计算经过 sRGB/线性域转换。数据加载器只构建 135 个训练相机，测试图不加载到训练进程。`resolution=2`，白背景关闭，几何变形头保持全零并冻结；优化的是共享 canonical Gaussian 几何，不优化时变几何或时变颜色。

## 4. 总损失及每一项的准确含义

正式训练里使用的合成式为：

\[
L=L_{photo}+0.1L_{alpha}+0.1L_{normal}+1000L_{distortion}.
\]

实际入口中的加权顺序是 `photo + lambda_alpha_loss*alpha + static_dl_normal_weight*normal + lambda_dist*distortion`。本组系数分别为 1、0.1、0.1、1000。normal 自 global 2000 后启用，distortion 自 global 8000 后启用；所有 2.6° 阶段都在这两个正则已经开启的区间。

### 4.1 Censored 鲁棒 RGB 光度项

令预测与目标 sRGB 图像为 \(I_p,I_t\)，残差为 \(r=I_p-I_t\)。先计算停止梯度的通道均值残差 \(s=\operatorname{mean}_{RGB}(r)\)：

- 若 `s > 0.08`，权重为 0.25。此类像素的预测比观测亮，常见于模型未能解释的阴影或强暗残差；降低其影响，避免错误阴影直接驱动几何。
- 若 `s < -0.08`，权重为 0.5。此类像素的预测比观测暗，常见于高亮方向的残差；同样降低极端残差的拉动。
- 其余位置权重为 1。背景 `alpha<=0.5` 的权重固定为 1，不由前景残差分组改写。

每通道的基本惩罚为 \(\sqrt{r^2+10^{-6}}\)，之后乘上述权重并对图像元素取均值。对 `target==1` 且训练 Alpha `>0.5` 的满码通道施加单边下界：将残差替换成 `min(r,0)`。如果预测已经达到或超过 1，该通道梯度为零；预测低于 1 时仍受罚，必须至少拟合到饱和值。

这不是阴影标签，也不是删掉暗像素。`s` 由当前预测残差计算且停止梯度；训练仍对所有原始图像像素计算损失，只有大残差的权重下降。满码规则只依赖训练 RGB 的精确满码值和原 Alpha，不依赖 GT 材质或 GT 阴影。

### 4.2 Alpha BCE

对渲染 Alpha 先裁到 `[1e-6,1-1e-6]`，再与训练图自身的 GT Alpha 做二元交叉熵。权重为 0.1。它约束轮廓和覆盖，但平台在脚后方时可以补足合成 Alpha，所以 Alpha 白满不能单独证明鞋面在三维中完整。

### 4.3 Expected-depth 法线一致性

比较同一渲染中的两张预测法线：Gaussian 朝向产生的 `rend_normal`，以及从**预测 expected depth** 经相机射线求出的 `surf_normal`。两张法线先单位化，逐像素损失为 `1-dot(n_render,n_surface)`，使用 GT Alpha 腐蚀 5×5 后与预测 Alpha `>0.5` 的交集作掩膜，再按有效掩膜数量归一。系数为 0.1。

这里的 expected depth 是模型渲染统计量，不是 GT 深度。训练里没有把任何 GT 法线或 GT 深度喂给该项。它的作用是让着色法线朝向和模型自身表面深度推导的法线一致，减少“颜色法线正确、真实几何不跟随”的分离。

### 4.4 Distortion 项

取原生 2D Gaussian/SURFEL 光栅输出的 `rend_dist` 均值，乘 1000。它是沿渲染深度分布的正则，不是深度 GT 监督。训练记录中的原始 distortion 常在 `1e-8` 到 `1e-7` 量级，乘权后通常约 `1e-5` 到 `1e-4`；不可因为系数是 1000 就断言它支配总损失。

### 4.5 每项对参数的梯度范围

正常 full 路由下，RGB、Alpha、normal 和 distortion 都可能通过原生渲染影响几何及 opacity。G2-T06 的特殊分流只对 normal 一项生效：normal 的真实值、图像前向和到 XYZ／旋转／尺度的梯度保持，单独删除它对 opacity 的梯度。RGB、Alpha BCE、distortion 到 opacity 的梯度继续存在。因此 `detach_opacity` **不等于冻结 opacity**，也不等于关闭 normal loss。

起点零更新审计逐元素核对 full 与 detach 的 normal 数值及渲染输出一致，normal→opacity 梯度从有限非零变成严格零；XYZ、rotation、scaling 的 normal 梯度在 `atol=1e-6, rtol=1e-4` 内一致；photo、alpha、distortion 的 opacity 梯度保留；总 opacity 梯度的差恰为 normal 项本身。该审计通过后才进行正式训练。

## 5. opacity reset 周围的核心路线

原生 `reset_opacity()` 把激活透明度改成 `min(current_opacity, 0.01)`。T05 和 T06 都从 G2-T03@14000 开始，进行真实自然训练，在 global 15000 执行 reset。候选 T06 在 reset 前的 global 14001–15000 仍用 full；只有 reset 完成后，global 15001–16000 才使用 `detach_opacity`。这一点不能和冒烟中的人工 reset 混淆：smoke 的人工 reset 只审计状态切换，科学结论来自正式训练的自然 15000 reset。

更具体地，detach 分支复制原生几何前向，令 normal 专用副本 `detach_opacity=True`，并将 `depth_ratio=0` 固定为 expected depth。它断开 normal 专用副本到透明度的导数，但不改变输出值、可见点集合和半径。T06 配对记录显示，跨过 reset 后，T05 控制与 T06 候选的低透明度裁剪数量明显不同：全场景 UID 审计统计的真正低透明度过滤，T05 为 14832 点、T06 为 2112 点；该数值是全场景拓扑统计，不是语义鞋点计数。

这个机制有清楚的物理动机：reset 后 opacity 被压到低值，normal 自一致性项若仍能通过 opacity 更新，可能为了让两类预测法线更一致而降低贡献表面的透明度，继而在后续 low-opacity prune 中失去表面支持。保留 XYZ、旋转、尺度上的 normal 几何约束，同时切掉这一条 opacity 旁路，可以让几何继续移动和转向，却不让 normal 单项在恢复窗口里抹掉点的可见贡献。

配对结果支持这条解释，但不构成精确到每个点的因果证明：两组在 reset 前已经有 31 个 Gaussian 的点数差异；点增密、split、父点替换和裁剪同时作用。预测高度带 UID 谱系不是 GT 语义鞋分割。并且 T06 的全局收益主要出现在平台和衣物，鞋区的三类法线 MAE 实际略差于 T05，虽然鞋 expected-depth 的同射线距离有所改善。

## 6. 优化器、学习率、采样与增密

### 6.1 优化器与学习率

- G2-T06 从 T03@14000 的 PLY／deform／lighting 参数加载，但新建 Adam，所有动量为零；不会恢复 T03 的 optimizer state。
- F-T04 同样从 T06@16000 参数重新初始化，新建 Adam 并把 `xyz_gradient_accum`、`denom`、`max_radii2D` 增密累计清零；不接续 G2-T06 的优化器或增密统计状态。
- XYZ 配置使用 `position_lr_init=1.6e-4`、`position_lr_final=1.6e-6`、delay multiplier `0.01`，按原 global 30000 步日程衰减，不将短续训预算压缩成新日程。真实使用的 XYZ LR：T06 global 14001 首步约 `9.3273e-5`；F-T04 global 16001 首步约 `6.8616e-5`。
- F-T04 记录的实际 optimizer group 起始值为：XYZ `6.86157e-5`、albedo DC `0.01`、albedo rest `0.0005`、opacity `0.05`、roughness `0.002`、scaling `0.01`、rotation `0.001`、feature `0.004`。模型载入 optimizer group 不表示每个字段都被当前 Lambertian loss 使用；实际梯度门禁重点核对 XYZ、rotation、scaling、opacity、albedo 和光强。
- F-T04 每步通过独立 Python RNG 从相机栈中不放回抽取训练相机，135 张都被抽完后再开始下一轮；seed=`1012`。2000 步大约相当于 14 个完整遍历加 110 张。

### 6.2 拓扑更新和保存次序

模型从 T13 时期就启用 Gaussian clone/split/prune。公共关键值为 `densify_from_iter=500`、`densify_until_iter=20000`、每 `100` 步更新一次、screen gradient threshold `0.0002`、minimum opacity `0.01`。训练步骤先 forward/backward，记录可见点 screen-space 余切，执行 Gaussian／light optimizer 更新，随后执行原生拓扑和必要 reset，再保存更新后的检查点。最后一步不做没有后续优化承接的增密或 reset。

G2-T06 仅覆盖一个正式自然 reset：global 15000。F-T04 采用 `reset_policy=skip_all`，从 16000 到 18000 不再执行 opacity reset，但在 20000 上限之前继续每 100 步走原本的拓扑路线。

F-T04 的 `densification_route=original` 按原生方式把非 normal photo/Alpha/distortion 的 screen 梯度与 normal 几何副本的 screen 梯度相加，然后只累计一次 screen norm 和 denom；它不额外施加任何增密下限。配对 F-T05 才试验 `non_normal_floor`，没有取得稳定整体几何优势，所以 2.6639° 结果没有依赖这个 floor。

## 9. 足部结果和四类可视化结论

全局覆盖率高并不保证脚尖表面有效。G2-T06@16000 的 GS／Depth／Mesh coverage 分别约 `99.803%／96.605%／99.315%`，但离线固定 GT object_4 鞋区 6185 像素的局部三项 MAE 仍为 `21.204°／27.743°／30.060°`。鞋区 Alpha coverage 为 100% 也不足以证明三维鞋体存在，因为后方平台可以补满合成 Alpha。

F-T04@16500 的鞋区三项 MAE 改善为 `19.511°／26.458°／28.201°`；Expected 与 Mesh 同射线距离 2 cm 内比例约为 `69.81%／67.87%`。鞋形确有改善，但多个固定视角仍可见鞋尖偏低、鞋端内缩，不能记为完整足形恢复。

历史终审的四类目检结论为：

- **RGB：** 双腿和鞋身主体连续；鞋尖仍钝、短缩，像素颜色连续不等于完整鞋形。
- **Alpha：** 人物和平台轮廓连续；脚与平台覆盖合并，不能区分平台替代鞋面。
- **Normal：** 双腿主体连续；鞋尖、鞋底边缘偏平，鞋区仍有较大法线误差。
- **Separation：** 输出符合静态 feature 分支；统一静态标签不表示语义分离或鞋部几何成立。

评测视频全帧解码通过，人工目检按记录查看四类 10／80／150 代表视角及鞋部关键视角；自动解码不等于人工逐帧检查。F-T04@16500 代表图片和完整逐视角图路径见 [1012-10 中间检查点轨迹审计](../报告/1012-10-足部T04中间检查点轨迹审计.md) 及 `output/archive/1012-21-LH-static-jumpingjacks_DL_V2-F-T04中间检查点回溯/iteration_16500/evaluation_16500/`。

## 10. 为什么这条线有收益，以及它没有证明什么

### 有证据支持的部分

1. T13 的较早 normal 正则和后续基于方向光的 RGB 几何优化建立了一个明显优于旧静态 DL 基线的起点。T13 本身已经低于静态 EL 的三项数值参考。
2. 从共同 T03 起点跨自然 reset 的 T05／T06 配对中，只有 T06 在 reset 后切断 normal→opacity。T06 的三项全局 MAE 比 T05 低，低透明度剪枝数量也少很多，说明这一梯度路径值得保留。
3. F-T04 没有继续改 loss，而是验证既有 T06 模型在原增密机制下的短程轨迹。T06 后续保存点的鞋区指标继续改善，且 16500 仍保留了最低 GS 的历史值。

### 不能外推的部分

- **没有证明 GS<2°。** 最低 GS 仍是 2.6639°，离 Goal 还差约 0.664°。
- **没有证明鞋足完整。** T06 的鞋区 MAE 仍远高于全局 MAE，F-T04@16500 也仍有短缩；Alpha 和 separation 都不能补足这项证据。
- **没有证明只靠 opacity 路由就修好鞋。** T06 对 T05 的全局改善主要来自平台和衣物，鞋区法线甚至略差；同射线深度改善和法线改善不是同一件事。
- **没有证明 F-T04 长训更优。** GS 在 16500 最低，之后到 18000 回升；mesh 在 17500 最低，Depth 的最佳记录来自其他检查点。不能拼出不存在的综合模型。
- **没有独立种子复现。** 所有结果都来自该单一训练谱系和 seed 1012 的续训链；不能声称统计显著或普遍稳定。
- **存在 checkpoint 按测试集回溯选择。** F-T04@16500 是从固定 15 张测试图结果中识别出的历史单项最低保存点，未来应用需增加独立验证选择环节。
- **没有 Stage2 和完整 PBR 外观结论。** 本轮训练的物理前向是 Lambertian 直接光加预测可见度，ambient 固定零；没有完成材质 Stage2、roughness 恢复或动态场景验证。

## 11. 当前可复用的方案建议

若复现 **最低 GS 记录**，应复现整条来源链，或从已验证的 G2-T06@16000 完整检查点开始：

1. 使用同一静态 DL 数据、相机、Alpha 和每帧训练方向；训练集只含 135 视角，评测用原 15 张固定协议。
2. 保持 `ambient=0`、`loss_model=censored`、normal statistic=`expected`、normal weight `0.1`、Alpha weight `0.1`、distortion weight `1000`，shadow/highlight/残差阈值为 `0.25／0.5／0.08`。
3. 在自然 opacity reset 前保留 normal→opacity full；只在 reset 后恢复窗口将 normal 专用几何副本切为 `detach_opacity`，其他损失和 normal→XYZ／rotation／scaling 梯度保持。
4. 保持 global 30000 步 XYZ 学习率日程、新 Adam 初始化、seed 与训练相机采样协议。reset 后路线、optimizer 状态及点拓扑必须通过审计，不能只检查配置字段。
5. 把 G2-T06@16000 作为当前低 Depth 的强基线；如果研究原增密续训，保存 16500／17000／17500／18000 并逐点按事先冻结的验证规则选点。F-T04 的历史数据不支持默认跑满 2000 步。
6. 用同一检查点完成三项法线、鞋部 expected/mesh 深度、四类可视化和完整几何验收。目标仍需同时满足指标与鞋足结构；不得把低平均 MAE 作为足部修复结论。

**复现时的优先检查点选择：** 如果关心 GS headline，保留 F-T04@16500 作为历史最低 GS 候选；如果关心较低 Depth 与稍少一层事后选择，优先从 G2-T06@16000 开始。两者都是数值候选，不是完整 Goal PASS。新训练若沿用该方案，应新增独立 seed 和 validation checkpoint selection，单独验证鞋足后再作结论。
