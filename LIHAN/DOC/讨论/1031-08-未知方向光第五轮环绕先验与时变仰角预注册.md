## 二、方法定义（E0–E4 口径与第三轮一致）

| 方法 | 定义 |
|---|---|
| `E0` | 固定 +Z（与第三轮相同） |
| `E1` | 绝对亮度白化投票 + 交界线仰角（第三轮 `voting(kind='E1')`，逐字复用） |
| `E2` | 相对亮度白化投票 + 半径 1 平滑 + 交界线仰角（第三轮 `initial(kind='E2')`，逐字复用） |
| `E3` | 第三轮第一阶段：KKT 闭式变量投影 + 共享恒定仰角 L2 拟合，250 步 Adam lr 0.03、第 150 步 ×0.3（逐字复用 `fit(..., stage2=False)`）。作为**恒定仰角对照**，必须与第三轮 `E3` 数值复现（无 GT 核对：逐元素差 ≤ 1e-6，否则停机记录） |
| `E4` | **本轮新方法**：带宽受限时变仰角 + 环绕轨迹平滑，按第四、五节无 GT 准则从固定候选网格中机械选出 |

### 2.1 光向参数化（三条采集先验的结构化）

对每帧 $t=1..150$：
$$\mathbf{l}_t=(\cos e_t\,\mathbf{u}_t,\ \sin e_t),\qquad \mathbf{u}_t=\tilde{\mathbf{u}}_t/\|\tilde{\mathbf{u}}_t\|\in\mathbb{S}^1,\qquad e_t = e_c + \Delta_{\max}\tanh(a_t)$$
- **先验 2（仰角小幅时变）**：$e_c = 45^\circ$、$\Delta_{\max} = 5^\circ$，**硬边界** $e_t\in(40^\circ,50^\circ)$，即 $z_t\in(\sin40^\circ,\sin50^\circ)=(0.6428,0.7660)$。二者为模型结构常数，任何后续阶段不得修改。
- **先验 1（环绕轨迹）**：150 帧是一条轨迹；方位角连续演化，允许匀速或变速，不允许跳变与折返（由 2.2 的一阶项与折返惩罚、以及第四节的折返门槛实现）。
- 世界系、`surface_to_light` 约定、方向光强度恒为 1（由每表面 $\rho_g,b_g$ 吸收），与第三轮一致。

### 2.2 目标函数（轨迹阶段，记作 Stage T）

数据项与第三轮 `E3` 完全一致：对称 L2，KKT 闭式非负变量投影（分母稳定 1e-6、三活跃分支），系数正则 $10^{-5}(\overline{\rho^2}+\overline{b^2})$，`float64`，不使用 Huber/IRLS（第三轮 Huber 候选全部未优于 E3，本轮不再引入该自由度）。

记 $\Delta\phi_t=\operatorname{atan2}(\mathbf{u}_t\times\mathbf{u}_{t+1},\ \mathbf{u}_t\cdot\mathbf{u}_{t+1})$（有符号方位增量，$t=1..149$），$\overline{\Delta\phi}$ 为其序列均值，$\Delta e_t=e_{t+1}-e_t$，$s=\operatorname{sign}\sum_t\Delta\phi_t^{(E3)}$（由同一支撑集自身的 E3 结果确定的环绕方向，Stage T 中固定）。**先验 3（平滑损失）**：

- 方位一阶（角速度偏离，允许匀速环绕零代价）：$R_{a1}=\operatorname{mean}_t(\Delta\phi_t-\overline{\Delta\phi})^2$
- 方位二阶（测地角加速度，第三轮 `geo_penalty` 推广）：$R_{a2}=\operatorname{mean}_t(\Delta\phi_{t+1}-\Delta\phi_t)^2$
- 仰角一阶（仰角角速度）：$R_{e1}=\operatorname{mean}_t(\Delta e_t)^2$
- 仰角二阶（仰角角加速度）：$R_{e2}=\operatorname{mean}_t(\Delta e_{t+1}-\Delta e_t)^2$
- 折返惩罚：$R_{rev}=\operatorname{mean}_t\operatorname{relu}(-s\,\Delta\phi_t)^2$

$$\mathcal{L}_T=\mathcal{L}_{\text{KKT-L2}}+\lambda_a(R_{a1}+R_{a2})+\lambda_e(R_{e1}+R_{e2})+\lambda_{rev}R_{rev},\qquad \lambda_{rev}=0.1\ (\text{固定})$$

说明：任务书要求“一阶项惩罚相邻帧方向夹角”。若直接惩罚相邻帧夹角本身，会系统性缩小环绕角速度（与先验 1 的完整环绕矛盾）。因此本轮把相邻帧夹角分解为方位分量与仰角分量：方位分量惩罚其相对序列平均角速度的偏离（匀速环绕零代价，跳变与抖动受罚），仰角分量直接惩罚角速度。所有角度单位为弧度。

### 2.3 优化流程（每条独立流程）

1. 在给定支撑集上运行 E2 投票（第三轮 `initial`，分位数候选按各自支撑评分，规则不变）；
2. Stage 1（=E3 定义）得到 $\mathbf{u}^{(0)}_t$ 与共享 $z^*$；
3. Stage T 初值：$\tilde{\mathbf{u}}_t=\mathbf{u}^{(0)}_t$，$a_t=\operatorname{atanh}(\operatorname{clip}((\arcsin z^*-45^\circ)/5^\circ,-0.9,0.9))$（全帧同值）；
4. Stage T：Adam 同时优化 $(\tilde{\mathbf{u}},a)$，400 步，lr 0.015，第 250 步 ×0.3；无早停。

同一支撑集的 E2/Stage 1 结果在各候选间共享（只算一次）。

### 2.4 固定候选网格（12 组，严禁网格外追加）

- $\lambda_a\in\{10^{-4},10^{-3},10^{-2}\}$
- $\lambda_e\in\{10^{-4},10^{-3},10^{-2},10^{-1}\}$

量级依据（无 GT，仅数量级推算）：单帧数据项曲率约 $10^{-4}$/rad² 量级，单帧锯齿在平滑项中的系数约 $0.05\lambda$；网格从“弱于数据项”到“强于数据项约两个数量级”覆盖。

## 三、每候选的无 GT 诊断量

对每个候选 $c$，运行以下 7 条完整流程：

| 流程 | 支撑 | 初值 |
|---|---|---|
| `full` | `body_fit` | 2.3 节标准初值 |
| `A` / `B` | `split_A` / `split_B` | 各自独立 E2 → 各自 Stage 1 → Stage T（不接触另一半集） |
| `hi` / `lo` | `body_fit` | `full` 的 Stage 1 方位；$a_t$ 初值 $=\pm\operatorname{atanh}(0.9)$（$e\approx 49.5^\circ/40.5^\circ$） |
| `boot103108` / `boot103109` | `body_fit` 有放回重采样（种子与第三轮相同） | 各自 E2 → Stage 1 → Stage T |

诊断量（全部只用估计结果与 RGB 观测）：
1. `split_mean_deg`、`split_p90_deg`：A/B 两条 150 帧光向夹角的均值与 90 分位；`split_el_mae_deg`：$\operatorname{mean}_t|e^A_t-e^B_t|$（度）。
2. `hilo_mean_deg`：hi/lo 两终点 150 帧夹角均值。
3. `boot_mean_deg`：两次 bootstrap 终点与 `full` 的 150 帧夹角均值的平均。
4. `body_heldout_mae`：第三轮 `ols_score` 逐字复用（`body_val`，奇数帧标定/偶数帧验证，截断 0.2）；同时记录 `all_heldout_mae`。
5. `saturation_frac`：`full` 中 $|e_t-45^\circ|\ge4.75^\circ$ 的帧比例（贴边率）。
6. `reversal_count`：`full` 中 $s\,\Delta\phi_t<0$ 的帧数。
7. `view_dz_abs`：按第三轮定义的无 GT 暗面比例 $f_{\text{dark},t}$，顺光帧（≤Q30）与侧/逆光帧（≥Q70）预测 z 均值差的绝对值。
8. 轨迹描述（只报告）：$R_{a1},R_{a2},R_{e1},R_{e2},R_{rev}$ 终值、仰角范围/标准差、最大 $|\Delta\phi_t-\overline{\Delta\phi}|$、最大 $|\Delta e_t|$、末 50 步相对 loss 变化。

## 四、机械门槛（全部写死）

| 编号 | 门槛 | 含义 |
|---|---|---|
| G1 | `split_mean_deg ≤ 3.50` 且 `split_p90_deg ≤ 6.00` | 空间半集独立重估一致（沿用第三轮） |
| G2 | `hilo_mean_deg ≤ 0.50` | 时变仰角对初值不敏感 |
| G3 | `boot_mean_deg ≤ 2.00` | 支撑重采样稳定 |
| G4 | `body_heldout_mae ≤ 1.01 × body_heldout_mae(E3)` | 光度泛化不劣于恒定仰角对照超过 1% |
| G5 | `saturation_frac ≤ 0.20` | 仰角不大量顶格贴边（任务书第五节） |
| G6 | `reversal_count ≤ 2` | 无折返抖动（先验 1） |
| G7 | `view_dz_abs ≤ 0.030` | 无顺光视角 z 暴涨伪影（第一轮 H4 机制；0.030 约为 z 带宽 0.123 的四分之一） |

说明：第三轮的 `body ≤ 0.60×E2` 门槛已被事后证明在本数据上不可达（E3 本身即为 0.80×E2），本轮不再使用；该调整只依据第三轮的无 GT 留出数值，不涉及 GT。

## 五、选择规则与回退（机械）

$$J(c)=\text{split\_mean\_deg}+0.5\,\text{split\_p90\_deg}+\text{split\_el\_mae\_deg}+\text{boot\_mean\_deg}+\text{hilo\_mean\_deg}$$

- **Tier 1**：在通过 G1–G7 全部门槛的候选中取 $J$ 最小者；$J$ 差 ≤ 0.02 时依次按较小 `body_heldout_mae`、较大 $\lambda_e$、较大 $\lambda_a$ 破平局。
- **Tier 2**（无 Tier 1 候选时）：在通过 G4–G7（光度与轨迹合理性）的候选中按同一 $J$ 与破平局规则选择，并在报告中明确标注“稳定性门槛未全部通过”。
- **Tier 3**（Tier 2 也为空）：`E4 = E3`，标注 `E3_fallback`。
- 若被选候选或大量候选贴边（G5 失败），报告必须如实指出“先验带宽或模型设定可能有问题”，不得临场改带宽。
