# 1002-03 输出目录说明

示例：`/home/lihan/reproduce/LumiMotion-stage2-perlight/output/1002-03-onlyclothV4-stage2_GT/`。
本实验只执行 **Stage2**：加载 Stage1 SH 的35000模型，固定几何、法线、opacity、形变和 GT 灯方向，训练 albedo 到55000（新增20000步）。

```text
1002-03-onlyclothV4-stage2_GT/
├── README.md                     实验总说明：完整命令、来源、指标、图片/视频、最终结论
├── commands/                     执行命令与辅助脚本
│   ├── train.sh / render.sh      Stage2 训练 / 渲染命令
│   ├── artifact_checks.py/.sh    检查图片数量、视频解码等产物完整性
│   ├── checkpoint_checks.py/.sh  检查训练步数、Stage1来源未变及冻结状态
│   └── readme_writer.py          汇总结果，生成实验 README
├── logs/                         上述执行产生的文本日志
│   ├── train.log / render.log    Stage2 训练 / 渲染过程
│   └── pipeline.log、*_checks.log 流程总日志 / 两类检查日志
├── model_mlp/                    Stage2 模型与原始渲染结果
│   ├── cfg_args                 模型/数据参数，供加载使用
│   ├── stage2_config.json       Stage2配置：Stage1路径、模式、固定光强等
│   ├── losses.jsonl             训练每500步记录损失，一行一个JSON
│   ├── TRAIN_COMPLETED          训练完成标记
│   ├── stage2_photometric/      训练写出的 Stage2 checkpoint
│   │   └── iteration_N/checkpoint.pth
│   │       N=35000/40000/50000/55000；35000为初始化，55000为最终模型
│   │       保存albedo、固定灯方向、优化器、随机状态及来源校验等
│   └── renders_stage2/ours_55000/  从55000 checkpoint离线渲染（均属Stage2）
│       ├── eval/                15组测试视角：*_render/gt/mask.png；metrics.json为指标
│       ├── insights/            四类可视化，各120帧PNG及一段同名MP4
│       │   ├── rgb/             当前光照下的最终颜色
│       │   ├── alpha/           前景覆盖度，观察轮廓和孔洞
│       │   ├── normal/          冻结几何的世界法线，观察表面朝向
│       │   └── albedo/          学得漫反射颜色，观察材质是否残留阴影
│       ├── directional/         固定相机/时刻转灯：72帧PNG、MP4、relight.json设置
│       ├── hdr/                 环境光重光照：120帧PNG、MP4、hdr.json设置
│       │                        3份*_linear.npz保留代表帧线性RGB
│       ├── command.json         实际渲染参数
│       ├── provenance.json / code_diff.patch  渲染时的代码版本与补丁
│       └── RENDER_COMPLETED     渲染完成标记
├── inspection/                  对上述模型/渲染做验收后生成的材料
│   ├── *_video_*.png            从六段视频抽取首/中/末帧
│   ├── four_categories.png / relight.png  四类可视化 / 重光照审阅拼图
│   └── artifact_checks.json / checkpoint_checks.json / manual_review.json
│                                产物检查 / 模型检查 / 人工目检结论
├── code_commit.txt / code_status.txt / code_diff.patch  启动时的代码版本、状态、补丁
├── server.txt / start_time.txt / finish_time.txt        服务器和起止时间
├── git_sync_verification.json   当时全分支文档同步的核对记录
└── STARTED / PIPELINE_COMPLETED / COMPLETED             已启动 / 流程结束 / 验收完成
```

生成顺序：`commands/train.sh` 调用 `scripts.train_stage2` → `commands/render.sh` 调用 `scripts.render_stage2 --task all` → 检查脚本与人工目检生成 `inspection/` → 汇总 `README.md`。实际完整命令直接看这两个 `.sh`。

Stage1来源在旧工作树的 `output/1001-01-onlyclothV4-FOVxy修复重训/model_mlp`（35000），不在本目录内；加载本模型时仍需保留该来源及数据。最终验收看 README 的 `PASS/FAILED`；本次 PASS 表示流程与产物可用，材质仍有阴影残留。
