# 输出目录速查

日期：2026-10-02。以下路径均相对各工作树的 `output/`；实际命令、指标和验收以实验 `README.md` 为准。

| 工作树 / 实验目录 | 用途与 Stage |
| --- | --- |
| `LumiMotion-perlight/0930-01-jumpingjacks…` | 中止的 Stage1 SH；`attempts/` 保留失败尝试。 |
| `LumiMotion-perlight/1001-01-onlyclothV4-FOVxy修复重训` | 原始两阶段归档；iter35000 是本次 Stage1 SH 来源。 |
| `LumiMotion-perlight/1002-01-onlyclothV4-perlight原始管线复现` | 历史 SH Stage1 + 原始 IR Stage2；现有 README 仍标待验收。 |
| `LumiMotion-stage2-perlight/1002-02-onlyclothV4-stage2_original` | 原始 IR Stage2 对照。 |
| `LumiMotion-stage2-perlight/1002-03-onlyclothV4-stage2_GT` | Lambertian Stage2：学 albedo，固定已知灯方向。 |
| `LumiMotion-stage2-perlight/1002-04-onlyclothV4-stage2_learned` | Lambertian Stage2：学 albedo 与训练时刻灯方向。 |
| 两工作树的 `smoke_test/` | 短训练验证；新工作树 GT/learned 为200步，`*_resume` 验证续训。 |

实验公共内容不属于额外 Stage：`commands/`、`run*.sh` 保存执行命令；`logs/` 保存日志；`inspection*/` 保存抽帧、拼图、统计和目检；`README.md` 汇总验收。`code_*`、`*provenance.json`、时间/服务器记录、补丁、`archive_manifest.json`、`git_sync_verification.json` 用于追溯。`preflight*` / `source_preflight.json` 检查输入，`gpu_checks*` 验证梯度、冻结与续训。

| `model_mlp/` 内模块 | 内容 / 输出方式 / Stage |
| --- | --- |
| `point_cloud/iteration_N/*.ply`、`deform/iteration_N/*.pth` | 高斯属性、形变网络；训练保存。历史实验35000属 Stage1，40000～55000属原始 Stage2。 |
| `envmap/iteration_N/` | 原始 Stage2 学得环境光；`.pth` 权重、`.hdr` 图像。 |
| `stage2_photometric/iteration_N/checkpoint.pth` | 新 Stage2 材质、灯方向、Adam、随机状态等；训练保存，35000为初始化。 |
| `cfg_args`、`stage2_config.json`、`resume_*_config.json`、`stage1_source.json`、`calibration.json` | 参数、恢复配置、来源、可选统一光强标定；训练写出，并非图像。 |
| `losses.jsonl`、`events.out.tfevents.*` | 新 Stage2 逐步损失 / 原始训练 TensorBoard。 |
| `renders_stage1_insights/ours_35000/` | Stage1 RGB、alpha、法线、大小高斯分离等 PNG/MP4；`scripts.render_stage1_insights`。 |
| `trained_materials/ours_55000/` | 原始 Stage2 albedo、roughness PNG/MP4；`scripts.render_materials`。 |
| `eval_nvs_static/`、`results_nvs_static.json` | 历史 Stage2 静态视角 render/GT/mask 与指标；`scripts.eval_nvs_static`。 |
| `stage2_insights/`、`render_relight_with_hdr_*/` | 本次原始 Stage2 四类诊断 / HDR PNG、MP4；统一 insights 任务 / 旧 HDR 脚本。 |

新 Stage2 默认渲染根：`model_mlp/renders_stage2/ours_N/`，由 `python -m scripts.render_stage2 --model_path … --load_iter N --task all` 生成；完整命令见[使用指南](1002-01-Stage2-Lambertian训练渲染与续训使用说明.md)。

| 渲染子目录 | 内容与用途（均属 Stage2） |
| --- | --- |
| `eval/` | 15组自身相机/时间 render、GT、mask PNG；`metrics.json` 记录整图/前景指标。原始 IR 对照也用此目录。 |
| `insights/{rgb,alpha,normal,albedo}/` | 各120帧 PNG + 4段 MP4：带光 RGB、覆盖度、法线、漫反射颜色。`materials` 任务也输出此处。 |
| `directional/` | 固定相机/时刻转灯72帧 PNG + MP4；`relight.json` 记录设置。 |
| `hdr/` | 环境光120帧 PNG + MP4；`hdr.json` 记录设置，3份 `*_linear.npz` 保存线性 RGB。 |
| `command.json`、`provenance.json`、`code_diff.patch` | 渲染参数、代码版本及补丁。 |

历史辅助目录：`data_view/` 是训练数据链接视图，`static/timestep0001/` 是静态评估输入；`matplotlib/`、`torch_extensions/` 是字体/编译缓存。`cameras.json`、`input.ply` 是加载时记录的相机/初始点云。冒烟的 `stage2_hdr_axis_fixed/` 保留修正轴向后的 HDR，`stage2_legacy_reader/` 验证旧入口兼容，均属 Stage2。

注意：新 Lambertian checkpoint **依赖外部 Stage1 模型和数据**，没有新 `.ply` / `deform/` 属正常。`TRAIN_COMPLETED`、`RENDER_COMPLETED`、`PIPELINE_COMPLETED` 分别表示步骤结束；最终看 README 的 `PASS/FAILED`。`FAILED` 与 `RECOVERED/COMPLETED` 可同时存在，表示失败历史被保留；PASS 不等于材质/光照已真实恢复。
