## 4. G2 精确复核

从实际调用链 `static_rgb_light_fit_goal1107_t01.py` → r3.compare 核对输入是否归一化、clip、arccos、角度单位、帧集合及均值权重，逐项给源码位置。G2 是 hi/lo 两条最终方向的平均三维夹角 ≤0.5°；不是全预测与 GT 的误差，也不是最大帧差或仰角单项差。核对 hi/lo 是否共享 full 支撑和 E3 方位初值、物理仰角初值是否分别为49.5°/40.5°，以及两条证书。

对七候选逐帧重算 d_t，输出 mean、P50、P90、max、阈值、signed margin=mean−0.5°、ratio=mean/0.5°、历史 gate 与重算一致性。C01 明确写实际均值、超出多少度和百分比，解释失败只有一个聚合判据，逐帧超过0.5°的比例只作描述。另给 hi/lo 仰角差 mean(abs)、signed mean、方位 wrap 差 mean(abs)，用于定位分歧方向，不把这些量当作 G2 的新增判据。对 C00/C01/C06 给证书是否通过及终点差异；证书收敛不等于全局唯一解，不由 G2 失败断言优化 bug。

## 5. J 精确分解与敏感性解释

J = split_mean_deg + 0.5×split_p90_deg + split_el_mae_deg + boot_mean_deg + hilo_mean_deg。从七流程终点重算五项，bootstrap 两个种子各自相对 full 的三维均值再等权平均，split_el 是 A/B 仰角绝对差均值。核对弧度转角度和分位数算法。输出 C00…C06 五项原始值、加权贡献及 J；C01、C06 对 C00 的逐项 Δ=候选−C00。要求贡献和等于 ΔJ，绝对误差≤1e-8°；对存档重算差≤1e-8°，若 arccos 浮点近零导致超差，报告差值和原因并停止对应断言，不放宽容差掩盖。

对 C06 列出每项减少/增加多少、净改善由哪些项贡献；贡献百分比以 J(C00)−J(C06) 为分母，允许负贡献和大于100%，净差近零（绝对值≤1e-12）时记不适用。不要把训练数据 loss 或仰角正则项误列为 J 项。可旁列已存 data_loss/e1/e2 说明优化目标与选档评分不同，不能据此选档。

敏感性以数学分析为主：split_el 直接响应 A/B 仰角不一致；三维比较项对方位和仰角差均敏感但无法识别共有绝对偏差；J 没有对 GT 精度、共同仰角中心偏差或真实动态幅度的直接测量。明确共同三维旋转保持球面距离，但共同仰角加偏置一般不保持球面距离（球面度量随仰角改变），不能笼统宣称 J 对共同仰角偏移完全不变。共同仰角偏移保持 A/B 仰角差；相同错误轨迹可令全部一致性项为零。仅用两个预先固定的合成例子验证这两个命题：所有流程同一轨迹；所有方向共同绕 x 轴旋转10°（仅验证三维项，split_el 可变）。不对真实轨迹施加扫描，不生成修改预测或新敏感性选档表。

## 6. G0–G7 与精度的潜在冲突

逐门给“代码定义/测量对象/可能约束真实仰角的机制/本轮可观测证据/无法推出的结论”五列，不仅列出失败门。G0 检查数值收敛，并非精度保证；不同参数化及弱正则条件数可影响通过，只有证书证明的情况才描述为实测。G1、G2、G3 测稳定性/重复性，可能奖励共同偏差或压低真实变化，失败也可能提示不可辨识而非门槛错误。G4 测留出光度拟合，ρ/b 等干扰参数及法线误差可能使光度好坏与方向精度脱钩；当前数据只能支持机制可能性，不能直接断言具体因果。G5 固定以45°中心及4.75°边缘计算比例，明确区别于候选自身0.95h边界，最直接压制中心以外轨迹；列实际比例和0.20阈值差。G6 测方位折返，主要间接耦合，不能无证据归为仰角系统性偏差。G7 测 f_dark Q30/Q70 分组预测 z 的均值差≤0.030，可能混淆真实视角关联运动与伪影；核对分组定义及是否重叠，只有重算具备全部冻结输入时才重算，否则用已存指标并标来源。

所有门槛仅复核原值与原 pass/fail；不做阈值移动后的 pass/fail、不删除门槛后重排、不输出“假如采用某规则就选 C01”。七候选历史表用于完整披露，不能只挑支持反例的行。事后 GT 证据仅由 analysis 引用用户指定反例及冻结统计，不能以七点相关性声称因果或用其标定阈值。
