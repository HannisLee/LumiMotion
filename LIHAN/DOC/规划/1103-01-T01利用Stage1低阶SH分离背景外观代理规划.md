# T01：利用 Stage 1 低阶 SH 分离背景外观代理的执行规划

日期：2026-11-03。服务器：`ushas`；所有 Python 命令使用 `conda run --no-capture-output -n lumimotion-ushas python ...`。本文件为实施前规划，不包含新实验结果。对应 [GOAL](../GOAL/1103-01-SH优化方向光重建迭代.md)。

## 1. 目标、边界与已裁定事项

在冻结 E4 的光度模型上增加由 Stage 1 SH 生成、与直射变化去共线的背景外观代理，优化其共享幅度，再估计方向光。检验该代理能否改善同帧方向初始化。第一迭代只研究这个因素，不重训 Stage 1、不训练 Stage 2，不改变几何、观测或 E4 轨迹先验。

代码事实：`gaussian_renderer/__init__.py` 使用每 Gaussian 的视向 SH；形变 `d_color` 调制 DC，SH 并非环境辐照度。故不能把这些系数直接放到法线方向求值当作环境光。逐点常量环境与自由常量 b 的分解也不可辨识。本规划的 bg 是受限的 SH 背景外观代理，静态分量采用明确约定，不能声称唯一恢复物理环境光。

## 3. 数据提取和 SH 阶数

复用现有 30000 Gaussian ID、逐帧位置、符号统一法线、有效掩码和权重，不重新抽样或改变可靠点规则。支撑集严格复现：full 2683，val 648，A 1450，B 1233；bootstrap 种子 103108、103109，使用 B 保存的样本索引。断言帧/ID/尺寸/索引一一对应。

新增只读 SH 提取器。读取原始未调制的 `g.get_features`，不使用 `d_color`，不新增逐帧外观自由度。视向采用 `v_tg=normalize(frame_xyz_tg-camera_center_t)`（世界坐标、相机指向 Gaussian），系数不旋转。固定依次计算截断阶数 L=0、1、2；L=0 仅做退化自检，不入候选。L=1/2 分别保留 4/9 个系数。L=3 不进入 T01，避免增加吸收直射和高频材质的能力。

对每阶计算 `rgb=clip(eval_sh(L,coeff,v)+0.5,0,1)`，用提取器相同的 sRGB 逆传递与亮度权重生成 h_tg。既有 SH 拟合的是编码 RGB，本次转换使 h 与线性观测亮度同域；截断、材质与烘焙直射均造成代理偏差，不能称物理光照。保存未截断值、上下截断率。若有效观测中任一通道截断的比例 >20%，该阶全体候选失效，保留诊断。

复用 observations 的位置避免重复 MLP 计算；提取器不需要新的 RGB 渲染。必须读取相机中心并核对同一帧，使用 `utils.sh_utils.eval_sh` 的实际基函数顺序。渲染器 Python 路径用 canonical 位置、CUDA 路径用变形位置可能不同，本模板按本节明确采用变形位置；不得将模板宣称为逐像素完整渲染复现。所有新输出存新目录，不改 observations。

## 4. 去共线模板与 bg 参数化

对每条流程分别使用 B 中同名支撑流程的冻结 E4 方向作为锚点 l0（full、A、B、boot103108、boot103109；hi/lo 均使用 full 锚点）。每条流程的方向初值也来自该锚点；hi/lo 只改变仰角初值。这样 A/B 的模板不借用 full 的方向拟合。留出评分使用 full 锚点。

对每点构造 150×4 矩阵 D=[1,x0,d_phi,d_e]，其中 x0=max(n·l0,0)，d_phi=1[n·l0>0] n·∂l/∂phi，d_e=1[n·l0>0] n·∂l/∂e；导数角度单位为弧度，恰好等于零时导数取零。用该点有效权重对 h 做加权最小二乘，SVD 伪逆相对截断 1e-8：beta=pinv(sqrt(w)D)sqrt(w)h；q=h-D beta。每点将 q 乘 `min(1,0.1/max(abs(q)))`，max 为零时倍率 1；这是整列缩放，保留正交性、不放大微小信号。

对拟合点使用所有有效帧计算投影。留出点只用编号为奇数的有效帧计算投影 beta，随后外推所有帧；不得用偶数留出亮度或权重拟合 beta。有效投影帧不足 8 或权重和为零时整点 q=0。所有 q 以 float64 保存。检查投影校准帧的 `max(abs(D.T W q))/(sum(w)*max(1,max(abs(D)))) <=1e-8`；不满足为实现错误停机。

定义固定非负模板 H_tg=q_tg-min_t(q_tg)，最小值取该点全部 150 帧。于是：

`bg_tg = gamma H_tg`

`yhat_tg = rho_g max(n_tg·l_t,0) + b_g + bg_tg`。

rho、b 非负，gamma 为全流程所有点和帧共享的一个标量，`gamma=sigmoid(c)`，0<gamma<1。H 的常量偏移只是一种非负规范；b 与 bg 的静态拆分不具有唯一物理含义。可辨识的研究对象是 gamma q 的时变分量，不以 b 变小作为成功证据。禁止逐点 gamma、自由 SH 系数、自由逐帧 bg 或使用 d_color。

每阶/流程中 q 加权 RMS≥1e-4 的点须至少占有效拟合点 20%，否则该流程/候选失效，原因 `SH_DEGENERATE`。不增加高阶或放大模板救活退化。L=0 必须得到 q≈0（绝对最大值≤1e-8），否则自检失败。

低阶并不天然隔离直射，本方案主要依靠固定锚点处的直射和切向导数投影、共享幅度、正则与后验相关门槛限制混淆。锚点带来局部约束偏差，可能阻止改进，失败仍是有效实验结果。

## 5. 候选、目标和数值规格

固定候选顺序：C01=(L1,lambda_bg=1e-4)，C02=(L1,1e-3)，C03=(L2,1e-4)，C04=(L2,1e-3)。E4 为 C00，只作为基线和最终回退，不从其他旧候选重新挑选。轨迹参数和先验保持 E4：lambda_a=1、lambda_e=10、lambda_rev=0.1；e=45°+5°tanh(a)。不搜索其他平滑参数。

给定方向和 gamma 后，将 `y-bg` 传入原有非负 rho/b KKT 计算；目标为原 E4 的加权 L2 光度项、1e-5 系数平方正则、轨迹正则，再加 `lambda_bg*gamma^2`。原 KKT 的外层正则并不进入内层精确解，这个性质保留并说明。所有负值观测修正和边界分支都必须通过合成 NNLS 对照自检。

每候选按 full、A、B、boot103108、boot103109、hi、lo 共七流程执行。主流程 c=0；hi/lo 分别 c=logit(0.9)、logit(0.1)，仰角分别 49.5°、40.5°；phi 来自对应冻结 E4。其余流程 a 由锚点逐帧仰角反算，clip tanh 输入到±0.999999。初始化轨迹绝对环绕量不足 180°则流程失效。

优化继承冻结 r5b 的 T-A/T-B/T-C 结构：Adam 1000 步，phi/a/c 学习率为 .01/.11/.03，第 600、850 步乘 .3；L-BFGS 200 外循环，不合格延至总 400，每外循环 max_iter=20、history_size=50、strong_wolfe；phi/a 的预条件矩阵逐字复用 r5b，c 使用恒等预条件。窗口 5 内相对目标变化<1e-9、方向最大变化<.005°、gamma 变化<1e-5 为 C1/C2。500 步 Adam 探针 phi/a/c 学习率 1e-4/1e-3/1e-3，要求方向最大变化<.1°、相对下降<1e-4、gamma 变化<1e-3；探针结束恢复全部参数。

不合格则仅一次 T-C：预条件空间 Adam 6000 步、lr=.003、余弦到 0，随后≤60 外循环 L-BFGS，重新检查相同证书。仍不合格即 `NOT_CONVERGED`。T01 不执行旧脚本异常后额外 Adam fallback；非有限 loss/参数或优化器异常即此流程失败。记录全部中间状态与异常，不无界续跑、不改阈值。候选其余流程仍完成，除非基础输入/自检失败。最多 28 个正式流程。

## 6. 无 GT 门槛与选择

G0 七流程全收敛、模板均有效。G1 A/B 平均角≤3.5°且 P90≤6°；G2 hi/lo 平均角≤.5°且 |gamma_hi-gamma_lo|≤.05；G3 两 bootstrap 与 full 平均角的均值≤2°。G5 full 的 |e-45°|≥4.75°帧比例≤.2；G6 逆环绕步≤2；G7 复用旧 relative 亮度暗点比例分组，两个分组 full z 均值差≤.03。

G4a 使用完全不带 bg 的原 `r3.ols_score` 评价候选方向：奇数帧无约束 OLS，偶数帧加权截断绝对残差（上限 .2）。要求 MAE≤1.015×冻结 E3 的同函数分数，同时≤冻结 E4 的同函数分数。所有候选使用与基线共同有效评分掩码，不能因候选退化少计难点。此项防止只靠增加外观解释力掩盖方向劣化。

G4b 补充模型留出：gamma 固定为 full 拟合值；留出点仅奇数帧以 KKT 标定 rho/b，在偶数帧计算带 bg 的截断加权 MAE。E4 用同一标定算法、同一奇偶帧及共同掩码、bg=0 计算基线。要求候选≤0.995×E4，且有效偶数评分观测数不小于原 OLS 评分掩码的 90%。只使用至少 8 个奇数有效帧、且 E4 校准 x 方差>1e-12 的留出点；先由基线锁定该掩码，四候选全部共享。若无点或某偶数帧无有效权重则门槛失败。

G8 在每条拟合流程最终方向处，用本流程权重对 q 与 x 以及两个角导数逐点加权去均值算绝对相关；零方差列跳过，按有效观测权重汇总跨点 P90，三项分别≤.2。另要求 full 的时变 bg RMS=`sqrt(sum(w*(gamma*q)^2)/sum(w))`≤0.25×`sqrt(sum(w*(y-每点加权均值y)^2)/sum(w))`。任意分母零时对应有非零分子的量失败，0/0 记 0。该门槛只拒绝，不反向重做投影或拟合。

全部通过者按原 J=`split_mean+0.5*split_P90+split_elevation_MAE+bootstrap_mean+hilo_mean` 排序（角度均用度）。取与最小 J 差≤.02 的集合，依次按 G4b MAE、G4a MAE、较低 L、较大 lambda_bg、候选编号升序破平，数值精确比较，不临场四舍五入。无通过者直接输出 C00 冻结 E4，标 `FALLBACK_E4`，不放松 Tier、不改选 E3。回退不是 T01 目标成功。

## 10. 一次评测、PASS 与终止

Academic-analysis 仅在冻结完成后读取方向光 GT，一次加载，使用原已确定世界坐标、surface_to_light、150 帧对应，无符号/轴/时间偏移搜索。对选中 T01 和冻结 E4 同一 150 帧同时计算逐帧夹角、Mean、P50、P90、≤5°帧数，以及包裹到[-180°,180°]的方位差、仰角差及各自 MAE/P50/P90，保存逐帧表和对照图；不使用 GOAL 中四舍五入数字当比较阈值。
