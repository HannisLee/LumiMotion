Per-Light 3D 查看器

查看三维场景、perlight 光线轨迹（JSON）、训练光线（.pth 导出）与 PLY 点云。

数据加载

支持拖拽文件到 3D 视口。perlight.json / light_dirs.json / lights.json 均可。

.pth 无法被浏览器直接解析，请先运行：
python tools/export_photometric_pth.py <photometric.pth>

数据集点云

初始点云来自 data/LH-data/transfer-dynamic/<数据集>/points3d.ply。新增数据集后运行 python tools/update_dataset_index.py 刷新列表。
