# 0809-01 V2 光照方向 3D 诊断要点

- 日期：2026-08-09
- 服务器/环境：garuda / `lumimotion-garuda`
- 原目录：`output/0809-only_clothV2-light-direction-3d`
- 类型：只读 checkpoint 诊断（非训练）
- 结论：learned 光方向与 GT 偏差大（mean `33.84°`）

## 一句话总结

对 0726 两个 V2 perlight 实验（学习光 vs GT 光）的 photometric checkpoint 做 3D 可视化诊断，在世界坐标与单位球上比较 learned per-light 方向与 GT；不修改任何训练或 checkpoint。

## 输入

- Learned：`output/0726-only_clothV2-perlight-facing-normal-lightlr3em3/.../iteration_35000/photometric.pth`
- GT：`output/0726-only_clothV2-perlight-facing-normal-gtlight/.../iteration_35000/photometric.pth`
- 方向约定 `light_to_surface`；代表帧 0 / 59 / 119
- 生成脚本：`scripts.visualize_stage1_light_trajectory`

## 定量

- Learned 相对 GT 参考方向：mean `33.84°`、median `32.92°`、P95 `40.66°`（`light_direction_metrics.json`）
- 注意：该比较针对 reference center 的整体入射方向，不替代每个变形 Gaussian 的局部点光方向比较

## 产物与读图

- 世界坐标光源轨迹 `light_position_world_01~03_*.png`：GT 三角为真实灯位；learned 圆点是以 GT 距离中位数构造的虚拟光源，仅用于同空间比较
- 单位球方向箭头 `light_direction_unit_sphere_04~06_*.png`：每点为归一化 `light_to_surface` 向量
- 2×3 总览 `light_direction_3d_contact_sheet.png`；可旋转交互视图 `light_direction_3d.html`（时间滑块逐帧高亮 GT 与 learned 箭头）
