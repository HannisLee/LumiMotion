# 0824-04 CV3s 逐 GS GT 位置光方向三法线消融实验

日期：2026-08-24  
服务器/环境：`garuda` / `lumimotion-garuda`  
状态：冒烟与正式实验均 **PASS**

## 目标与对照

以已通过验收的 0823 CV3s `gt_directional + lambertian_normal3` 为对照，只将固定场景中心方向替换为光源点到每个变形后 GS 的实时单位方向。光强、颜色、loss、训练调度、随机初始化和评估协议全部不变，且明确关闭距离衰减。

## 验收计划

1. 运行相关单元测试，确认坐标、方向符号、衰减和 checkpoint 行为。
2. 运行 1200 iter 冒烟，使 live@500 与 mv@1000 均实际触发；检查梯度审计、有限值和 checkpoint 恢复。
3. 运行 35000 iter 正式训练、全时序 Stage 1 insights 渲染及 GT normal 离线评估。
4. 与 0823 的 Best PSNR 47.65、normal mean 19.23° / median 15.60° / p95 59.90°比较。
5. 在实验 README 中记录 RGB、alpha、albedo/separation、normal 四类目检及最终 `PASS`/`FAILED`。

## 执行结果

### 冒烟结果

- 1200 iter 正常退出，耗时约 3 分 10 秒，无 NaN/OOM。
- Best PSNR 31.76463@1000，SSIM 0.98100，LPIPS 0.03025。
- live loss 在 iter 500 后产生 90 条有限审计记录；mv loss 在 iter 1000 后产生 30 条有限记录。
- checkpoint 保存 120 个世界坐标光源点，真实恢复前向成功，逐 GS 方向不同且 attenuation 恒为 1。
- 8 帧 RGB、alpha、albedo/separation、normal 快速渲染目检均无异常；详见冒烟目录 README。

冒烟结论：**PASS**，允许启动 35000 iter 正式训练。

### 正式实验结果

- 35000 iter 正常退出，耗时约 53 分 59 秒，无 NaN/OOM；最终为 16012 个 Gaussian。
- iteration 35000 的 point cloud、deformation、photometric checkpoint 完整；光源 checkpoint 保存 120 个有限世界坐标位置，确认使用变形后 GS 坐标，且距离衰减关闭。
- 梯度审计共 91980 条数据记录，全部有限；live/mv normal 分别从 iter 500/1000 持续到 35000。
- 完成 120 帧 RGB、alpha、normal、small/large separation 渲染与独立 GT normal 评估。

- 本实验逐帧 normal mean 为 16.2923°–20.1982°，train/test mean 为 18.3548°/18.3787°，未见明显过拟合。
- alpha coverage 均值 0.172123，范围 0.167996–0.182142，时序差 3.614e-4；覆盖率与 0823 基本一致，时序波动略高于 0823 的 2.609e-4。
- 四类目检：RGB 主体清晰且无异常曝光；alpha 轮廓连续；normal 平滑、无椒盐噪声；separation 前景完整、背景干净。末帧底座下方拖影也存在于 0823 对照，不属于本模式新增退化。

正式结论：**PASS**。逐 GS GT 位置方向在严格关闭距离衰减时显著改善 normal mean/median/p95，但最佳 PSNR 比 0823 directional 对照低约 0.69 dB，alpha 时序稳定性略差。它应保留为方向 oracle 消融 preset：优先法线恢复时有价值，但现有证据不足以将其作为 RGB 重建的默认替代。完整命令、日志、代表图片/视频路径和四类目检见 `output/0824-04-CV3s-GTposition_perGSdir_3ncons/README.md`。
