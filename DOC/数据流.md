# LumiMotion 代码流程与数据流总览

> 本文档梳理 LumiMotion（可重光照的动态 2D 高斯泼溅）从**数据加载 → Stage 1 几何训练 → Stage 2 材质/重光照训练 → 渲染评估**的完整数据流。
> 所有行号基于当前分支 `feature/photometric-lambertian-v1`。所有入口脚本均从**仓库根目录**作为模块调用：`python -m scripts.train_stage1 ...`。

---

## 0. 一句话定位

重建一个**动态场景**：先用 Stage 1 学好几何 + 运动（形变）+ 动静分割，再用 Stage 2 在冻结几何上学**材质**和**环境光**，从而能在**未见过的环境光照**下重新打光。

核心创新点是每个高斯附带一个可学习的**二值分离特征** `feature`（直通 Gumbel-sigmoid，T=0.5），它乘到形变量上，把高斯推向"动(1)/静(0)"二值分布。

### 4.2 二值分离机制（论文核心）

每个高斯有 1 个可学习标量 `feature`（`fea_dim=hyper_dim=1`，初始化 `binarization_init_value=-1e-2`）。

- **`get_binary_feature(eval, T=0.5)`**（`gaussian_model.py:223-241`）：直通 Gumbel-sigmoid
  ```
  u = rand(训练) 或 0.5(eval)
  binary = sigmoid( (1/T)·(log_feat + log(u) - log(u)) )   # 用 -log(u)+log(1-u) 近似 Gumbel 噪声
  ```
  warm-up 期间直接返回 `ones`（所有高斯都"动"）。
- **动/静如何体现**：`binary_feature` 直接乘到 `d_xyz`、`d_rotation`。feature→0 的高斯位移归零（静态，仅靠 canonical 几何表达）；feature→1 的受 MLP 形变（动态）。
- **`lambda_separation`**：`mean(binary_feature)·λ` 把 feature 推向 0/1 二值分布（无监督二值化的 L1 推动项）。

### 4.3 Stage 1 保存产物（`scripts/train_stage1.py:247-252`）

在 `saving_iterations`（含 `[1,1000,10000,20000]+每万步+iterations`）或 `warm_up-1` 触发，写入同一 `model_path`：

1. **高斯 PLY** → `point_cloud/iteration_<iter>/point_cloud.ply`（`Scene.save` → `gaussian_model.py:364`）
   含：xyz、albedo_dc(3)、albedo_dc_stage1(3)、albedo_rest、f_dc(3)、opacity、roughness、scale(2)、rot(4)、feature(1)，启用 photometric 时额外 `photometric_albedo_*`。
2. **形变 MLP** → `deform/iteration_<iter>/deform.pth`（`deform_model.py:38`，含 `mlp_color` 头供 Stage 2 复用）
3. **光度光照**（仅 photometric 模式）→ `photometric/iteration_<iter>/photometric.pth`

### 4.4 【当前分支新增】Photometric Lambertian 模式

- **启用**：`pipe.render_mode == "photometric_lambertian"`（默认 `"original"`，`arguments/__init__.py:85`）。
- **渲染参与**（`gaussian_renderer/__init__.py:115-125`）：当启用且无 override_color 时，绕过 SH 颜色路径，取高斯旋转后局部 z 轴作法线，调用 `PhotometricLambertianRenderer(albedo, normal, fid)`，输出 `color = albedo·light_rgb·max(N·L,0)` 作为 `colors_precomp` 喂给光栅化器（`photometric_lambertian.py:53-67`）。
- **可学习参数**：每时间步 6 维光照（`raw_light_dir`(3)+`raw_light_rgb`(3)）+ 每高斯 3 维 `_photometric_albedo`。
- **损失**（`train_stage1.py:166-172`）：`light_smoothness_loss`×`lambda_photometric_light_smooth`（**默认 0**）+ `photometric_albedo_reg_loss`×`lambda_photometric_albedo_reg`（**默认 0**）。默认两权重为 0，即仅替换颜色计算路径、不引入额外 loss。

### 5.3 `render_ir` 渲染方程（`gaussian_renderer/render_ir.py:26-401`）

一次调用对同一组 splat 跑**三次** diff-surfel 光栅化：

1. **albedo 光栅化**（`:123-132`）：`base_color = srgb_to_rgb(get_albedo)`，`get_albedo = clamp(SH2RGB(albedo_dc),0.03,0.97)`。
2. **roughness 光栅化**（`:135-144`）：`get_rough = sigmoid(_roughness)`。
3. **Stage1 SH 颜色光栅化**（`:146-159`）：`_albedo_dc_stage1` + `_albedo_rest`，叠加可训练阴影调制 `shadowed_modulation = d_color[:,:3].clamp_max(1.0)`。

**几何属性**（`:178-231`）：从多通道输出取 alpha/normal/depth（expected/median 按 `depth_ratio` 混合）/dist，反投影表面点 `points`，得伪法线 `surf_normal`。

**光线采样**（`:257-298`）：在 `render_alpha>0.9` 的像素里均匀采 `trace_num_rays//(diffuse_sample_num+light_sample_num)` 个像素得 `mask`，仅对这些像素计算渲染方程。

**`rendering_equation`（`:435-555`）**——默认 `diffuse_sample_num=256, light_sample_num=0`：

```
sample_incident_rays(normals, 256)            # Fibonacci 上半球采样 (relight_utils.py:36)
global_incident_lights = envlight(incident_dirs, mode='pure_env')   # 直接查 EnvLight latlong  (:469)

# 可见性 + 间接光 (relight=False 分支 :510-523)
trace = pc.trace(position + incident_dirs*light_t_min, incident_dirs, shs=sh_features, ...)  (:512)
incident_visibility = 1 - trace['alpha']            # surfel_tracer 阴影
local_incident_lights = srgb_to_rgb(trace['color']) # 用 Stage1 SH 颜色作间接光先验

incident_lights = visibility·global + local_indirect
f_d = base_color / π                               # Lambert 漫反射
f_s = GGX_specular(N, w_o, L, roughness, F0=0.04)  # 镜面 (:527,558-591)
transport = incident_lights · incident_areas · (N·L)
diffuse  = (f_d · transport).mean(-2)
specular = (f_s · transport).mean(-2)

final_image = rgb_to_srgb(diffuse + specular)·alpha + bg·(1-alpha)
```

> **训练用 Stage1 SH 颜色作间接光先验；`relight=True`（评估重光照）才用材质(albedo/rough)重算 trace 的 diffuse/specular（`:471-508`）。**

### 5.4 EnvLight（`scene/light.py:159-396`）

- `base`：`nn.Parameter [16,32,3]`，`exp` 激活，**内部存 log 空间**。查询返回 `exp(base)`（HDR）。
- `__call__(dirs, mode)`（`:359-395`）：`mode='pure_env'`（训练主用）经 latlong UV 双线性采样；`mode='diffuse'/'specular'` 基于 cubemap+mip，**仅 relight=True 时用**。
- 优化器：Adam 单组，`lr=envmap_cubemap_lr=0.1`（**不**被 ×0.1）。

### 5.5 BVH / 光线追踪（`scene/gaussian_model.py:706-770`）

封装 `surfel_tracer.GaussianTracer`（`transmittance_min=0.03`）。
- `get_boundings`（`:706`）：每个高斯算 12 顶点 icosahedron 包围盒。
- `build_bvh`（首帧一次）/`update_bvh`（之后每帧）：因高斯随时间形变，每帧重算包围盒。
- `trace(rays_o, rays_d, shs, ...)`（`:730`）：由 `rendering_equation` 对 N×256 条阴影光线调用，返回 `color/normal/feature/depth/alpha`；alpha 归一化取命中表面。

### 5.6 Stage 2 保存产物（`scripts/train_stage2.py:265-269`）

写入同一 `model_path`（最终 55000 步）：
1. **高斯 PLY** → `point_cloud/iteration_<iter>/point_cloud.ply`（同 Stage1 属性集）
2. **形变 MLP** → `deform/iteration_<iter>/deform.pth`
3. **EnvLight** → `envmap/iteration_<iter>/envmap.pth`（state_dict）+ `envmap.hdr`（256×512 latlong 可视化）

## 6. 阶段四：渲染与评估（必须先完成 Stage 2）

### 6.1 执行顺序（`bash_scripts/synthetic_results_from_paper.sh:85-142`）

```
train_stage2 (55000)
  ├─ render_materials                              # 可视化, 非依赖
  ├─ [static]  scale_albedo_static  → eval_material_static → eval_relight_static → eval_nvs_static
  └─ [dynamic] scale_albedo_dynamic → eval_material_dynamic → eval_relight_dynamic → eval_nvs_dynamic
```

### 6.2 ★为什么 `scale_albedo_*` 必须先于 eval

Stage 2 的 albedo 存在**全局尺度歧义**（光照与 albedo 可互换缩放）。`scale_albedo_static.py:122-132` / `scale_albedo_dynamic.py:111-120` 把渲染线性 albedo 与 GT 线性 albedo（PNG 经 `srgb_to_rgb`）在前景掩码内逐像素相除，算出 4 种候选缩放，写到 **model_path 根目录**的 `albedo_scale_linear_{static,dynamic}.json`：

```json
{"0":[1,1,1], "1":[median(R)·3], "2":[median per-channel R,G,B] ★实际用, "3":[mean per-channel]}
```

所有 material/relight eval 脚本在开头加载它并**固定取 key `"2"`**（如 `eval_material_static.py:34-36`），作为 `base_color_scale` 传入 `render_ir`，在进入渲染方程前对线性 albedo 做逐通道缩放（`render_ir.py:234-235`）。**NVS 评估不应用此缩放**（尺度已含在学到的光照里）。跳过 scale_albedo 会让 eval 直接 `FileNotFoundError`。

### 6.3 static vs dynamic 变体

| 维度 | static | dynamic |
|---|---|---|
| 时间步 | 固定单一静止帧 `fid_static`（从静态数据集名提取） | 每相机用自身 `view.fid`（真实运动） |
| GT 来源 | 静态数据集 `<source>_statictimestep*/` | 动态数据集自身 |
| roughness 评估 | **有**（读 `roughness/r_*.png`） | **无** |
| 语义 | 把动态场景冻结在某一帧评估 | 完整运动序列上评估 |

### 6.4 各脚本输入/输出

| 脚本 | 用途 | 关键输入 | 结果文件 |
|---|---|---|---|
| `render_materials` | 可视化 albedo/roughness + mp4 | Stage2 ckpt | `trained_materials/ours_<iter>/*.png,mp4` |
| `scale_albedo_static/dynamic` | 估计 albedo 全局缩放 | Stage2 ckpt + GT albedo | `albedo_scale_linear_*.json` |
| `eval_material_static` | 静态 albedo+roughness | 读 scale json | `results_material_static.json` |
| `eval_material_dynamic` | 动态 albedo | 读 scale json | `results_material_dynamic.json` |
| `eval_relight_static/dynamic` | 未见光照重光照（PBR） | `<test_light_folder>.hdr` + scale json | `results_relight_*.json` |
| `eval_nvs_static/dynamic` | 训练光照新视角（用**学到**的 EnvLight，非重光照） | `env_light.load_weights` + `train_light_folder` GT | `results_nvs_*.json` |

### 6.5 评估指标

- **PSNR**（`utils/image_utils.py:32`）：`20·log10(1/√MSE)`
- **SSIM**（`utils/loss_utils.py:45`，11×11 窗口）
- **LPIPS**（`lpipsPyTorch.lpips(..., net_type='vgg')`）
- **MS-SSIM / Alex-LPIPS**（`pytorch_msssim.ms_ssim` / `utils/image_utils.py:17 alex_lpips`，仅训练报告与两个新 stage 脚本用）

逐相机累加后除以相机数写 `results_*.json`。relight/nvs eval 用 `test/train_light_folder` 的 alpha 通道做前景抠图后算指标。

### 6.6 【新文件】`eval_stage1_dynamic` / `eval_stage2_dynamic`

未跟踪、**不在 bash 流水线**，是独立的逐帧诊断评估器：
- 遍历**全部** test 相机（`dataset.eval=True`，不像 `train_report_utils` 只取前 4 个）。
- 每帧存 render/gt/error/mask/normal/comparison PNG + 逐帧指标进 `metrics_per_frame`。
- 指标更全（l1/psnr/ssim/lpips_vgg/ms_ssim/lpips_alex）。
- **`eval_stage1_dynamic`**：用 Stage1 ckpt + 普通 `render`（非 IR），`relight=False`，GT 为训练光照图，输出 `results_stage1_dynamic.json`（`:151`）。
- **`eval_stage2_dynamic`**：用 Stage2 ckpt + `render_ir`（学到的 EnvLight），**内置 albedo 缩放评估**（前景像素 `GT线性albedo/预测线性albedo` 取逐通道中位数，把 `scale_albedo_dynamic`+`eval_material_dynamic` 合为一步，无需静态数据集），输出 `results_stage2_dynamic.json`（`:283`）。

## 7. 关键张量速查表

| 张量 | 形状 | 来源 | 去向 |
|---|---|---|---|
| `_xyz` | (N,3) | `create_from_pcd`/`load_ply` | `means3D = _xyz + d_xyz` |
| `feature` | (N,1) | 可学习，init -1e-2 | `get_binary_feature` → 二值化 |

| `d_rotation` | (N,4) | `gaussian_rotation(h)·binary_feature` | 旋转四元数偏置 |
| `d_scaling` | — | **恒 0**（Stage1） | — |
| `d_color` | (N,6) | `mlp_color` 头（shadow3+dynamic3） | 阴影调制；Stage2 可训练 |
| `albedo_dc` | (N,3) | SH DC | `get_albedo` → base_color |
| `roughness` | (N,1) | 可学习 | `get_rough=sigmoid` |
| `EnvLight.base` | (16,32,3) | 可学习 log 空间 | `exp(base)` 查全局入射光 |
