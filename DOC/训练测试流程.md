# 训练测试流程

本文只记录给其他 agents 复用的命令模板：Stage1 训练、Stage1 eval、以及导出 1000-35000 阶段的光照可视化。

## 1. 环境

新服务器 `minakshi`：

```bash
conda activate lumimotion-cu126
```

旧服务器：

```bash
conda activate lumimotion-cu129
```

下面命令均从仓库根目录执行。

## 2. Stage1 训练命令

以 LH static 单场景为例：

```bash
SCENE=brass_vase
GPU=0
OUT_ROOT=output/LH-staticv2

CUDA_VISIBLE_DEVICES=${GPU} conda run --no-capture-output -n lumimotion-cu126 \
python -m scripts.train_stage1 \
  --source_path data/LH-data/transfer-static/${SCENE} \
  --model_path ${OUT_ROOT}/${SCENE}_stage1v2 \
  --images images \
  --train_light_folder images \
  --is_blender --eval --gt_alpha_mask_as_scene_mask \
  --render_mode photometric_lambertian \
  --photometric_stage s1d_joint \
  --photometric_light_param bspline \
  --photometric_num_ctrl_points 16 \
  --photometric_s1d_light_lr 0.0001 \
  --photometric_s1d_albedo_lr 0.001 \
  --photometric_s1d_rotation_lr 0.0001 \
  --photometric_s1d_scaling_lr 0.0001 \
  --photometric_s1d_position_lr 0.0 \
  --photometric_s1d_deformation_lr 0.0 \
  --photometric_s1d_opacity_lr 0.0 \
  --photometric_use_hemi_prior \
  --lambda_photometric_light_smooth1 0.01 \
  --lambda_photometric_light_smooth2 0.01 \
  --lambda_photometric_hemi 0.001 \
  --lambda_photometric_albedo_prior 0.005 \
  --deform-type static \
  --resolution 2 \
  --iterations 35000 \
  --densify_until_iter 8000 \
  --opacity_reset_interval 100000 \
  --min_opacity 0.005 \
  --binarization_warm_up 1000 \
  --lambda_separation 0.005 \
  --d_xyz_loss_weight 0.001 \
  --d_color_reg_loss_weight 0.01 \
  --depth_ratio 1.0 \
  --test_iterations 1000 5000 10000 20000 30000 35000 \
  --save_iterations 1000 5000 10000 20000 30000 35000 \
  --quiet
```

注意：训练脚本会自动追加 `_static` 后缀，实际输出目录为：

```text
output/LH-staticv2/brass_vase_stage1v2_static
```

## 3. Stage1 评测命令

评测 `iteration_35000`：

```bash
SCENE=brass_vase
GPU=0
MODEL=output/LH-staticv2/${SCENE}_stage1v2_static

CUDA_VISIBLE_DEVICES=${GPU} conda run --no-capture-output -n lumimotion-cu126 \
python -m scripts.eval_stage1_dynamic \
  --source_path data/LH-data/transfer-static/${SCENE} \
  --model_path ${MODEL} \
  --images images \
  --train_light_folder images \
  --is_blender --eval \
  --resolution 2 \
  --render_mode photometric_lambertian \
  --deform_type static \
  --load_iter 35000
```

主要输出：

```text
${MODEL}/results_stage1_dynamic.json
${MODEL}/eval_stage1_dynamic/ours_35000/
```

评测图示例：

```text
${MODEL}/eval_stage1_dynamic/ours_35000/000_frame_0008_comparison.png
${MODEL}/eval_stage1_dynamic/ours_35000/000_frame_0008_render.png
${MODEL}/eval_stage1_dynamic/ours_35000/000_frame_0008_albedo.png
${MODEL}/eval_stage1_dynamic/ours_35000/000_frame_0008_normal.png
```

## 4. 导出 1000-35000 光照图

`LH_Utils.export_light_directions` 读取：

```text
${MODEL}/photometric/iteration_<ITER>/photometric.pth
```

如果某个 iteration 没有 photometric checkpoint，会自动跳过。

```bash
SCENE=brass_vase
MODEL=output/LH-staticv2/${SCENE}_stage1v2_static
LIGHTS_JSON=data/LH-data/static/${SCENE}/lights.json

for ITER in 1000 5000 10000 20000 30000 35000; do
  CKPT=${MODEL}/photometric/iteration_${ITER}/photometric.pth
  if [ ! -f "${CKPT}" ]; then
    echo "[skip] missing ${CKPT}"
    continue
  fi

  CSV=${MODEL}/light_directions_it${ITER}.csv
  POLAR=${MODEL}/light_polar_compare_it${ITER}.png
  CURVE=${MODEL}/light_timeseries_compare_it${ITER}.png

  conda run --no-capture-output -n lumimotion-cu126 \
  python -m LH_Utils.export_light_directions \
    --model_path ${MODEL} \
    --iteration ${ITER} \
    --output ${CSV}

  conda run --no-capture-output -n lumimotion-cu126 \
  python -m LH_Utils.plot_light_polar \
    --csv ${CSV} \
    --lights_json ${LIGHTS_JSON} \
    --output ${POLAR} \
    --title "${SCENE} light polar iteration ${ITER}"

  conda run --no-capture-output -n lumimotion-cu126 \
  python -m LH_Utils.plot_light_timeseries \
    --csv ${CSV} \
    --lights_json ${LIGHTS_JSON} \
    --output ${CURVE} \
    --title "${SCENE} light xyz iteration ${ITER}"
done
```

每个 iteration 会输出：

```text
${MODEL}/light_directions_it<ITER>.csv
${MODEL}/light_polar_compare_it<ITER>.png
${MODEL}/light_timeseries_compare_it<ITER>.png
```

CSV 有 6 列：

```text
raw_x, raw_y, raw_z, dir_x, dir_y, dir_z
```
