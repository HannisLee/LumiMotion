# Per-light 光线学习率实验报告

日期：2026-07-21  
数据：`data/LH-data/transfer-dynamic/only_clothV2`  
服务器/环境：`mahadevi` / `lumimotion-mahadevi`

## 技术摘要

本报告比较 8 组从头训练的 per-light 学习率实验：4 组恒定学习率和 4 组“前期高、后期低”的分段学习率。所有实验从 iteration 1 起直接使用 per-frame directional light 与 Lambertian BRDF，训练 35000 iteration，并在 35k 完成固定视角、120 timestep 的 Stage 1 insights 渲染。

主要结论如下：

- **如果目标是 RGB 重建质量，恒定 `3e-5` 明显最好。** 它在 30k/35k 分别达到 PSNR `46.6792/46.2253`，35k LPIPS `0.00842`，同时也是八组中目检最干净的一组；代价是光线方向几乎没有脱离初始化，35k 平均角误差仍为 `42.56°`。
- **如果目标是光源方向拟合，恒定 `3e-3` 最好。** 35k cosine direction loss 为 `0.18371`，平均角误差 `35.09°`；但 RGB 退化到 PSNR `44.5866`，并出现更多漂浮点和末帧拖影。
- **恒定 `1e-3` 是当前较合理的折中点。** 35k PSNR `45.1864`、平均方向误差 `38.29°`。它没有取得单项第一，但位于 RGB–方向误差的非支配前沿。
- **四种分段 LR 没有产生新的 Pareto 最优解。** 其中 `long-high` 是分段策略里最好的一组，但其 35k PSNR `44.3853`、平均角误差 `36.63°`，两项同时弱于恒定 `3e-3`。
- **所有实验在 30k 后 PSNR 都下降，且所有完整视觉验收均为 `FAILED`。** 即使后期把 light LR 降到 `1e-4`，分段组仍继续退化，说明 30k–35k 的 RGB 下降不能只归因于光线方向学习率，Gaussian、deform、albedo 等联合优化也可能参与了过拟合或伪影增长。

因此，当前没有任何学习率配置可以作为严格验收通过的最终模型。后续若继续研究方向学习，建议以恒定 `1e-3` 或 `3e-3` 为起点，同时处理光照–albedo–几何的可辨识性和时序 Gaussian 伪影，而不是继续只搜索全局 light LR。

### 恒定 LR 呈现清晰的 RGB–方向权衡

从 `3e-5` 增大到 `3e-3` 时，光线方向平均角误差从 `42.56°` 降到 `35.09°`，但 35k PSNR 从 `46.2253` 降到 `44.5866`。这不是单纯的“学习率越大越好或越坏”，而是两个目标发生分离：

- 小 LR 让方向保留较强的初始化先验，模型更依赖 albedo、Gaussian 和 deform 吸收 RGB 误差，因此重建指标较好，但方向不准确。
- 大 LR 允许方向更快偏离初始化并更接近诊断 GT，但同时改变 Lambertian shading，联合优化更容易产生颜色/几何补偿和视觉伪影。
- `1e-3` 同时优于 `3e-4` 的 RGB 与方向结果；因此在已测恒定值中，`3e-4` 没有保留价值。

以 35k 的 PSNR 最大化、平均方向误差最小化为双目标，非支配前沿仅包含：

1. `3e-5`：RGB 端点；
2. `1e-3`：折中点；
3. `3e-3`：方向端点。

### 分段 LR 没有解决后期退化

四组分段方案中，`S-long` 的方向结果最好，平均角误差 `36.63°`；`S-moderate` 的 35k RGB 最好，PSNR `44.7942`。但所有分段策略都被恒定 LR 方案同时支配：

- `S-short` 与恒定 `1e-3` 的平均角误差几乎相同，但 PSNR 低 `0.9400 dB`。
- `S-medium` 和 `S-long` 的 PSNR、方向误差均弱于恒定 `3e-3`。
- `S-moderate` 的 PSNR、方向误差均弱于恒定 `1e-3`。

更重要的是，八组 `ΔPSNR` 全部为负。分段组即使在末段使用 `1e-4`，30k 到 35k 仍下降 `0.40–1.79 dB`。这说明仅衰减 light LR 不足以稳定后期 RGB；下一轮应检查其他参数组的后期学习率、30k 后的 deformation/opacity 漂移，以及 albedo 与方向的补偿关系。

## 光线方向指标的定义与解释

模型保存的方向采用物理传播约定 `light → object/surface`。源数据 AREA light 的位置只用于训练后诊断，未进入训练 loss。诊断 GT 为：

```text
scene_center = centroid(points3d.ply)
GT_ray[t] = normalize(scene_center - light_pos_world[t])
```

逐帧方向 loss 为：

```text
L_dir = mean_t(1 - dot(normalize(pred_ray[t]), normalize(GT_ray[t])))
```

平均角误差由逐帧 dot product 的反余弦计算。这里没有对预测序列做循环移位或时间反向对齐，因此指标同时包含未知起始相位、绕行方向以及训练校正不足带来的误差。

八组共享的 iteration 1 初始化 cosine loss 约为 `0.27712`。到 35k 后，相对下降幅度如下：

| 实验 | cosine loss@35k | 相对初始化下降 |
| --- | ---: | ---: |
| C-3e-5 | 0.27044 | 2.41% |
| C-3e-4 | 0.24812 | 10.47% |
| C-1e-3 | 0.21699 | 21.70% |
| C-3e-3 | **0.18371** | **33.71%** |
| S-short | 0.21715 | 21.64% |
| S-medium | 0.20200 | 27.11% |
| S-long | 0.19960 | 27.98% |
| S-moderate | 0.22697 | 18.10% |

该结果确认恒定 `3e-3` 并非“学习率过大导致无法下降”：它仍在有效学习方向，且取得最低方向 loss。问题是方向改善没有同步转化为更好的 RGB 或视觉质量。

## 实验边界与不确定性

1. **GT 方向是 AREA light 到点云中心的单方向近似。** 它不是 AREA light 到每个表面点的精确入射 ray，因此方向误差适合组间诊断，不应解释为物理光照的绝对误差。
2. **真实起始相位和绕行方向没有用于初始化或监督。** 当前 loss 未做循环移位/时间反向对齐；绝对角误差包含初始化未对齐成分。
3. **方向 GT 没有参与反向传播。** 训练只通过 RGB loss 和相邻帧 smoothness 间接学习方向，因此 albedo、几何和光照之间存在明显不可辨识性。
4. **每种设置只有一次从头训练。** 未做多随机种子重复，较小的指标差异可能包含随机初始化和训练采样波动；但 `3e-5` 与高 LR 在 RGB/方向上的大幅差异，以及八组统一的 30k 后退化，足以支持当前定性结论。
5. **完整时序渲染使用固定 test camera。** 它适合检查运动连续性和伪影，不等价于逐帧移动相机 GT 对齐，也不代替 novel-view 定量评估。
6. **最佳 checkpoint 只在已保存 iteration 中比较。** 目前证据支持 30k 优于 35k，但真正峰值可能位于两个 checkpoint 之间。

## 推荐下一步

### 若优先保留当前最好的模型

- RGB/外观研究使用恒定 `3e-5` 的 30k checkpoint。
- 光源方向研究使用恒定 `3e-3` 的 30k 或 35k checkpoint；方向指标以 35k 最终诊断为准。
- 需要单一折中模型时使用恒定 `1e-3`，不再投入 `3e-4` 或当前四种分段 schedule。

### 下一轮实验不要只继续扫 light LR

优先做以下受控实验：

1. 将默认保存/早停点移到 30k，并在 `25k–32k` 增加密集 eval，确认退化起点。
2. 在 25k 或 30k 后同时衰减/冻结 Gaussian position、deform 和 albedo 参数组，以定位后期 PSNR 下降来源。
3. 显式优化或枚举光线轨迹的 `phase` 与 `direction_sign`，先解决未知起点和绕行方向，再让 120 条 per-frame residual 做小幅校正。
4. 对方向参数加入“椭圆轨迹 + 小 residual”的低维结构，减少 120 条独立方向与 albedo/geometry 相互补偿。
5. 如果允许使用源 light 标注，增加低权重方向监督或 phase-alignment loss，并分别报告有监督和纯 RGB 结果。
6. 针对所有 LR 都存在的漂浮点和末帧拖影，单独检查 opacity、densification、deformation 与 alpha mask，而不是将其继续归因于 light LR。

## 仍待回答的问题

- 30k 后退化主要来自 albedo、deform、Gaussian geometry，还是它们与 light direction 的共同漂移？
- 先对齐 phase/sign 后，较低 light LR 是否能同时保留 `3e-5` 的 RGB 和 `3e-3` 的方向精度？
- 使用低维光轨迹参数化后，是否能消除 t=60/119 的射线和拖影伪影？
- 多随机种子下，恒定 `1e-3` 的折中优势是否稳定？

在这些问题解决前，八组实验的正式结论保持为：训练和渲染成功，但严格 Stage 1 验收全部 `FAILED`。
