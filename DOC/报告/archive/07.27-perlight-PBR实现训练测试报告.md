# Per-light PBR 实现与训练前验证报告

## 1. 结论

本次在不改变原始 SH、`photometric_lambertian` 和原生 LumiMotion Stage2
默认行为的前提下，新增独立渲染模式：

```text
photometric_perlight_pbr
```

该模式继续采用 per-Gaussian / pre-splat 着色，但把原来的单项 Lambertian
扩展为受约束的线性空间 PBR 混合管线：

```text
photometric albedo
+ rough diffuse
+ dielectric GGX specular
+ learned per-light intensity/color/area
+ low-frequency environment fill
+ soft local visibility
+ bounded normal residual
+ bounded multiplicative shading residual
→ linear-space Gaussian rasterization
→ sRGB output
```

训练仅使用 RGB 图像。GT albedo、normal 和 light 不进入训练图；PBR 前景 loss
使用固定几何产生的 detached render alpha，而不是 GT alpha。

CPU 单元与回归测试共 15 项全部通过。only_clothV3 Stage1
`iteration_35000` 上完成了两次真实 GPU forward/backward、一次 optimizer
update、checkpoint 保存/恢复、PBR 分解渲染以及原始 SH 单帧回归。验证结果：

- checkpoint 内所有 tensor 均为有限值；
- geometry、rotation、opacity 最大绝对漂移均为 `0`；
- 32 个 deformation tensor 与 Stage1 完全一致；
- photometric albedo、roughness 及 15 个 PBR 状态 tensor 正常更新；
- 原始 SH 渲染路径单帧退出码为 `0`。

因此实现与长期训练前 sanity check 结论为 **PASS**。

## 2. 受约束模型

### 2.1 Per-light 方向

- 每帧共享一个 learned directional light。
- 主轨迹由二阶 Fourier 系数产生。
- 每帧仅允许一个受角度上限约束的 tangent residual。
- 默认方向残差上限为 `10°`。
- 训练不读取 GT light；checkpoint 仍输出完整 light trajectory JSON，供训练后
  与 GT light 做角度诊断。

### 2.2 光照与曝光

- 全局正值 intensity。
- 零均值、约束在 `±0.1 log` 的逐帧 exposure。
- 归一化 learned RGB light color。
- 默认 `2°`、最大 `12°` 的 learned angular radius。
- 训练使用 4 个确定性面积光样本，评估使用 8 个。

### 2.3 材质与 BRDF

- photometric albedo 由 Stage1 SH/DC 初始化并在 sRGB/linear 之间显式转换。
- diffuse 使用 rough diffuse。
- specular 使用 dielectric GGX，固定 `F0=0.04`。
- Gaussian 原有 roughness 参数参与训练。
- 所有 BRDF 计算和 Gaussian 颜色 rasterization 均在线性 RGB 中完成，最终只在
  rasterized image 上执行一次 sRGB encoding。

### 2.4 可见性

默认使用 `local_knn` 软阴影：

- 在固定 Stage1 Gaussian 中心上建立一次 16-neighbor KNN topology；
- 动态帧沿用 topology，但使用当前 deformation 后的位置；
- 根据 blocker 的沿光方向距离、垂直距离、Gaussian scale 和 opacity 构造连续
  optical depth；
- visibility 为有界的 `exp(-optical_depth)`，对 learned light direction
  保持可导。

原生 BVH backend 仍作为显式可选项保留，但不会成为默认路径。

### 2.5 受限 residual

- normal residual 是每个 Gaussian 的二维 tangent perturbation，默认最大 `10°`。
- shading residual 是小型 MLP 输出的乘性项：

  ```text
  multiplier = exp(0.2 × tanh(MLP(...)))
  ```

- 因此 residual 不能生成无界的独立 RGB，也不能绕过物理项直接添加 RGB。

## 3. 训练范围

PBR 阶段固定：

- xyz；
- Gaussian rotation；
- scaling；
- opacity；
- deformation network；
- 原始 SH coefficients。

训练：

- photometric albedo；
- roughness；
- structured per-light direction；
- intensity、exposure、light color、angular radius；
- low-frequency environment；
- bounded normal residual；
- bounded shading residual。

为保证 per-Gaussian normal residual 的 checkpoint shape 稳定，PBR
`photometric_start_iter` 必须不早于 `densify_until_iter`。

## 4. RGB loss

主 loss 为：

```text
1.0 × full-image sRGB MSE
+ 0.2 × detached-render-alpha foreground L1
+ 0.1 × detached-render-alpha foreground DSSIM
+ 0.05 × log-linear Charbonnier
+ constrained regularizers
```

regularizer 包括一阶/二阶 light smoothness、exposure、normal residual、
roughness prior、environment energy 和 residual parameter norm。

PBR 模式不计算 GT alpha BCE、normal loss、depth distortion loss、
deformation loss 或 separation loss。

## 7. Native BVH 记录

在当前 `minakshi` 环境中，原生 `surfel_tracer.build_bvh` 发生 native
segmentation fault。输入 checkpoint 中有 3321 个 Gaussian 的 opacity 低于
tracer 的 `alpha_min=0.01`；过滤这些 Gaussian 并确认所有 BVH vertex 有限后，
native build 仍能复现段错误。

因此：

- 失败日志完整保留在 smoke 目录；
- 默认 PBR 可见性改为 `local_knn`；
- 显式 `bvh` backend 在发现 opacity 不满足 native bound 前提时会先抛出
  Python `RuntimeError`，避免已知输入直接进入 native 崩溃；
- 未修改 `GaussianModel.build_bvh/update_bvh/trace`，原生 LumiMotion Stage2
  默认行为保持不变。
