# Deferred GS 实现、训练与测试报告

> 归档文件名沿用 07.26 实验系列；deferred 实现、四组重训及完整评估实际完成于
> 2026-07-27。

## 1. 结论

本次实验把 `photometric_lambertian` 的 Lambertian 计算位置从
**per-Gaussian / pre-splat** 改到 **per-pixel / post-splat**，没有加入 GGX、
roughness、light intensity、light color、environment、shadow、indirect light
或额外 RGB residual。

实现通过了 CPU 数值测试、V3 GPU 单帧梯度检查、原有 photometric/staged-training
回归测试和 120 timestep 完整渲染。四组训练均无 NaN、OOM 或异常退出，所有指定
checkpoint、日志、统计、接触表和视频均已保存。

但四组 iteration 55000 的 PSNR 都没有超过各自的旧 per-GS 对照：

| 组别 | 旧 per-GS PSNR | deferred PSNR | 差值 |
| --- | ---: | ---: | ---: |
| learned V2 / fixed | 24.0884 | 24.0781 | -0.0102 |
| GT point / fixed | 21.8088 | 21.6260 | -0.1828 |
| learned V2 / rotation LR 1e-7 | 24.1628 | 24.1590 | -0.0037 |
| GT point / rotation LR 1e-5 | 26.9493 | 26.8959 | -0.0533 |

此外，所有结果仍继承 Stage1 在后段 timestep 出现的布料水平拖尾/边缘毛刺。
因此按预设验收标准，四组最终结论均为 **FAILED**。实验产物完整保留，没有覆盖
任何 07.26 checkpoint 或报告；代码在本报告归档后回退到 per-GS 版本。

## 2. 实现范围

### 2.1 修改前：per-GS Lambertian

```text
每个 Gaussian：
color_i = albedo_i × max(0, normal_i · light_i)
→ rasterize color_i
```

### 2.2 修改后：deferred per-pixel Lambertian

```text
rasterize albedo / normal / depth / alpha
→ 构造逐像素 albedo、world normal、surface position
→ color_pixel = albedo_pixel × max(0, normal_pixel · light_pixel)
→ alpha composite
```

具体行为如下：

- `photometric_lambertian` 名称和 photometric checkpoint 格式保持兼容。
- rasterizer 的颜色输入改为未着色的 `photometric_albedo`。
- 逐像素 intrinsic albedo：

  ```text
  albedo_pixel =
      (rendered_albedo - background × (1 - alpha)) / max(alpha, 1e-6)
  ```

- rasterized world normal 除以 alpha 后归一化，再按原规则朝向 camera，保持布料
  双面着色行为。
- surface position 从 raster depth 和 camera ray 还原。
- learned directional 模式仍然是每帧一个方向，所有像素共享该方向。
- GT point 模式改为真正的逐像素方向：

  ```text
  normalize(light_position_world - surface_position_pixel)
  ```

- 最终输出：

  ```text
  foreground = albedo_pixel × clamp(normal_pixel · light_pixel, 0)
  render = foreground × alpha + background × (1 - alpha)
  ```

- 新增的诊断输出为 `photometric_albedo_map`、
  `photometric_normal_map`、`photometric_ndotl_map` 和
  `photometric_shading_map`。
- 原始 SH 路径和原生 LumiMotion Stage2 路径未修改。

## 3. 数值稳定性与兼容性

GPU 单帧 anomaly check 首次发现：无覆盖像素上的 `expected_depth / alpha` 会在
反向传播中触发 `DivBackward0` NaN。修复只作用于 photometric deferred 分支，将
分母钳制为 `alpha.clamp_min(1e-6)`；SH 分支保持原样。

修复后的结果：

- deferred RGB、albedo、normal、surface position 和 light 方向梯度均有限；
- 低 alpha 和纯背景像素不再产生 NaN；
- alpha composite 与背景还原符合公式；
- 已有 learned directional 和 GT point checkpoint 均可直接加载；
- capture/checkpoint 数据结构未改变。

- 600 张 PNG；
- 7 个 MP4；
- RGB、alpha、normal、albedo、photometric normal、shading、`n·l`、

- 120 帧 normal-depth 统计；
- alpha coverage 统计；
- Gaussian 参数、geometry、rotation、deformation 漂移审计；
- learned light/GT light 方向审计；
- 训练日志与渲染日志。

目检结果：

- RGB：FOV、主体比例、位置和时序运动正常，没有新增主体缺失、跳变或全黑帧。
- alpha：背景稳定，轮廓随主体连续；fixed 组与旧组严格一致。
- normal：时序连续，无大面积随机翻转或脱离 RGB 轮廓。
- separation：动态布料保持红色，静态椅子/圆台保持绿色，没有退化成全动态或
  全静态。
- albedo、shading、`n·l`：均为有限值且时序连续，未出现 NaN 条带。
- 遗留问题：所有组仍可见源 Stage1 在约 t87 之后出现的布料水平拖尾/边缘毛刺。

由于 Stage1 Eval 规范规定关键时序伪影不能由定量指标抵消，因此该遗留问题也是
严格验收失败原因之一。
